# v5.5.7

发布日期：2026-10-12

## 更新标题

3DPartHub v5.5.7 - 修复选型页误弹「产品数量不能超过 500」（结果超 500 自动改存参数快照、后台预创建失败静默）+ 选型快照恢复体验优化（菜单进入弹提示告知/重新选择立即清快照）+ 构建期剥净内联脚本注释（view-source 不再显示源码注释）

## 更新描述

修复三个问题：① 选型页在用户没有主动分享时弹出「产品数量不能超过 500」——根因是选型结果出现后页面会自动预创建工单来源分享快照，匹配结果超过 500 个产品时被服务端上限拒绝，后台任务的报错错误地弹给了用户；② 选型快照恢复（v5.5.6 引入）在主动点选型菜单进入时恢复得无声无息，用户不知道状态从哪来；③ 生产 view-source 仍能看到内联脚本的中文块注释——已有的构建期注释剥离插件只剥了 HTML 注释和 // 行注释，漏了 /\* \*/ 块注释。全部为前端改动，无数据库迁移。

## 修复清单

### 1. 选型页误弹「产品数量不能超过 500」（核心修复）

- **现象**：用户没有点分享，选型结果一出现就弹出「产品数量不能超过 500」报错
- **根因**：选型结果出现后页面自动预创建「工单来源分享快照」（结果卡跳工单页带来源用的后台任务），把当前匹配到的全部产品 ID 冻结进快照；匹配结果超过服务端 500 上限时创建失败，失败提示弹给了没有在分享的用户
- **修复一**：匹配结果超过 500 时自动改存**纯参数快照**（不冻结产品列表）——分享链接打开后自动回跳选型页、按参数实时过滤出结果（复用现成的 selection-mode 机制），分享功能完整可用且产品列表永远最新
- **修复二**：后台预创建（工单来源）失败一律静默——它本来就有回退兜底（结果卡跳工单回退到模型页/选型首页），任何失败都不再打扰用户
- **用户主动分享**的报错提示保留不变

### 2. 选型快照恢复体验优化（v5.5.6 的补充）

- **点选型菜单/侧栏/底部 tab 主动进入且发生了恢复**：弹一条提示「已恢复上次的选型进度」——消除「怎么还在？」的困惑；返回/刷新的恢复保持静默（体感是同一会话延续）
- **「重新选择」「清空」**：现在立即删除快照——点完就走的下次进入是全新开始；之后重新选的参数会重新累计
- 点「首页」清空（v5.5.6 已有）、2 小时有效期、显式入口（深链/分享链接）优先等规则均不变

### 3. 构建期剥净内联脚本注释（view-source 清洁度）

- **现象**：生产环境 view-source 仍能看到首帧主题脚本的大段中文块注释
- **根因**：构建期注释剥离插件只处理了 HTML 注释（`<!-- -->`）和内联脚本的 `//` 行注释，`/* */` 块注释原样进入产物
- **修复**：内联脚本（无 src、不参与打包压缩的）构建时整体过一遍 esbuild 压缩——行注释/块注释全部剥除（字符串中的 `//`、`/*` 不受影响），变量名不动、行为等价；transform 异常时回退原文不影响构建
- 已全渠道扫描：JS bundle / CSS 产物 / public 静态 HTML 均无注释泄漏；唯一保留的注释是 nginx SSI 指令（生产注入 favicon 用，必须保留）
