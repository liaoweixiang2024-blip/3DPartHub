# v5.3.1

发布日期：2026-10-06

## 更新标题

3DPartHub v5.3.1 - 大文件导出下载截断修复（数据包/模型导出 revokeObjectURL 延迟，导入端不再报「无法读取压缩包」）+ 移动端选型图片选项不再被吸顶头整排遮挡（滚动定位补偿）+ 大分类卡触摸 focus 轮廓/文字拖选防御

## 标签描述

v5.3.1 fixes large-file export downloads being truncated, mobile selection options being hidden under the sticky header, and two remaining touch-feedback paths on the category cards. The export-download bug: after triggering `a.click()`, the code called `URL.revokeObjectURL(url)` synchronously - but browsers read the blob asynchronously, so with large packages (selection data packs with image assets, model export zips - tens of MB) the revocation won the race and the saved file was a truncated zip that failed to import with "cannot read archive or manifest corrupted". Fixed in 4 places (selection data-pack export, model export switched to the existing `downloadBrowserBlob` helper with 60s-delayed revocation plus iOS PWA fallback; kit-list txt and audit-log json get delayed revocation). The mobile selection page sticky header (title + search + selected strip, ~176px tall) was swallowing a whole row of image option cards because scroll positioning did not compensate for it - four scroll-position calculations now subtract the actual header height, so the current step title and first row of options land fully below it (desktop unaffected). Category cards get `select-none` (iOS text-drag selection highlight looked like the background turning white while scrolling) and the focus-visible outline is desktop-only now. No database migrations.

## 更新描述

本次为 **导出下载修复 + 移动端选型体验修复** 版本，无数据库迁移，更新前后端镜像即可。

## 大文件导出下载截断（导入报「无法读取压缩包」的根因）

### 问题

- 「导出数据包」下载的 zip 在「导入数据包」时报 `无法读取压缩包或 manifest 损坏`
- 服务端导出产物本身完好（绕过浏览器直接下载验证可正常解析）

### 根因

- 下载保存代码在 `a.click()` 后**同步**执行 `URL.revokeObjectURL(url)`
- 浏览器下载是**异步**读 blob 的：小包读取快碰巧没事；大包（带图片资产的数据包、模型导出包，几十 MB）revoke 先完成 → 浏览器保存的是**截断的 zip** → 导入端 AdmZip 打不开

### 修复（4 处同款）

| 位置               | 修复                                                                        |
| ------------------ | --------------------------------------------------------------------------- |
| 选型数据包导出     | 改用现成 `downloadBrowserBlob`（revoke 延迟 60s，含 iOS 主屏 PWA 下载兜底） |
| 模型库导出         | 同款 bug（模型包更大、截断风险更高），同修                                  |
| 清单 txt 下载      | revoke 延迟 60s                                                             |
| 审计日志 JSON 导出 | revoke 延迟 60s                                                             |

### 验证

- 本地实测：导出水枪 600 条产品（无资产 14KB）与全铜快插接头（含 17 张选项图 2.5MB）→ 同一 zip analyze 均 200 通过

## 移动端选型图片选项被吸顶头遮挡

### 问题

- 每步选项都带图片时（如「接头形态」17 张图），选完一步自动滚到下一步，**新步骤的标题和首排图片卡整个钻到吸顶头（标题+搜索框+已选条，约 176px≈一整排图片卡）底下被吞掉**

### 修复

- 壳层吸顶头标记 `data-sticky-header`；选型页 4 处滚动定位（步骤推进/回顶意图/自动跳步/结果揭晓）统一减去吸顶头**实际高度**
- 实测（iPhone 视口）：吸顶头 bottom=268，新步骤标题 top=357，完整露出头下方；桌面端标题在滚动容器外不受影响

## 大分类卡触摸反馈防御（v5.3.0 后残余机制）

- 分类卡加 `select-none`：iOS 按住文字拖动触发文本拖选，选中高亮观感即「背景变白」
- focus-visible 轮廓门控到桌面（≥768px）：移动端触摸导致的 focus 不显示轮廓线

## 升级说明

- 无数据库迁移（schema 未变更）
- 服务器更新：`cd /opt/3dparthub && docker-compose pull && docker-compose up -d`，浏览器强刷（Cmd/Ctrl+Shift+R）
- 验证：重新「导出数据包」→「导入数据包」不再报「无法读取压缩包」；手机选型到带图片选项的步骤（如全铜快插接头·接头形态），选完上一步后新步骤标题完整可见；按住大分类卡拖动时卡片不再变白
