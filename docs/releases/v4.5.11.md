## 更新标题

3DPartHub v4.5.11 - 修复站点 Logo/Favicon 404（nginx 路由缺陷）+ 详情页长标题自适应 + 分类筛选悬停闪烁优化

## 标签描述

v4.5.11 fixes a long-standing nginx routing defect that made all admin-configurable brand assets return 404: the regex location serving /static/(favicon|logo|watermark)/ combined `alias` with `try_files $uri`, and in regex locations `$uri` keeps the full /static/ prefix — nginx probed a doubled path (/app/static/static/logo/icon.png) that never exists, so the site logo, favicon and watermark were permanently 404 (phones showed a "?" placeholder). The location now maps the path explicitly via capture groups (`try_files /$1/$2`), verified in a local nginx container including path-traversal rejection. Also in this release: the PC model-detail page title now adapts to length (30px → 24px → 18px tiers, 3-line clamp with a Show more toggle that only appears when the title is actually truncated — measured via scrollHeight, not guessed from character count); the workbench category sidebar hover flicker is fixed (icon chip now transitions background-color in sync with the row, and rows keep a faint constant background instead of transparent-to-tinted switches that force text re-rasterization on macOS); and the dev server (vite) now injects the live head fragment from the API on first paint so the custom favicon shows immediately instead of flashing the default. No database migration; server-side code unchanged.

## 更新描述

本次为 **品牌图标修复 + 详情页体验优化** 版本，无数据库迁移、无 API 改动。

**① 修复：站点 Logo / Favicon / 水印 404（nginx 路由缺陷）**

- 根因：nginx 对 `/static/(favicon|logo|watermark)/` 的正则 location 里 `alias` + `try_files $uri` 组合，`$uri` 含完整 `/static/` 前缀，实际探测双重路径 `/app/static/static/logo/...` → 三类品牌资源**自该 location 上线起一直 404**（文件本身完好在卷里）。此前靠浏览器缓存掩盖，更换 Logo 后暴露——手机端（无缓存）显示「?」占位
- 修复：正则加捕获组，`try_files /$1/$2` 显式映射；本地 nginx 容器实测三类文件 200、不存在 404、路径穿越（`../`/`%2e%2e`）正常拦截

**② 优化：PC 端模型详情页长标题自适应**

- 标题按长度分档字号：< 22 字保持 30px / 22–39 字降 24px / ≥ 40 字降 18px，长型号名不再把下载按钮挤出首屏
- 最多 3 行截断 +「展开/收起」；展开按钮**只在标题真的被截断时才出现**（渲染后实测 scrollHeight，替代按字数猜测的误判——避免「点了展开却没内容」）

**③ 优化：分类筛选悬停闪烁（workbench 主题）**

- 侧栏项图标底片补 150ms 背景色过渡（原来 0s 瞬跳，与行背景过渡不同步造成闪烁感）
- 行背景改为常驻极浅底色（替代「透明→4% 主题色」切换），避免 macOS Chrome 重绘时文字子像素抗锯齿翻转被感知为「文字晃一下」

**④ 优化：本地开发首帧 Favicon**

- vite dev 插件改为启动时从本地 API 拉实时 head-fragment（30s 缓存 + 静态兜底），首帧即自定义图标，不再「先默认后切换」（生产 SSI 路径本就正常，此修复仅影响本地开发）

## 升级步骤

```bash
cd /opt/3dparthub
docker-compose pull && docker-compose up -d --force-recreate
```

> 本次必须重建 **web 容器**（nginx 配置进镜像），`--force-recreate` 必不可少。
> 升级后浏览器强制刷新（Cmd/Ctrl+Shift+R），手机端微信彻底关闭页面重开以清除图标缓存。
