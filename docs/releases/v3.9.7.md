## 更新标题

3DPartHub v3.9.7 - 应用描述可自定义 + 修复分享按钮误报「页面运行出错」

## 标签描述

3DPartHub v3.9.7 adds an admin-configurable PWA app description and fixes the v3.9.6 muted-error regression. New setting 站点与品牌 → 应用描述 (site_app_desc, up to 200 chars): feeds the webmanifest description — what Chrome shows as the installed app's note — falling back to the site description, then the built-in default. The v3.9.6 fix for iOS "Script error." had an ordering bug: getErrorMessage replaced the muted string with the localized fallback (e.g. 页面运行出错) BEFORE the silence check, so the check never matched and the fallback toast still appeared when tapping the share button; the silence check now inspects the raw error object (string or Error.message) before any conversion. No DB migration.

## 更新描述

本次 2 项改动，**无数据库迁移**。

- **[新增] PWA 应用描述可后台自定义**
  - 设置 → 站点与品牌 → 新增「应用描述」（应用图标下方）。
  - 控制 Chrome「安装应用」后应用列表/快捷方式里显示的备注文字。
  - 优先级：应用描述 → 站点描述 → 内置默认（Enterprise 3D Part Model Management Platform）。
- **[修复] v3.9.6 遗留：点分享按钮弹「页面运行出错，请刷新后重试」**
  - v3.9.6 的 Script error 静默逻辑存在顺序缺陷：错误文案先被替换成本地化兜底文案，替换后再做静默判断永远匹配不上，导致 iOS 点分享/系统分享时兜底文案照样弹出。
  - 现在静默判断在**原始错误对象**上执行（转换前），纯 "Script error." 一律不弹。

前端「检查更新」会读取本更新描述展示最新版本号与更新内容。

## 部署备注

本次**无数据库迁移**。升级步骤：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v3.9.7 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

curl -s http://localhost:3780/api/settings/version   # 应显示 v3.9.7
```

升级后注意：

- **应用描述**：后台「设置 → 站点与品牌 → 应用描述」填写保存后，需要**卸载重装**浏览器里已安装的应用（Chrome 安装时缓存 manifest），新备注才会生效；iOS 添加到主屏幕同理重新添加。
- **分享按钮**：iOS 点应用内分享按钮不应再弹任何报错提示。

默认跟随 latest 的部署由 Watchtower 自动更新。
