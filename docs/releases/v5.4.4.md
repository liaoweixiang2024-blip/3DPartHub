# v5.4.4

发布日期：2026-10-08

## 更新标题

3DPartHub v5.4.4 - 系统选型导航移动端去外层包裹（大分类卡与标题平级同规格）+ 模型转换完成自动展示预览（不再需要手动刷新）

## 更新描述

本次包含两项修复：**系统选型导航页（/category-nav）移动端布局重构**——拆掉包裹在四个大分类外面的双层大容器，分区卡与标题卡平级、同规格呈现；**模型详情页转换状态自动轮询**——转换完成后页面自动切出预览，兑现状态页文案承诺。均为前端改动，无数据库迁移、后端代码零改动（api 镜像仅版本号随动），更新 web 镜像即生效。

## 修复清单

### 1. 系统选型导航移动端去外层包裹

- **之前**：移动端四个大分类被两层容器裹住——内容面板的圆角边框盒 + 里面再一层画布底色，视觉上「大盒套小卡」；分区卡比标题卡缩进一圈、底色边框规格也不一致
- **现在**：
  - 外层容器（内容面板 + 画布底色）在移动端全部透明无框，四个大分类分区卡直接平铺在页面底色上，与标题卡同层级、左右边缘逐像素对齐
  - 分区卡规格与标题卡完全对齐：同底色（surface-container-low）、同圆角（走主题变量 `--app-page-radius`，换主题自动同步）、同细淡描边（不再用深色描边——深边会把同宽的卡读成窄一圈）
  - 标题卡保留全站统一样式；标题位于滚动器之外，天然固定不随内容滚走
  - 桌面端（≥768px）拓扑画布布局零改动
- **实现备注**：主题 CSS 的 `[data-interface-theme] .app-content-panel`（特异度 0,2,0）会压掉 Tailwind 的 `border-0`/`bg-transparent` 工具类（0,1,0），去壳规则写在 global.css、选择器带 `[data-interface-theme]` 提到 (0,3,0) 才能生效，且仅在 <768px 媒体查询内

### 2. 模型详情页转换完成自动展示预览

- **之前**：转换中状态页文案写着「转换完成后会自动展示预览」，但页面没有任何轮询机制——停在该状态页永不自愈，只能手动刷新，承诺落空
- **现在**：`queued / processing` 期间每 3 秒静默拉取一次状态（与管理端转换队列面板 2 秒同量级），转换完成后最多 3 秒内页面自动切到预览；转失败则自动切到失败态。手机切后台时暂停轮询、切回前台立刻补一次，避免后台空耗
- **负载评估**：该状态页仅管理员可达（服务端对其他用户 404），现实并发为 1 人；3 秒一次主键点查（1~5ms）≈ 单核 0.2%，且状态翻转即停，对比通知铃铛（全部登录用户、15 秒常驻轮询）可忽略
