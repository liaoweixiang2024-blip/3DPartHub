# v5.4.6

发布日期：2026-10-09

## 更新标题

3DPartHub v5.4.6 - iOS 移动端体验三连修（主屏应用静默自动更新 + 发版后旧资源钉死修复 + 首帧主题修复治「页面浅色顶栏却黑」）

## 更新描述

本次为**iOS 移动端专项修复**，三个独立问题一次治齐：主屏安装的应用在服务器更新后一直跑旧代码且用户无法自救；发版后部分文件被 iOS 磁盘缓存钉在旧版（「一半新一半旧」）；iPhone 上页面明明是浅色、Safari 地址栏和状态栏却一直是黑色（刷新无效，所有页面如此）。纯前端 + nginx 改动，无数据库迁移、后端代码零改动（api 镜像仅版本号随动），更新 web 镜像即生效。

## 修复清单

### 1. 主屏应用静默自动更新（iOS 挂起恢复检测）

- **问题**：iOS 把主屏 WebApp 切后台后是「挂起」，点图标只是恢复挂起的页面——不重新导航、不发任何请求，页面 JS 从挂起前继续跑。服务器更新后，已安装的应用会一直停在旧页面，用户没有任何「更新」入口
- **修复**：构建时注入版本号并产出 `/version.json`（nginx no-cache）；应用在「从后台恢复」（visibilitychange / pageshow）以及前台每 30 分钟兜底时静默对比版本，不一致自动整页刷新（URL 不变，用户回到同一页面，全程无感、无任何提示）
- **防打断保护**：切走不足 30 秒的快速切回不刷；焦点正在输入框/富文本上不刷（留到下轮）；页面不在前台不刷
- dev 构建不注入版本，检测自禁用；单次请求为 30 字节静态文件，负载可忽略

### 2. 发版后「一半新一半旧」修复（nginx 根级静态文件缓存头）

- **问题**：public/ 下的固定文件名文件（CAD 导入内核 `occt-import-js.js`/wasm、字体、图标等，无内容哈希）此前响应不带任何 Cache-Control 头——浏览器（尤其 iOS 主屏应用独立的磁盘缓存）按启发式新鲜度把旧文件钉住，发版后出现「新页面里跑着旧文件」
- **修复**：nginx 对根级静态文件统一下发 `public, max-age=0, must-revalidate`（每次向服务器校验，304 很快）；带哈希的 `/assets/`（immutable 365d）与后端 `/static/`（immutable 30d）策略不变。Docker 起真实 nginx 逐路径实测验证

### 3. 首帧主题修复（治 iOS「页面浅色、顶栏黑色」）

- **问题**：index.html 首帧内联脚本只设颜色标记没切主题类，且主题逻辑放在「有配置缓存才执行」的门槛后（首次访问整段跳过）——首帧按默认深色渲染；主题存储回填还会抢先按旧值掰回深色一瞬。iOS Safari 在**首帧取一次页面颜色**染地址栏/状态栏后**不再跟随**后续变化——表现为页面浅色、顶栏却锁死黑色，刷新无效，所有 iPhone 浅色用户都受影响
- **修复**：首帧主题判定提到最前（不再依赖缓存存在），优先级与后端规则完全对齐（本地自动切换 > 用户手动 > 服务器自动时段 > 服务器默认/跟随系统）；首帧同步挂对主题类；主题存储回填不再抢先反转非用户手动的主题，消除深色闪变窗口
- **收益**：iPhone 浏览器与主屏应用的顶栏颜色恢复跟页面一致；手动深色用户不受影响；Android/桌面首帧的深色闪烁也一并消除

## 验证

- client `npm run verify` 全绿（主题合同/加载合同/UX 合同/typecheck/lint/format/build/33 单测）；server 无代码改动，verify 维持全绿
- CDP 模拟 iPhone 实测：静默自动更新在「离开 31 秒后回前台」场景正确触发整页刷新且路由保持；四组主题场景逐毫秒时间线确认「本地存深色 + 服务器默认浅色」从第 1 毫秒起全程浅色、深色帧为 0
- Docker 起生产同构 nginx 实测缓存头：根级文件 must-revalidate / 哈希 assets 仍 immutable / 入口与 version.json、sw.js 均 no-cache

## 升级说明

- 无数据库迁移（schema 未变更）
- 服务器更新：`cd /opt/3dparthub && docker-compose pull && docker-compose up -d`，浏览器强刷（Cmd+Shift+R / Ctrl+Shift+R）
- 本次仅 web 镜像有实质改动，api 镜像仅版本号随动，两端一并拉取即可
- **上线后注意**：现已装在用户手机里的旧应用没有自动更新机制，需要**杀掉应用重开一次**（或删图标重装）拿到新版本，之后自动生效；宝塔代理层可用 `curl -sI https://域名/occt-import-js.js | grep -i cache-control` 验收（期待 `public, max-age=0, must-revalidate`）
