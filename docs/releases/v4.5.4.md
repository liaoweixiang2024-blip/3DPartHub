## 更新标题

3DPartHub v4.5.4 - 三项前端修复（手机端删除弹源码报错 / 120每页缩略图裁切 / 首页点logo回初始态）

## 标签描述

3DPartHub v4.5.4 ships three frontend fixes. Mobile model-detail delete: the optimistic cache update after deleting from the mobile detail page used the raw snake_case server response shape instead of the mapped camelCase page object SWR actually caches, and dropped totalPages — useInfiniteModels then read undefined and threw a TypeError whose message (containing minified callback source code) was toasted to the user as gibberish before "已删除" appeared; the updater now matches HomePage's correct form (camelCase, totalPages preserved and recomputed, page untouched when the id is absent). 120-per-page thumbnail clipping: the home list switches to virtualized scrolling above 80 items, and virtual rows were pinned to a fixed 260px height — grid cards are naturally taller at common column widths (square cover + text block ≈ 340px+), so the cover got squeezed/clipped; TanStack Virtual's measureElement dynamic row measurement replaces the fixed height, correct at every column count and window width, both classic and workbench desktop themes. Logo click on home: clicking the logo while already on the home page only cleared the search box, and the category was only reset when a search term existed — with a category selected and no search, nothing happened on both PC and mobile; a dedicated home-browse-reset event now restores the full initial state (category → all, search cleared, page 1, default sort, URL params stripped, list refreshed). No DB migration.

## 更新描述

本次为**三项前端修复**版本，无数据库迁移。

**① 手机端模型详情页删除模型不再弹出源码报错**

此前手机端在详情页删除模型时，删除本身成功但会先弹一条乱码 toast（内容是压缩后的函数源码，如 `items:e.items?.filter(...)`）。原因：删除后更新列表缓存的代码写错了缓存对象形态（按原始 snake_case 服务端响应处理，实际缓存是映射后的 camelCase 对象），且丢失了 `totalPages` 字段，导致无限滚动逻辑读到 `undefined` 抛运行时错误，错误信息被全局 toast 原样弹出。现改为与首页列表删除一致的正确写法（保留并重算 `totalPages`，未命中时不动该页）。PC 端与首页列表删除原本就正常，不受影响。

**② 120 个/页时缩略图不再显示不完整**

首页模型列表超过 80 条会自动启用虚拟滚动，虚拟行此前被固定为 260px 高——而网格卡片在常见列宽下天然高度 340px+（正方形封面 + 标题/按钮区），固定高度装不下导致封面被压缩/裁切。20/40/60 每页在阈值内不受影响，所以只有切到 120/页才出现。现改为按渲染后的真实卡片高度动态测量行高，列数、窗口宽度、网格/列表模式怎么切换都正确；classic 与 workbench 两套桌面主题一并修复。

**③ 首页点 logo 立即回到初始状态（手机 + PC）**

此前已在首页时点左上角 logo 只会清搜索框回顶部；只选了分类没搜索时分类不会被重置，看起来「点了没反应」。现在点 logo 完整回到首页初始状态：分类回「全部」、搜索清空、回第 1 页、排序回默认（最新）、URL 参数清掉、列表刷新并回顶部。不在首页时点 logo 跳回首页的行为不变。
