## 更新标题

3DPartHub v3.9.1 - 选型工单来源直达选型结果 + 隐藏自动快照

## 标签描述

3DPartHub v3.9.1 refines the ticket-source feature for selection results. When a user submits a support ticket from a selection result card, the ticket source is now a selection-share snapshot link (/selection/s/<token>) that opens the exact filtered result set the user was viewing — instead of just linking to the selection homepage. The snapshot is pre-created automatically when results appear and is rebuilt whenever filters change, so the source always reflects the current result set. These auto-created snapshots are flagged with a new auto_created column and are excluded from My Shares, the admin share management list, and admin share statistics — they are internal ticket-source artifacts, not user shares — while the snapshot links themselves remain accessible so existing ticket sources never break. Fallbacks (matched model page / selection homepage) still apply for logged-out users or when sharing is disabled. One additive DB migration (nullable-default-false column, no data touched).

## 更新描述

本次优化**选型提交工单的来源链接**，并让自动生成的分享快照不再出现在分享列表，包含一个数据库迁移（仅新增默认 false 的列，无数据风险）。

- **[优化] 选型工单来源直达选型结果**
  - 之前从选型结果提交工单，来源链接只跳到选型首页；现在直接指向**用户当时筛选出的那组选型结果**（选型分享快照页，含筛选条件与结果列表）。
  - 快照在选型结果出现后自动预创建；筛选条件（规格/搜索词/分类）变化会自动重建，来源始终对应当前结果。
  - 管理员查看工单点「来源选型」即可看到用户当时看到的那组结果，无需再问用户筛选了什么。
- **[调整] 自动快照不再出现在分享列表**
  - 提交工单自动创建的选型快照带内部标记（auto_created），不出现在：用户的「我的分享」、后台「分享管理」列表、后台分享统计。
  - 快照链接本身不受影响，工单来源永远可访问。
  - 用户手动点「分享结果」生成的分享完全不受影响，照常显示。
- **[兜底] 未登录或分享功能关闭时**，来源回退为匹配模型页/选型首页，不报错不打扰。
- **[数据库] 一个迁移（仅加列，无数据风险）**
  - `selection_shares` 新增 `auto_created` 布尔列（默认 false）。

前端「检查更新」会读取本更新描述展示最新版本号与更新内容。

## 部署备注

本次**有数据库迁移**（仅新增默认 false 的列，API 容器启动时自动执行，无数据风险）。升级步骤：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v3.9.1 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

curl -s http://localhost:3780/api/settings/version   # 应显示 v3.9.1
```

升级后注意：

- 选型来源直达选型结果只对**升级后新提交**的工单生效。
- 分享列表里不会再出现工单自动生成的快照；此前已生成的快照链接仍有效。

默认跟随 latest 的部署由 Watchtower 自动更新。
