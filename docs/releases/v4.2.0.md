## 更新标题

3DPartHub v4.2.0 - 新功能：模型支持挂多份 PDF 图纸 + 个人资料页改版（换绑邮箱/地址联动）+ 分享页移动端图纸入口

## 标签描述

3DPartHub v4.2.0 adds multi-drawing support and a profile-page rework. Models can now carry multiple PDF drawings (new model_drawings table with automatic backfill of legacy single-drawing data; upload is now append-semantics): the model detail page, admin edit dialogs, and share pages list every drawing with per-drawing view/delete, per-drawing 5-minute access tokens, and per-drawing share endpoints. Multi-select upload and ZIP/RAR batch archives now bind ALL same-named PDFs instead of silently keeping only one. Search matches drawing names; the orphan-file cleanup gains an orphan_drawings category; the models module backup includes the new table. The profile page now matches the register form: email becomes read-only with a two-step rebind flow (verification codes to both old and new mailbox, all sessions revoked on success), address switches to a 3-level cascading region picker, and username gets on-blur validation. Also: the share page mobile bottom action bar now shows drawing entries (previously desktop-only), the duplicated 429 rate-limit toast text is fixed, and an admin password reset script (server/scripts/reset-admin-password.ts) is included. DB migration included (auto-applied on container start).

## 更新描述

本次为**功能更新**，含数据库迁移（容器启动时自动执行，无需手动操作）。

**新功能：模型多图纸**

- 一个模型可挂多份 PDF 图纸（如总装图 + 零件图各一份）：详情页下载区、管理编辑弹窗、分享页均逐份列出，可逐份查看/删除
- 上传语义从「覆盖替换」改为「追加」——编辑弹窗常驻「继续添加 PDF 图纸」按钮
- 每份图纸独立 5 分钟访问令牌与分享接口；旧链接（无图纸 ID）自动回落第一份，平滑过渡
- 批量上传（多选文件 + ZIP/RAR 压缩包）同名多份 PDF **全部绑定**，不再只保留一份
- 原有单图纸数据升级时自动迁入新表（每模型一条记录），无需任何手动操作
- 搜索支持按图纸文件名命中；孤立文件清理新增「孤立图纸文件」类别；模型库模块备份已包含图纸表

**新功能：个人资料页改版（对齐注册页）**

- 邮箱改为只读 + **换绑邮箱**：旧邮箱、新邮箱各发一封验证码，双码确认后生效；换绑成功全部设备强制下线重新登录
- 地址改为省/市/区三级联动选择（不再手填），原地址自动回填
- 用户名失焦即时校验（重名/格式即时提示）

**体验修复**

- 分享页移动端底部操作条补上图纸入口（此前只有 PC 端信息面板能看到图纸链接）
- 修复 429 限流提示重复拼接（「请15分钟后重试，请 14 分钟后再试」→ 只显示一条带倒计时的）
- 附带管理员密码重置脚本 `server/scripts/reset-admin-password.ts`（服务器/本地通用）

**建议升级后验证**：任选模型 → 编辑 → 连续上传两份 PDF → 详情页下载区应出现两个 PDF 行，分享链接页 PC 与手机视图均逐份可打开。

前端「检查更新」会读取本更新描述展示最新版本号与更新内容。

## 部署备注

本次**含数据库迁移**（新增 model_drawings 表 + 旧图纸数据回填），容器启动时自动执行：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v4.2.0 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

curl -s http://localhost:3780/api/settings/version   # 应显示 v4.2.0
```

升级后注意：

- 首次启动会自动把原有单图纸数据迁入新表，原上传过图纸的模型自动显示为 1 条图纸记录
- 换绑邮箱功能需要邮件服务（SMTP）已配置，否则验证码发不出去

默认跟随 latest 的部署由 Watchtower 自动更新。
