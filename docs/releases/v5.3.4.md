## 标签描述

v5.3.4 finds and fixes the real cause of the mobile selection category-card white-out that survived five earlier fix rounds (v5.2.9-v5.3.3): a Workbench-theme override rule in themes/interfaceThemes/workbench/styles.css styled the category cards with `:hover { background: var(--color-surface-container-lowest) }` - pure white in the light palette. The site default interface theme is Workbench, and on touch input the browser pins `:hover` to the card under the finger through tap / hold / drag / release, so sliding the category list turned the touched card solid white (255,255,255, no selection bar) - matching the on-device screenshots exactly. All previous fixes only touched the base utility classes; this theme override outranked them and was never swept. Reproduced headlessly in the real touch pipeline (emulated 430px viewport, touchscreen tap + CDP touchStart/Move/End): pre-fix, the touched card went `rgb(255,255,255)` through hold, 65px drag, and after release; the earlier CDP-only probe missed it because raw touch dispatch without a preceding tap never derives the hover state. Fix: the rule now requires `[data-mouse-hover='true']` - an attribute only set from `pointerenter` with `pointerType === 'mouse'` - so touch physically cannot trigger it while desktop mouse hover keeps its lighten effect. Post-fix, the same five touch poses leave the card at `rgb(246,245,243)` unchanged. Desktop visuals unchanged; no database migrations.

## 根因：为什么 v5.2.9～v5.3.3 五轮修复后滑动仍变白

- 真凶是 **workbench 主题覆盖 CSS**（站点默认主题就是 workbench）里给选型分类卡的悬停规则：`[data-selection-category-card]:hover { background: var(--color-surface-container-lowest) }`——该变量在浅色主题下就是**纯白**
- 浏览器触摸行为：手指落到卡上后 `:hover` 会被置上并**全程粘在落点卡上**（点按/按住/拖动/松手都不释放）→ 被触摸的卡整张变纯白、无选中橙条——与真机截图像素分析（255,255,255、无橙条）完全吻合
- 五轮修复全部改在**基础工具类**（selectionUtils / global.css / SelectionPage），而主题目录的覆盖规则优先级更高，一直漏网
- 早期 CDP 裸派 touch 排查测不出来的原因：不先经过点按派生的裸 touch 序列不会让浏览器进入 hover 态，导致「计算样式零变化」的误判

## 修复

| 位置                      | 改动                                                                                                                                                   |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| workbench 主题 styles.css | 分类卡悬停规则选择器 `:hover` → `[data-mouse-hover='true']`（该属性仅由卡片 `pointerenter` 且 `pointerType==='mouse'` 时设置，触摸设备物理上无法设置） |
| 桌面端                    | 不变：真鼠标悬停变亮照旧；v5.3.3 的不透明压平色继续保留（合理加固）                                                                                    |
