# v5.9.8

发布日期：2026-10-21

## 更新标题

3DPartHub v5.9.8 - 用户编辑弹窗管理操作全景（具体操作+操作人+用户自助+登录记录IP）+ 审计日志页筛选合并与死数据归位（1100+ 条「其他」可识别可筛选）+ 全站 23 处原生下拉统一为主题化组件

## 更新描述

本版围绕后台两处高频界面做了一次彻底的信息化改造：① 用户编辑弹窗的「最近管理操作」此前只显示 update/create 裸动作名，现在按请求路径还原成具体操作（更新资料/重置密码/更改角色…）并显示操作人；用户自己的改资料/改密/换绑邮箱也进入列表（标注「用户自己」），新增「最近登录」区块（成功/失败+IP，失败红色标示）；底部账号数据从挤成一行的秒级时间戳改为迷你统计卡+相对时间。② 审计日志页两行重叠的筛选合并为一行（资源范围收进下拉），并修复 1100+ 条日志因资源映射缺失全挤在「其他」里不可识别的问题（选型/图片墙/邀请/登出等归位，历史行立即可筛）。③ 全站 23 处原生 `<select>`（浏览器系统样式弹层、不跟主题不跟暗色）统一替换为主题化下拉组件。

## 变更清单

### 1. 用户编辑弹窗：管理操作全景

- 「最近管理操作」按审计记录里的请求路径还原具体操作：更新资料 / 重置密码 / 发送重置邮件 / 更改角色（带新角色名）/ 创建用户 / 删除用户；每行显示操作人用户名（后端批量反查）；**历史记录立即生效**（路径一直在存，此前只是没显示）
- **用户自助操作入列**：改资料（/api/auth/profile）、自助改密、换绑邮箱三类操作的审计行绑定到用户 id（autoAudit 绑定 + 资源归类 user），弹窗每行标「用户自己」与管理员操作区分；历史自助行按路径兜底同样显示
- **创建用户记录补链**：管理员创建用户的审计行此前没有绑定新用户 id（POST 路由无 :id 参数），被创建用户的弹窗里看不到自己怎么来的——创建路由现在显式挂 `res.locals.auditResourceId`，新用户弹窗立即可见
- **「最近登录」区块**（新增）：最近 5 次登录尝试（含失败），按审计行 IP + 状态码显示，失败行红色；登录行发生时未认证，按尝试邮箱（details.body.email，审计侧已统一小写归一）关联到用户，**历史登录记录同样显示**
- **账号数据卡**：底部「下载 N · 收藏 N · 注册 <秒级时间戳> · 最近登录…」单行小字改为两行迷你统计卡（图标+数值+标签，与后台统计卡同族）；最近登录/活跃用相对时间（刚刚/x 分钟前/x 小时前/x 天前，>30 天回退日期），与用户列表页规则一致；五语言同步

### 2. 审计日志页：筛选合并 + 死数据归位

- **两行筛选合并为一行**：动作 tab（全部/创建/更新/删除/登录/下载/工单/设置）保留在页头，「资源范围」一整行 chips 删除、收进搜索框旁的下拉（此前两行大量重名：登录≈认证、下载≈下载、工单≈工单、设置≈设置）
- **资源映射补全**（此前全落「其他」不可识别，本地实测 1136 条）：选型（`/api/selections`、`/api/selection-shares` 及后台管理路由）、图片墙、邀请码、批量上传（归模型）、登出（归认证+新增「登出」动作进登录 tab）——新日志立即归位，历史行照常显示且「其他」选项让它们终于可筛
- **登录行摘要显示尝试邮箱**（此前摘要回退显示 `/api/auth/login` 路径无信息量），登录失败行挂红色「失败」标记（状态码 ≥400）
- 下拉新增选项：选型 / 图片墙 / 邀请码 / 其他

### 3. 全站下拉框统一（新组件 SelectMenu）

- 原生 `<select>` 弹出层是浏览器系统样式（白色、不跟主题、不跟暗色模式），全站 23 处统一替换为主题化下拉：跟主题的圆角卡片弹层、选中项主题色+勾选、入场动画、三种尺寸形态（工具栏/行内/表单字段）
- 弹层 portal 挂载 + 贴近视口底部自动向上翻转；点击外部/Esc 关闭；行内点击不穿透到所在行
- 覆盖：操作日志/用户管理×3/用户编辑弹窗/分页页大小/省市区三级联动/询价分配×2/选型生成器/系统设置×5/选型列编辑器×9/模型管理/导航管理/选型管理分组/通知类型/螺纹工具/图片墙×2/模型导入×2/classic 首页排序
- 旧自绘排序下拉 AdminSortMenu 并入删除（消除两套样式）；AppSelect 按主题契约保留导出但页面侧全部下线
- 修复两个组件级 bug（Playwright 实测抓出）：AnimatePresence 直接包 portal 子节点不渲染（改为 portal 在外动画在内）；选项在 portal 内被「点击外部关闭」误判导致选择不生效（弹层拦截 pointerdown）
