## 更新标题

3DPartHub v3.0.1 - 备份创建与生产镜像热修复版

## 标签描述

3DPartHub v3.0.1 production hotfix release with BusyBox tar compatible backup packaging, restored backup record creation, production-image verification, and refreshed Docker images.

## 更新描述

- 修复生产 Docker 镜像中创建备份后没有生成 `.tar.gz` 和 `.json` 记录的问题。
- 备份打包逻辑兼容 Alpine/BusyBox tar，不再因为多段 `-C` 参数导致 `_backup_db` 找不到。
- 打包时使用单一归档根目录和目录软链接，避免为了兼容 tar 而复制整份模型静态目录，降低大站点备份时的磁盘压力。
- 备份列表增加孤立 `.tar.gz` 兜底识别：即使元数据记录缺失，后台也能看到未登记备份，方便人工处理和恢复。
- 已使用发布版 API 镜像 + 临时 PostgreSQL 环境复现并验证，修复后可正常生成备份包和后台记录。
- 发布前验证通过服务端构建、类型检查、单元测试和生产镜像备份流程。
- 镜像已同步更新：api/web 均发布 v3.0.1 与 latest 标签。

```bash
# Default deployment follows latest and uses Watchtower for api/web auto-updates.
# Run this when you want to update immediately:
cd /opt/3dparthub
curl -L -o docker-compose.yml https://raw.githubusercontent.com/liaoweixiang2024-blip/3DPartHub/main/docker-compose.yml
touch .env
grep -q '^IMAGE_TAG=' .env && sed -i 's/^IMAGE_TAG=.*/IMAGE_TAG=latest/' .env || echo 'IMAGE_TAG=latest' >> .env
docker compose pull
docker compose up -d --force-recreate

# Verify health
curl http://localhost:3780/api/health
```
