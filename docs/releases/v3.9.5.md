## 更新标题

3DPartHub v3.9.5 - 关于系统页升级：版本更新时间线 + 细节修复

## 标签描述

3DPartHub v3.9.5 upgrades the admin About tab and fixes two small UI issues. The 关于 tab is renamed 关于系统 and gains a version-update timeline: a vertical node list of the last 20 releases in reverse-chronological order, each showing the version badge, publish date, release title (extracted from the release notes 更新标题 section), with the currently-running version highlighted in green and labeled 当前版本; clicking a node expands the full release notes with a link to the GitHub Release. Data comes from a new admin endpoint GET /api/settings/update/history backed by the GitHub Releases API with a 10-minute in-process cache, auto-loaded on tab entry with manual refresh and failure retry. Fixes: the 当前配置已保存 status badge in the settings header had a fixed 108px width that clipped its green dot on wider font rendering — now width-adaptive; the share-link input in the share dialog now selects all text on focus, giving iOS users a reliable manual-copy fallback. No DB migration.

## 更新描述

本次升级「关于系统」页，新增**版本更新时间线**，并修复两个小问题。无数据库迁移。

- **[新增] 版本更新时间线（设置 → 运维维护 → 关于系统）**
  - 「关于」更名为「关于系统」。
  - 版本检测下方新增「版本更新记录」：纵向时间线从上到下按发布时间倒序展示最近 20 个版本，每个节点显示版本号、发布日期和更新标题。
  - 当前运行中的版本节点绿色高亮并标注「当前版本」；点击节点展开该版本完整更新内容与 GitHub Release 链接。
  - 进入页面自动加载；数据来自 GitHub Releases（服务端缓存 10 分钟，不会频繁请求），失败可手动刷新重试。
- **[修复] 设置页「当前配置已保存」绿圆点显示不完整**
  - 状态徽章此前是固定宽度，宽字体渲染时圆点被裁切；改为宽度自适应。
- **[优化] 分享弹窗链接输入框点击即全选**
  - iOS 等移动端上一键复制如遇权限问题，点击输入框可直接全选链接手动复制。

前端「检查更新」会读取本更新描述展示最新版本号与更新内容。

## 部署备注

本次**无数据库迁移**。升级步骤：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v3.9.5 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

curl -s http://localhost:3780/api/settings/version   # 应显示 v3.9.5
```

升级后注意：

- 版本时间线在后台「设置 → 运维维护 → 关于系统」；需要服务器能访问 api.github.com，无法访问时显示占位并可重试。

默认跟随 latest 的部署由 Watchtower 自动更新。
