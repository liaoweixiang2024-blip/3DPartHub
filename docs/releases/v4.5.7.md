## 更新标题

3DPartHub v4.5.7 - 偶发掉登录修复 + 重转进度条/子进程隔离 + 登录用户右键分享

## 标签描述

v4.5.7 fixes the intermittent "logged out" bug, makes manual reconversions show real progress without freezing the site, and adds right-click share for logged-in users. Auth fix: multi-tab/PWA windows loading concurrently sent the same refresh cookie twice — the second window was misjudged as token reuse and ALL tokens for the user were revoked (killing both windows); rotation detection now has a 30s grace window where concurrent replays get a fresh access token without rotating the family, replays outside the window are still hard-revoked, and Redis blips (1s command timeout) fail-open instead of returning 401. Reconvert: the edit dialog's "standard/repair" reconversion now runs in a forked child process (occt WASM / gmsh / software rasterization off the API event loop — site stays responsive during conversion) as an async job with a progress endpoint; both buttons show a real progress bar (server reports stage boundaries, client smooths +1%/s between them); gmsh install guide updated to the verified production method (official SDK build + dependency libs mount — distro apt/yum builds are glibc-linked and cannot run in the container). Home page: logged-in users can right-click a model card on desktop to get a quick panel with Open Detail + Share (admins keep the full panel with rename/delete); the panel disappears entirely when the share feature toggle is off. No DB migration.

## 更新描述

本次为 **偶发掉登录修复 + 重转体验重构 + 右键分享** 版本，无数据库迁移。

**① 修复「记住登录」偶发失效（多窗口互踢 + Redis 抖动误杀）**

- **根因一（主）**：浏览器标签页 + PWA 窗口（或两个窗口）同时打开时，页面加载各发一次 `/auth/refresh`，带的是同一份 cookie。先到的成功轮换并把旧 token family 标记「已吊销」，后到的被判「token 复用攻击」→ 401 + 该用户全部 token 连坐吊销——表现为右上角显示未登录，强刷又恢复。现在轮换检测有 **30 秒宽限窗口**：窗口内的并发重放只发新 accessToken、不换 family、不吊销，多窗口从此共享同一 family 互不干扰；窗口外的旧 token 重放仍按原逻辑全家吊销（真泄露防护不降级，攻击面只多 30 秒）。
- **根因二（次）**：轮换检测走裸 Redis eval（commandTimeout 仅 1 秒），一次网络抖动即抛错 → 401「会话失效」。现改为 fail-open：Redis 故障时放行本次轮换，不再把用户顶下线。
- 回归测试覆盖四种场景（首次轮换 / 宽限内重放 / 宽限外重放 / Redis 故障），服务端 184 个测试全绿。

**② 手动重转：子进程隔离 + 真实进度条**

- 编辑弹窗「重新生成（标准引擎）」「修复预览（gmsh）」改为**异步任务**：立即返回 jobId，前端轮询进度——不再转多久按钮就转多久圈。
- 重活（occt WASM 解析、gmsh 网格化、软件光栅化缩略图）全部移入 **fork 出的子进程**执行，API 进程事件循环不受影响，转换期间网站正常浏览、下载不卡。
- 按钮上显示**真实进度条**：服务端在阶段边界上报（解析 5% → 转换 20% → 45%…），前端每秒平滑 +1% 衔接长阶段，完成时精确归位 100%。
- gmsh 安装指引更新为**生产实测可用**的方案：gmsh.info 官方 SDK 包 + 依赖库一起挂载（发行版 apt/yum 的 gmsh 动态链接 glibc，Alpine 容器跑不起来；此前指引按此装会失败）。

**③ 首页右键分享（登录用户）**

- PC 端模型列表：登录用户**右键模型卡片**弹出「快捷操作」面板——打开详情 + 分享链接（与管理员右键一致，但没有编辑名称/删除按钮）。
- 分享功能开关关闭时，普通用户右键不响应；管理员面板里分享按钮同步隐藏。
- 面板文案六语言对齐（简中「快捷操作」/ 繁中 / English / 日本語 / 한국어 / Deutsch）。

## 升级步骤

```bash
cd /opt/3dparthub
docker-compose pull && docker-compose up -d --force-recreate
```

升级后浏览器强制刷新（Cmd/Ctrl+Shift+R）；装了 PWA 的设备建议重开一次窗口，让 refresh cookie 完成一次正常轮换。
