# v6.0.2

发布日期：2026-10-22

## 更新标题

3DPartHub v6.0.2 - 移动端抽屉动画终极丝滑版：framer-motion JS 动画改 CSS 合成器动画（主线程再忙不掉帧）+ 关闭曲线起始提速（修「卡住一会儿再关」）+ 开合状态 store 化（点击时页面树零 re-render）；修复详情页上滑 sheet 收起态面包屑露出一截

## 更新描述

本版是 v6.0.1 移动端动画批次的收尾修正，针对实测反馈的三处手感问题。① 「动画像没有高刷新率」：v6.0.1 的弹簧动画是 framer-motion 的 JS 动画，每帧在主线程计算 transform，主线程稍有抖动整个动画就掉帧——本版侧滑抽屉全面改为 CSS transition（在合成器线程独立运行，主线程再忙动画也满帧），打开用减速曲线 0.26s、关闭 0.22s。② 「收尾卡住一段时间再关闭」：两个来源都已清除——弹簧尾部速度趋零（最后一段近乎爬行）+ 隐藏是固定 0.35s 延迟后瞬间切换，表现为面板停在半路等延迟到点再消失；CSS 版隐藏与位移同一 transition 同时长（离散插值全程保持可见、结束点才隐藏），且关闭曲线起始速度即刻拉满（此前加速曲线起始速度为零，头几十毫秒面板原地不动）。③ 点击菜单按钮瞬间的页面树 re-render：开合状态原先挂在 Layout/Shell/HomePage 组件级 state，每次点击整页（含产品列表）重新 diff；现移入 zustand 小 store，点击时只有常驻抽屉自身响应。④ 修复模型详情页/临时查看页上滑 sheet 收起态在「下载模型」按钮下方露出一截面包屑——peekHeight 常量略大于手柄+peek 条实际高度，内容常驻渲染后那点空隙被内容区顶部填充；收起态给内容区叠加 translateY(peek) 推到 peek 线之下。

## 变更清单

### 1. 侧滑抽屉动画引擎更换（导航两套主题 + 首页分类）

- **CSS 合成器动画替代 framer-motion JS 动画**：CSS transition 在合成器线程独立运行、掉帧免疫；JS 动画逐帧占用主线程，任何抖动都会让动画像降了刷新率
- **关闭曲线起始提速**：加速曲线 `cubic-bezier(0.4, 0, 1, 1)` 起始速度恰好为零（头几十毫秒面板原地不动）→ 减速曲线 `cubic-bezier(0.32, 0.72, 0, 1)` 0.22s，实测 60ms 已滑完 73% 行程（旧曲线同期约 15%）
- **隐藏与位移同步**：不再用固定 0.35s 延迟（弹簧版面板滑完大半后停在半路等延迟到点再消失）；visibility 与 transform 同一 transition，滑出全程可见、结束点隐藏，无静止期
- **遮罩常驻**：opacity 切换 + 关闭态穿透，开合全程零 DOM 挂载

### 2. 开合状态 store 化（新增 useMobileDrawerStore）

- 导航抽屉与分类抽屉的 open 状态移入 zustand store；菜单按钮只调 action（引用稳定不订阅），点击时 Layout/Shell/HomePage 页面树零 re-render
- 接线覆盖：AdminLayout / PublicLayout / AdminPageShell / PublicPageShell / HomePage 全部调用点
- `keepMobileDrawerMounted` prop 删除（抽屉恒常驻，4 处调用点同步清理）；`MobileNavDrawerThemeProps` 随之清空删除

### 3. 详情页上滑 sheet 面包屑修复（模型详情 + 临时查看）

- **现象**：收起态在「下载模型」按钮（peek 条）下方露出一截分类面包屑
- **根因**：peekHeight 常量略大于手柄+peek 条实际渲染高度，v6.0.1 内容改常驻渲染后，那点空隙被内容区顶部（面包屑恰好是第一块）填了进来
- **修复**：收起态给内容区叠加 `translateY(peek)` 推到 peek 线之下（与容器滑出动画同步过渡），展开态归零；实测收起态内容顶在屏幕外（900px > 视口 844px）

### 4. 顺带清理

- 删除 `mobile-nav-drawer-open` 死 class（挂在 html 上但无任何 CSS 规则引用，每次开合触发一次全局 class invalidation 检查）
- UX 契约脚本同步新写法（shell 无 props 挂载抽屉）
