## 更新标题

3DPartHub v3.5.9 - 设置页只读项改为静态展示 + 规格查询使用指南排版优化

## 标签描述

3DPartHub v3.5.9 ships two frontend-only polish items. (1) **Settings page read-only fields no longer render as fake-interactive controls** — fields that are actually determined by environment / infrastructure (Redis connection, private signed-URL, multipart chunk size, download acceleration, etc.) were drawn as togglable switches / dropdowns / text inputs, but the backend silently rejects writes to them (`updateSetting` guards `READONLY_SETTING_KEYS`), so clicking looked broken with no feedback. They now render as static info badges / masked values, and the two always-redundant cache toggles (`cache_enabled`, always on; `cache_driver`, always Redis) are removed entirely. (2) **The thread-size guide (使用指南) layout is reworked** — the four cards (螺纹 / 俗称 / 测量 / 管路) previously used a `grid-cols-2` for the example chips, which broke visually with odd example counts (3 / 5) leaving half-empty truncated rows, and on PC the card row was force-stretched to fill the viewport (`grid-rows-1` = `minmax(0,1fr)`) with chips bottom-anchored via `mt-auto`, creating a large empty gap between the description and the examples. Examples now use `flex-wrap` (size to content, wrap naturally), cards size to their own content with `items-start`, and examples sit directly under the description. No DB migration, no breaking change.

## 更新描述

本次**纯前端**两项体验优化,无数据库迁移、无破坏性变更。

- **[体验] 设置页「假开关/假下拉」改为静态信息展示**
  - 「Redis 与页面缓存」「本地与云存储」里那些由环境变量/基础设施决定、后端本来就**拒绝写入**的字段(如 Redis 地址/密码、签名访问开关、签名有效期、分片大小、下载加速等),以前画成了**可点的开关、下拉、输入框**,但点了毫无反应——像是坏了。现在改成**静态徽章 / 遮蔽值**(开关类显示「已启用 / 未启用」徽章,密码类显示 `••••••`,空值显示 `—`),一眼能看出是只读诊断信息。
  - 顺手删掉两个**永远是噪声**的字段:**启用缓存**(缓存永远启用)和**缓存驱动**(永远用 Redis)。后端兜底守卫保留。
- **[体验] 规格查询「使用指南」四卡排版重做**
  - 修掉移动端示例用 `grid-cols-2` 导致的**断裂**:示例数量是奇数(螺纹/俗称/管路各 5 个、测量 3 个),两列网格会让最后一行只剩一个被截断的按钮(「外径13.1」「牙距1.5」会被 truncate)。改为 `flex` 自适应换行,示例按内容定宽、自然换行,长短不一也不裂。
  - 修掉 PC 端卡片**中间大块空白**:之前卡片行被 `grid-rows-1`(`minmax(0,1fr)`)强制拉满视口、示例又被 `mt-auto` 钉到底部,标题/描述贴顶、示例贴底,中间留洞。现在卡片按内容自适应高度、`items-start` 顶部对齐,「标题 → 描述 → 示例」紧凑自上而下排列。
  - 顺带统一了示例按钮的间距与点击区(更易点、和顶部快捷示例一致)。

前端「检查更新」会读取本更新描述展示最新版本号与更新内容。

## 部署备注

本次**纯前端、无数据库迁移、无破坏性变更**。直接升级即可：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v3.5.9 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

curl -s http://localhost:3780/api/settings/version   # 应显示 v3.5.9
```

默认跟随 latest 的部署由 Watchtower 自动更新。
