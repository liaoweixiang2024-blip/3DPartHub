# v5.4.2

发布日期：2026-10-08

## 更新标题

3DPartHub v5.4.2 - 全站安全审计修复（28 项：refresh 令牌重放/分类白名单泄漏/分享绕权/备份令牌提权 + 资源耗尽与 SSRF 防护）+ 登录会话恢复崩溃修复 + 主题跟随系统实时切换

## 更新描述

本次为**安全加固 + 稳定性修复**版本：对前后端全部功能与 API 做了一次完整安全审计，修复 2 个真高危安全洞、1 个完全不可用的功能、1 个令牌复活 bug 及一批中低危问题；同时合入上一版本遗留的登录会话恢复修复。**无数据库迁移（schema 未变更）**，两端都有改动，需同时更新 web 与 api 镜像。

## 背景

对认证授权链、文件路径、IDOR、注入与缓存、模型生命周期、前端六条线做全面审计，共确认 30 项问题：6 高危、19 中危、5 低危。逐项修复并复核，其中 1 项（下载记录 DB 故障时放行）评估确认为有意设计仅补注释固化，1 项（trust proxy 跳数）属服务器 .env 运维决策不在代码内修复。

## 高危修复

- **Refresh 令牌重放**：原实现重放检测只有 30s 并发宽限窗口，窗口外重放旧 cookie 会被当成首次轮换正常换发。改为 grace（30s 自然过期）+ used（31 天终态标记）双 key 原子检测——多标签页并发行为不变，宽限外的旧令牌重放按泄露处理吊销全家族
- **分类白名单泄漏**：`/api/categories/flat` 原样下发 `allowedRoles`/`allowedUserIds` 白名单明细，普通用户可直接读到受限分类的授权名单。改为只下发公开字段；分类树缓存按 admin/普通用户分桶
- **版本回滚不可用**：版本表 fileKey 存的是带 `?v=` 的完整 URL，回滚拼本地路径时未剥前缀和查询串，路径永远拼错，回滚 100% 失败。已修复（`versions.ts` 上传/回滚同时补原子抢占 PROCESSING + 失败恢复原状态，与转换主流程同语义）
- **登出令牌复活**：logout 撤销标记只存 24h，而 access token 有效期 7 天——第 25 小时起被登出的令牌重新生效。撤销 TTL 改为按令牌剩余寿命计算；撤销时间比较改 `<=` 堵同秒签发竞态
- **备份下载令牌提权**：24h 复用窗口内创建者被降级/禁用后令牌仍有效。消费时回库复核创建者仍为活跃 ADMIN（批量 zip 令牌同范式）
- **批量重转误标 FAILED**：reconvert-all 转换失败把本来预览正常的 COMPLETED 模型打成 FAILED（详情页打不开、GLB 明明还在），且失败无日志。改为与单模型重转一致的「恢复动手前状态」语义

## 中危修复（选摘）

- **分享链路**：分享 info/预览/图纸/下载四端点校验模型 COMPLETED（软删/下架模型不再经分享旁路泄漏）；分享创建补分类可见性校验（受限分类的模型，无权限用户不能再铸造分享 token 绕过白名单）；分享缓存键修正 + 撤销/更新/批量删除全部驱逐缓存
- **SSRF**：IPv6 地址校验重写为完整展开 + 前缀匹配，封堵 `::127.0.0.1`、`::ffff:7f00:1` 十六进制映射、NAT64、6to4 等历史漏网形态（新增 16 项回归测试）
- **资源耗尽**：选型导入解压先按 zip 头预检再解（4GB 上限）；分片上传改流内熔断（超限即断流，不再先落盘再删）；product-wall 解压加累计上限 + 图片魔数校验；无原文件重转从「白等 15 分钟超时」改为一口气回 400
- **注入与配置**：选型导入扩展名白名单（堵目录内写 .html 的存储型 XSS）；`redis_url` 纳入敏感设置脱敏；模型详情缓存键加权限桶（受限变体元数据不跨用户泄漏）；temp-previews 静态访问无条件要求登录
- **图纸/下载令牌**：图纸两下载端点与 drawing/model-token 全部补发布状态校验（ADMIN 豁免，全站口径一致）

## 前端修复

- **登录会话恢复崩溃**：useAuthStore 与 client.ts 循环依赖，入口先加载 client.ts 时会话恢复同步引用未初始化模块直接 TDZ 抛错，被当成网络错误走「乐观保活」——已死的会话被当成仍登录。修复为微任务延迟恢复；已登录访问 /login 自动跳回来源页（仅登录模式），hydration 期间不再闪登录表单
- **批量下载 401 自愈**：批量 zip 下载用裸 fetch 不走 axios 拦截器，令牌过期后首下必失败需手动重试。补齐 401 → refresh → 重试一次
- **主题跟随系统**：「跟随系统」模式挂 matchMedia 监听，OS 切深浅色实时跟随（含旧 Safari 兼容）；修服务端默认主题设置的双段 set 回跳
