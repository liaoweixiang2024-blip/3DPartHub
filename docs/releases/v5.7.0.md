# v5.7.0

发布日期：2026-10-14

## 更新标题

3DPartHub v5.7.0 - 选型页全局型号搜索（跨全部选型产品搜型号/名称，下拉直达 + 查看全部结果列表 + 连续搜索回路）

## 更新描述

选型页新增全局型号搜索：在选型首页（大类落地页）和子分类页都可以按型号/名称搜索**全部选型产品**（本地约 1.96 万条），不再受"不知道产品在哪个分类就无从下手"的限制。PC 端工具栏提供与向导页同款搜索框，输入即出下拉结果（滚到底自动翻页），点结果直达该产品所属分类的选型向导并自动亮出产品卡；下拉底部"查看全部"进入全站搜索结果列表页——与向导搜索列表完全同款的卡片流，每张卡显示各自分类的参数列，卡片上的来源按钮（标签图标）可跳进该分类继续选型，浏览器返回还能回到搜索列表不丢进度。移动端为标题右侧搜索图标 + 标题下展开行形态。配套"清空即返回搜索"回路：从搜索直达向导后点 ✗ 清空直接回到搜索页接续搜下一个型号。后端复用 v2.8.0 既有的全站搜索接口（补充返回分类参数列，缓存 key 升 v2）。

## 新增功能

### 1. 全局型号搜索（下拉/内联）

- 入口：PC 大类/子分类页工具栏搜索框；移动端标题右侧搜索图标（点击在标题正下方展开一行，非弹窗）
- 跨全部选型产品搜型号/名称，隐藏产品/分类自动排除；IME 中文输入安全、300ms 防抖、请求竞态守卫
- 结果行：缩略图 + 型号 + 名称 + 所属分类徽章；点击直达该产品所属分类向导（型号自动预填，产品卡直接显示；跨大类直达时面包屑/分组正确）
- 下拉滚到底自动翻页（无"加载更多"按钮）；面板限高内部滚动，滚轮/触摸不穿透带动页面；底部"共 N 个结果 + 查看全部"常驻

### 2. 查看全部 → 全站搜索结果列表

- 下拉 footer"查看全部"进入列表态：与向导搜索列表完全同款卡片流（间距/卡片宽度逐项对齐），结果跨分类，每张卡渲染**自己分类的参数列**
- 列表态工具栏：左侧"搜索结果 · 共 N 个结果"（固定宽度槽位防跳动），顶部搜索框可改词即时刷新列表
- 卡片操作行的来源按钮（标签图标，悬停显示分类名）：点击进入该分类选型向导
- 浏览器返回恢复列表：进入列表/进入分类各占一个历史条目（**地址栏始终不变**），返回自动恢复搜索词与结果
- 列表卡可直接加入询价（询价车与向导共用）；列表态不写不删向导快照，进行中的选型不受影响

### 3. 清空即返回搜索（连续搜索回路）

- 从全局搜索直达向导、且还没动过任何选项时：向导搜索框点 ✗ 清空 = 回到搜索页（移动端自动展开搜索行、桌面自动聚焦），无缝搜下一个型号
- 已选过参数/跳过/手填后 ✗ 只清词；退格删空不返回（改词中间态不误伤）
