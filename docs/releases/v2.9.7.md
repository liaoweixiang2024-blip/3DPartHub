## 更新标题

3DPartHub v2.9.7 - 主题架构、询价流程与产品图库性能优化版

## 标签描述

3DPartHub v2.9.7 production release with isolated interface themes, refined inquiry and ticket workflows, improved product gallery image previews, expanded cache/storage settings, and refreshed Docker images.

## 更新描述

- 新增 Classic/Workbench 界面主题包隔离体系，主题目录、注册表、模板、样式作用域和开发规范补齐，便于后续像 CMS 主题一样扩展维护。
- 新主题首页、模型库侧栏、分类筛选、页头、模型卡片和页面宽度重新整理；旧主题保持原有自动加载与移动端体验。
- 询价流程补齐待询价清单、客户信息校验、销售分配、快捷回复、附件、导出和客户/管理员详情页布局。
- 工单和询价回复输入框、快捷词、附件上传、详情页标题和移动端底部输入体验统一。
- 系统设置新增缓存与云存储配置，覆盖 Redis、页面缓存、资源目录、访问策略、图片优化、腾讯云/阿里云等对象存储参数与连通性测试。
- 产品图库新增列表缩略图预览与详情原图渐进加载，降低大图解码、滚动和首屏渲染卡顿。
- 全站搜索框、后台刷新/批量操作、移动端导航隐藏策略、模型列表收藏按钮、分享预览和页面抖动问题持续优化。
- 主题 token、surface 色板、硬编码颜色扫描、打印主题常量和主题验证脚本补齐，减少新主题开发污染风险。
- 后端设置、询价、产品图库、缓存、静态资源和版本检查相关接口同步加固。
- 镜像已同步更新：api/web 均发布 v2.9.7 与 latest 标签。

Web image description: React/Vite frontend for 3D preview, product selection, inquiry/quote workflows, sharing, profile management, admin pages, interface themes, and smoother home browsing.

```bash
# Default deployment follows latest and uses Watchtower for api/web auto-updates.
# Run this when you want to update immediately:
cd /opt/3dparthub
curl -L -o docker-compose.yml https://raw.githubusercontent.com/liaoweixiang2024-blip/3DPartHub/main/docker-compose.yml
touch .env
grep -q '^IMAGE_TAG=' .env && sed -i 's/^IMAGE_TAG=.*/IMAGE_TAG=latest/' .env || echo 'IMAGE_TAG=latest' >> .env
docker compose pull
docker compose up -d --force-recreate

# Verify health
curl http://localhost:3780/api/health
```
