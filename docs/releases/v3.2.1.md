## 更新标题

3DPartHub v3.2.1 - 通知邮件与生产体验增强版

## 标签描述

3DPartHub v3.2.1 production release with clickable precision notifications, action-link email templates, backup reliability hardening, Safari/PWA fixes, secure temporary STEP previews, search/download-name improvements, and refreshed GHCR images.

## 更新描述

- 通知中心升级为可点击入口：询价、工单、模型、备份等通知会直接跳转到对应详情页或具体区块，不再只是提示文本。
- 邮件通知新增 `actionUrl` / `actionLabel`：邮件页头、按钮和底部入口会显示当前业务的真实入口链接；旧模板会自动升级首页链接为动作入口，后台模板预览和测试邮件同步使用当前访问域名。
- 区分用户与管理员通知策略：管理员保留站内通知，避免询价、工单、备份体检、收藏、下载、模型转换等业务邮件轰炸；普通用户继续按个人偏好接收站内和邮件通知。
- 备份链路继续加固：修复生产环境创建整站备份可能出现 `_backup_db` 缺失的 tar 错误，优化备份记录、删除提示、体检说明、真实资产统计和模块备份展示。
- 临时 STEP 看图功能完善：支持拖拽上传、最多 5 条有效临时记录、50MB 上传限制、自动清理、删除源文件和预览文件，并移除未可靠支持的 XT 描述与入口。
- 移动端和 Safari/PWA 体验修复：模型下载、PDF 图纸、注册弹窗、临时看图、图库浏览等场景减少卡死、遮挡和无法退出的问题。
- 图库和模型详情页性能与布局优化：移动端图库减少卡顿，模型详情页窄屏工具栏显示更稳定。
- 登录与账号安全修复：记住登录生效、首次强制改密不再重复弹窗，普通注册用户不会误触发改密要求，注册图形验证码完整显示 6 位。
- 搜索和下载名称优化：模型下载保留正确文件名，搜索支持 1/8、1_8、1分、大小写和 `* / x / X / 叉` 等常见输入别名。
- 邮件设置体验优化：联系邮箱合并到邮件配置，测试邮件按当前选中模板发送，邮件模板标题/描述减少重复。
- Docker 和本地启动体验继续收敛：本地启动脚本减少误连数据库风险，部署说明和版本示例更新到 v3.2.1。
- 发布前验证包含前后端类型检查、后端 120 项测试、前端生产构建、部署工具校验、Git 空白检查和企业验收聚合校验。
- 镜像已同步更新：api/web 均发布 v3.2.1 与 latest 标签。

```bash
# 默认部署跟随 latest，并由 Watchtower 自动更新 api/web 镜像。
# 需要立即更新时执行：
cd /opt/3dparthub
curl -L -o docker-compose.yml https://raw.githubusercontent.com/liaoweixiang2024-blip/3DPartHub/main/docker-compose.yml
touch .env
grep -q '^IMAGE_TAG=' .env && sed -i 's/^IMAGE_TAG=.*/IMAGE_TAG=latest/' .env || echo 'IMAGE_TAG=latest' >> .env
docker-compose pull
docker-compose up -d --force-recreate

# 快速健康检查
curl http://localhost:3780/api/health

# 只读部署自检并生成报告
curl -fsSL -O https://raw.githubusercontent.com/liaoweixiang2024-blip/3DPartHub/main/scripts/deploy-health-check.sh
sh deploy-health-check.sh --report deploy-health-report.txt --json deploy-health-report.json

# 采集脱敏证据包用于支持和最终验收
curl -fsSL -O https://raw.githubusercontent.com/liaoweixiang2024-blip/3DPartHub/main/scripts/collect-deploy-evidence.sh
sh collect-deploy-evidence.sh
```

把 `deploy-evidence-*.tar.gz` 和同名 `.sha256` 回传到仓库后可执行：

```bash
npm run deploy:acceptance -- deploy-evidence-YYYYMMDD-HHMMSS.tar.gz
npm run deploy:report:verify -- deploy-evidence-YYYYMMDD-HHMMSS.tar.gz --max-age-hours 24 --summary deploy-health-acceptance.md --summary-json deploy-health-acceptance.json
```
