# v5.9.0

发布日期：2026-10-17

## 更新标题

3DPartHub v5.9.0 - 全站国际化补账（后台管理全量翻译：六语言 × 2861 条新文案）+ 日语等长词下首页按钮文字挤压修复

## 更新描述

用户切换语言后后台页面仍是中文——排查发现约 3000 条 UI 文案硬编码在 70 个源码文件里（系统设置页一个文件就近千条），从未接入 i18n；同时日/韩/德语言包的后台导航标签是当年的中文占位。本版一次性补齐：全部硬编码中文抽入语言包并翻译成英/日/韩/德四语（繁中自动转换），后台各管理页、设置页、诊断面板、螺纹工具等全部按当前语言渲染。另修复日语「ダウンロード」等长词在首页模型卡按钮里被固定高度压扁折行的问题。

## 新增功能

### 1. 后台管理界面全量国际化（2861 条新文案 × 5 语言）

- 覆盖页面：系统设置（1017 条）、选型管理（450）、模型管理（228）+ 模型管理组件（243）、用户管理（121）、审计日志（143）、下载统计（66）、询价/分享/工单后台、分类/图库/导航管理、上传弹窗、转换队列与预览诊断面板、螺纹规格工具等 60+ 文件
- 语言包新增 27 个命名空间；日/韩/德覆盖包各注入 2861 条翻译（此前新键会回退英文）
- 修复合并欠账：日/韩/德包的 nav.admin 后台菜单标签是中文占位 → 补齐三语翻译；「图片管理/导航管理/邀请管理」三个新菜单项未登记翻译白名单 → 登记
- 修复 en-US 存量缺口（如 nav.admin.productWall）——这类缺口的回退方向是中文，正是"切英文还见中文"的另一处病灶

### 2. 首页按钮长词挤压修复（日语/德语可见）

- 模型卡「下载/预览」按钮固定高 h-7 → min-h-7 + 单行强制（whitespace-nowrap）：文字永远单行、不再被垂直压扁
- 操作行放不下并排时上下堆叠各占整行（实测 11px 字号下日语并排需 ~199px，5 列网格卡片行仅 173–190px，缩字号无解）；中文布局完全不变

## 修复清单

- **后台页面切换语言不变**：~2900 条硬编码中文全部抽入 i18n 语言包
- **日语下首页下载/预览按钮文字上下挤压**：见上
- **数据驱动标签**（角色名、审计操作名、队列状态、诊断筛选等 26 项枚举 map）改为「存 key、渲染时翻译」模式，未知值回退原始字符串
- 询价导出 Excel 表头、客户端状态视图、路由加载标题卡、主题显示名等 lib 层文案全部接入 i18n（运行时惰性求值，语言切换即时生效）

## 有意保留的中文（非缺陷）

- **法律文档正文**（用户协议/隐私声明）：法律文本保持仅中文版
- **服务端数据**：站点名、分类名、产品名、用户名、ICP 备案号、管理员可自定义的询价/工单状态标签——这些是数据库/配置数据，非界面文案
- **数据契约**：选型 Excel 导入/导出模板的中文表头（下载模板→填写→上传的往返解析键，翻译会破坏匹配）；螺纹规格表的中文搜索别名与正则（用于解析中文查询）
- 注释保持中文（代码规范）

- client `npm run verify` 全绿（33 测试，0 lint 错误）；server 全绿（193 测试）；仓库根 `verify:deploy` 通过；vite build 通过
- 键完整性脚本：源码引用的 3596 个翻译键在 zh-CN 与 en-US 全部齐备、零缺失

  - zh-CN：15 个页面无裸键（此前设置页主/次标签与分区标题渲染过裸键，已修）
