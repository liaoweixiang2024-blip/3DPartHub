## 更新标题

3DPartHub v3.0.0 - 稳定性、上传下载与备份恢复增强版

## 标签描述

3DPartHub v3.0.0 production release with hardened model upload/download flows, safer backup and restore handling, reduced 502 risk under pressure, stronger release checks, and refreshed Docker images.

## 更新描述

- 模型上传增加已上传/总大小与实时速度显示，并节流进度渲染，减少大文件上传时的前端卡顿。
- 分片上传改为流式计数字节，避免请求体被重复监听；默认模型上传上限提升到 500MB，与 Nginx 和业务设置保持一致。
- 模型转换缩略图生成增加 JPEG/PNG 双格式兜底，修复 canvas 编码返回空数据导致转换任务失败的问题。
- 下载文件名保留型号里的斜杠分数，上传记录不再把 `SCFM-1/2.step` 截断成 `2.step`，下载时会安全保存为 `SCFM-1_2.step`。
- 批量下载继续统一历史与收藏接口，补齐旧版 `/api/downloads/batch-download/check` 兼容入口，并确保 STEP 打包不混入多余 `.bin` 文件。
- 备份下载改用 Nginx X-Accel 接管大文件传输，减少 API 长连接占用和大备份下载引发的 502 风险。
- 备份导入保存优先移动归档文件，跨磁盘才复制，避免大备份在同一磁盘上重复占用一倍空间。
- 备份恢复前磁盘空间保护继续生效，空间不足时会中止并给出所需容量，避免破坏现有数据。
- API worker 内存回收后会自动重启，不再因为 SIGTERM 回收导致 worker 数量减少、服务变 502。
- 发布前验证补齐主题、加载、UX、维护扫描、类型检查、单测和构建检查。
- 镜像已同步更新：api/web 均发布 v3.0.0 与 latest 标签。

```bash
# Default deployment follows latest and uses Watchtower for api/web auto-updates.
# Run this when you want to update immediately:
cd /opt/3dparthub
curl -L -o docker-compose.yml https://raw.githubusercontent.com/liaoweixiang2024-blip/3DPartHub/main/docker-compose.yml
touch .env
grep -q '^IMAGE_TAG=' .env && sed -i 's/^IMAGE_TAG=.*/IMAGE_TAG=latest/' .env || echo 'IMAGE_TAG=latest' >> .env
docker compose pull
docker compose up -d --force-recreate

# Verify health
curl http://localhost:3780/api/health
```
