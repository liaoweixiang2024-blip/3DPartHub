# v5.8.1

发布日期：2026-10-15

## 更新标题

3DPartHub v5.8.1 - 全站搜索列表画册按钮 + 移动端整页搜索底栏（询价条同款）+ ✗清空返回来源还原 + 空态/加载体验修复

## 更新描述

v5.8.0 全局搜索的一轮打磨修复：全站搜索列表现在**显示画册按钮**（与向导结果页同规则：选项级画册 → 分类自带 → 按接头形态共享兜底，每个产品按自己所属分类解析）；移动端整页搜索的底部操作条改为**与询价条同款的页面级固定条**（计数 + 查看全部 + 关闭搜索，按钮轻量无底色、翻页转圈不带动布局）；向导 ✗ 清空返回时**还原到发起搜索的页面**（首页或原大类，不再停在产品的大类）；「查看全部」进入列表不再先闪一帧「没有匹配的产品」；列表空态上下居中；移动端键盘弹出时自动隐藏「已选 X 项」条。

## 新增功能

### 1. 全站搜索列表画册按钮

- 每张结果卡按产品**自己所属分类**解析画册：选项级 optionCatalogs 命中 → 分类自带 catalogPdf → 按接头形态共享兜底（与筛选接口同规则）
- 未配置画册的分类不显示按钮（条件渲染与向导结果页一致）
- 搜索接口缓存 key 升 v3（旧 TTL 缓存无 categoryCatalogPdf 字段，一次性刷新）；解析用字段不进响应 payload

### 2. 移动端整页搜索底部操作条

- 页面级固定条，与询价条同款（bg-surface-container-high + 上边线 + 向上投影，底部导航/安全区/软键盘自动让位）
- 布局：计数居左（翻页小转圈只出现在计数区，右侧按钮逐像素不动）+「查看全部」（主题色文字）+「关闭搜索」（幽灵样式）居右
- 滚动容器隐藏右侧滚动条

## 修复清单

- **✗ 清空返回来源还原**：全局搜索跨大类直达后 ✗ 清空，返回发起搜索时的页面（首页/原大类子页）——此前 groupId 停在产品所属大类，标题分类不对
- **「查看全部」空态闪帧**：进入列表先闪一帧「没有匹配的产品」再转圈——hook 新增 settled 标记，防抖等待期与 query 提交间隙均按加载态渲染
- **列表空态居中**：「没有匹配的产品」在可视区域内上下居中（原贴顶偏上）
- **键盘弹出已选条跳动**：向导结果页点搜索框弹键盘时，「已选 X 项」条聚焦即隐藏、失焦恢复（原跟随吸顶头跳到输入法上方）
- 移动端搜索结果行去掉 `:active` 缩放（滑动起手不再「跳动」）；桌面下拉底栏移出滚动区（iOS 回弹不拽动、无漏行）

## 后端变更

- `GET /api/selections/search`：补画册解析（选项级/分类自带/接头形态共享，逐产品按所属分类），items 增加 `categoryCatalogPdf`；缓存 key `v2` → `v3`
- 无数据库迁移（schema 未变更）
