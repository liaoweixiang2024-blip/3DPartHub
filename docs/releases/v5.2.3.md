# v5.2.3

发布日期：2026-09-28

## 更新标题

3DPartHub v5.2.3 - 移动端选型页两处视觉修复（冻结头矩形阴影移除 + 选项区宽度对齐）

## 标签描述

v5.2.3 ships two mobile selection-page visual fixes. The sticky header (frozen title + stats + search toolbar) carried an always-on shadow that, in light mode, outlined the whole block as a rectangle flush against the cards — dark mode hid the black shadow, which is why only light-mode users reported it; the shadow is now removed entirely (the header keeps its page-colored backdrop that masks content scrolling beneath, just with no outline). The wizard option area was inset 16px by a padding layer meant for the desktop scroll panel; on mobile the selection content panel is transparent so that padding just made the option step cards narrower than the title card above — mobile now strips it (desktop keeps md:px-5), so the step cards and in-wizard search results align edge-to-edge with the title card and the category cards. No database migrations.

## 更新描述

本次为 **移动端选型页视觉修复** 版本，无数据库迁移，需同时更新两端镜像。

## 冻结头矩形阴影移除

### 问题

移动端选型页的整块冻结头（标题卡 + 统计区块 + 搜索工具栏，吸顶常驻）带一个无条件渲染的投影：阴影沿容器四边画出轮廓——上贴标题卡顶、左右贴卡片边、下贴区块底部，看起来像一个矩形把标题和选项区整体框住，非常突兀。深色模式下黑色投影落在深底上不可见，所以只在浅色模式被反馈。

### 修复

- 彻底移除冻结头的 `shadow-sm` 投影：静止、滚动中、滚回顶部任何状态都不再有矩形描边
- 冻结头保留与页面同色的遮罩背景（滚动时内容从头下穿过被正确盖住），只去掉描边
- 同步惠及所有使用整块冻结头的页面（选型页、螺纹工具页）

## 选型选项区宽度对齐

### 问题

向导阶段（参数选型）的选项步骤卡比上方的标题卡左右各缩进 16px，与首页大类阶段的分类卡片宽度也不一致——原因是向导内容沿用了桌面滚动面板的内容内边距，而移动端选型页的内容面板是透明的，这层内边距没有视觉来源，只造成无来由的缩进。

### 修复

- 移动端：去掉向导步骤区与搜索结果区的水平内边距，选项步骤卡、结果卡与标题卡、大类卡片同宽对齐（左缘 17px = 17px = 17px）
- 桌面端：保留 `md:px-5` 面板内边距，布局不变

## 升级说明

- 服务器更新：`docker-compose pull && docker-compose up -d`，浏览器强制刷新（Cmd/Ctrl+Shift+R）
