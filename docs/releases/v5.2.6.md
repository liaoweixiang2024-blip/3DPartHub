# v5.2.6

## 更新标题

3DPartHub v5.2.6 - 画册放大弹窗修复与缩放升级（真全屏置顶+滚轮缩放拖拽平移）+ 画册 PDF 上限 20M→50M 可配置

## 标签描述

v5.2.6 overhauls the selection catalog zoom modal and raises the catalog PDF upload limit. First, the zoom modal no longer renders trapped inside the page: the result cards live inside a transform-gpu animated container, which becomes the containing block for fixed descendants — so the "fixed" modal was pinned to the content box, clipped by the scroll container and obscured by overlapping content. The modal now portals to document.body (the same pattern as the password dialog), making it a true fullscreen overlay at any scroll position. Second, image catalogs gain a full zoom/pan toolkit: mouse-wheel zoom anchored at the cursor (100%–800%), drag-to-pan with grab/grabbing cursor and boundary clamping, two-finger pinch on touch devices, double-click to toggle reset/2.5× zoom, header controls (zoom out / live percentage / zoom in / fit) and keyboard shortcuts (+/−/0/Esc). Third, the modal itself is much larger: width cap 1024→1280px with height filling the viewport minus overlay padding. Finally, the catalog/spec PDF upload limit (previously a hardcoded 20MB on the product-asset endpoint) becomes a configurable uploadPolicy field `selectionPdfMaxSizeMb` (default 50MB, adjustable 1–200 in admin system settings), and upload-failure toasts now surface the server's reason (e.g. "文件不能超过 50MB") instead of a generic "上传失败". Verified end-to-end: 30MB PDF uploads successfully, 60MB is rejected with a clear message and the previously uploaded file is retained. No database migrations.

## 画册放大弹窗修复与缩放升级

### 问题

- 弹窗「长在页面里」：放大弹窗写在结果卡片内部，而选型页内容区包在常驻 `transform-gpu` 的动画容器里——transform 祖先会成为 fixed 后代的包含块，弹窗被钉进页面内容、受滚动容器裁剪遮挡
- 无缩放交互：图片放大后只能看，不能滚轮缩放/拖拽移动
- 弹窗偏小（宽上限 1024px、高度随内容自适应）

### 修复

- **portal 到 document.body**（与改密码弹窗同一模式）：彻底脱离变换容器与滚动裁剪，真全屏置顶，实测任意滚动位置下弹窗恒为整视口 (0,0,VW,VH)
- **图片缩放/平移全家桶**（新组件 `CatalogZoomModal`）：
  - 滚轮缩放朝光标位置（光标指哪放大哪），100%–800%
  - 放大后拖拽平移，抓手光标（grab/按住 grabbing），边界钳制不拖飞
  - 手机双指捏合缩放（朝两指中点）
  - 双击：已放大→复位；未放大→2.5× 定点放大
  - 头部按钮组：缩小 / 实时百分比 / 放大 / 适应窗口复位（回 100% 自动归零回中）
  - 键盘：`+` `−` 缩放、`0` 复位、`Esc` 关闭
- **弹窗加大**：宽上限 1024→1280px，高度贴满视口（1440 屏实测卡片 1280×852）
- PDF 模式不加自绘缩放（浏览器自带查看器有自己的缩放），按钮组仅图片模式出现

## 画册/规格书 PDF 上传上限放宽

### 问题

选项设置里的画册 PDF 上传超过约 20MB 失败——服务端 `product-asset` 端点写死 20MB 常量。

### 修复

- 上限改为配置项 `selectionPdfMaxSizeMb`：**默认 50MB**，管理端「系统设置 → 上传策略」新增「画册/规格书 PDF 上限 MB」可调（1–200）
- 上传失败提示从笼统「上传失败」改为带服务端原因（如「文件不能超过 50MB」），选项画册/选项图片/粘贴/拖拽各路径统一
- 实测：30MB ✅ 成功；60MB ✅ 拒绝且旧文件保留（弹窗内原文件不受失败影响）

## 升级说明

- 无数据库迁移（schema 未变更）
- 服务器更新：`docker-compose pull && docker-compose up -d`；强刷后在选型结果页点「放大查看」验证：弹窗应全屏置顶、滚轮可缩放、按住可拖动、头部有缩放按钮组；上传大于 20MB 的画册 PDF 应可成功
