# v5.4.1

发布日期：2026-10-07

## 更新标题

3DPartHub v5.4.1 - PC 选型页已选选项条横向滚动补全：鼠标滚轮纵向转横向 + 按住拖动平移（拖动松手不误触掉选）

## 更新描述

本次为**选型页工具栏交互补全**版本，接 v5.4.0 用户反馈（挤压修好了但选项条滚不动）。无数据库迁移（schema 未变更），只涉及前端，更新 web 镜像即可（api 镜像例行同步）。

## 背景

v5.3.9 把工具栏右侧控件（搜索框/生成链接/全部分类）锁定自然宽度后，左侧已选选项 chips 收进横向滚动条。但条本身「能滚却没人滚得动」：

- 鼠标滚轮只有纵向分量，对横向滚动条无效
- 原生 overflow 容器不支持鼠标按住拖动
- 滚动条被 `scrollbar-none` 隐藏，没有任何可见入口

三条叠加，用户看到的就是「选项固定住了，不能横向滚动」。

## 改动

- **滚轮转换**：鼠标悬停在选项条上滚动时，纵向滚轮转为横向滚动（非被动监听 + preventDefault，悬停区域页面不跟滚）；触控板原生横向滑动（deltaX）不劫持；条未溢出时不劫持，普通滚动行为不变
- **拖动平移**：鼠标左键按住选项条左右拖动即可平移；拖动超过 5px 阈值后松手**不触发 chip 点击**（防止拖动变成掉选重选），拖动期间禁用文本选中
- 仅桌面端生效（移动端该条隐藏，选中摘要走触屏原生横滑）

## 验证

- client `npm run verify` 33 项全绿；无迁移（schema 未变更）
- 滚轮：900px 宽选 5 项，悬停条上滚 3 格 → scrollLeft 精确 360，页面滚动位置不动
- 拖动：按住第一颗 chip 左拖 200px → scrollLeft 0→200，chips 数量不变（无误掉选）；拖后正常单击 chip 仍可掉选
- 回归：条未溢出（宽屏）时滚轮/点击行为与之前完全一致

## 升级说明

- 无数据库迁移（schema 未变更）
- 服务器更新：`cd /opt/3dparthub && docker-compose pull && docker-compose up -d`，浏览器强刷（Cmd+Shift+R / Ctrl+Shift+R）
- 验证：PC 选型选多项后，工具栏选项条上滚滚轮 / 按住拖动都能左右查看已选内容
