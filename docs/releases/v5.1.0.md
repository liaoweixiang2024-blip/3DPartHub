## 更新标题

3DPartHub v5.1.0 - 选型隐藏开关（分类/产品级）+ 子零件清单表格导入 + 手填列数值校验 + 选型管理与全站移动端布局修复

## 标签描述

v5.1.0 adds hidden toggles to the selection system: admins can now hide any selection category or individual product with an eye icon (hidden items show a badge and dimmed row, are excluded from the public selection page / search / filter / detail / share links, and can be restored anytime — the public endpoints are no-store so a restored category is visible immediately instead of replaying a stale browser cache). The parts-kit (子零件) list in the product editor gains spreadsheet import (.xlsx / .csv) with a downloadable Excel template. Manual-fill selection columns (like hose length/M) can now be constrained to numbers-only: a new "填写内容" setting per column strips non-numeric input live, blocks incomplete values like "1." with a friendly error, and opens the numeric keypad on mobile (5 languages). Layout fixes: the selection admin page no longer double-scrolls (only the inner list scrolls, bottom fully reachable), its title+toolbar stick on mobile, the cover-image block and the column-table headers now align with their controls, and the product list auto-loads more rows with a zero-height trigger instead of a permanent "继续滚动自动加载" strip. Site-wide, a pb-safe-nav utility fixes the last ~10px of mobile content being hidden behind the bottom navigation (iPhone safe-area). Includes one additive database migration (hidden boolean fields on selection categories and products); existing data untouched.

## 更新描述

本次为 **选型系统增强 + 布局修复** 双主题，含一个纯新增数据库迁移，需同时更新两端镜像。

**① 选型分类/产品隐藏开关**（方便先配置好再上线参与选型）

- 选型管理：分类行与产品行的「眼睛」按钮一键隐藏/恢复，隐藏项显示「隐藏」徽标、行置灰；管理端凭管理员身份独立拉取全量（含隐藏），公开页缓存不受污染
- 公开链路全过滤：选型首页/分组、搜索、筛选、分类详情、分享链接（打开即 404「分享不存在」）均不出现隐藏项；隐藏分类下的产品连带不出现
- 修复两处根因：产品 payload 白名单漏传 `hidden`（管理端永远显示未隐藏态）；分类列表 `Cache-Control: max-age=120` 导致恢复后 2 分钟内浏览器回放旧列表 —— 选型公开端点全部改 `no-store`，服务端 Redis 缓存照旧写时失效
- 迁移 `add_selection_hidden`：两张表各加一个布尔字段，默认 false，不动现有数据

**② 子零件清单批量导入（表格文件）**

- 产品编辑弹窗的子零件清单支持 .xlsx / .csv 导入（5MB 上限），自动识别表头（名称/型号/编码/数量，兼容旧三列格式）
- 一键下载 Excel 导入模板（含示例行），填好再导回即可

**③ 手动填写列「仅数字」校验**

- 编辑分类 → 参数列 → 更多：新增「填写内容」（任意文字 / 仅数字，可小数），已将「高压油管总成 → 长度/M」预设为仅数字
- 公开选型页：非数字字符即时丢弃（多个小数点只留第一个）、不完整值（如 `1.`）拦截提交并红字提示、手机弹数字键盘；提示文案中/英/日/韩/德五语言

**④ 布局与对齐修复**

- 选型管理页：整页不再滚动，仅内部分类/产品列表自滚，滚动到底完整可达；移动端标题+工具栏整块吸顶
- 编辑分类弹窗：封面图区块的输入框与左侧「图标名称」精确水平对齐（提示文字统一挪到输入框下方）
- 参数列定义表：表头文字按下方控件内边距内缩，与输入框文字逐列对齐
- 产品列表「继续滚动自动加载」占位条改为零高度触发器（桌面藏在滚动容器内、移动贴列表尾，滚动到底自动续载）
- 全站移动端：新增 `pb-safe-nav`，修复底部导航（含 iPhone 安全区）遮挡最后约 10px 内容的问题（首页/管理壳层）
