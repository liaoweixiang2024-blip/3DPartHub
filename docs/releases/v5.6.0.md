# v5.6.0

发布日期：2026-10-13

## 更新标题

3DPartHub v5.6.0 - 选型反查弹窗产品管理升级（行内编辑单个产品、操作列右缘固定、选项卡片实时刷新、去重复型号列、同型号重复拦截）+ 选型页选项图片圆角修复

## 更新描述

选型系统两项管理体验 + 一项用户侧视觉修复：① 「选项设置 → N 型」反查弹窗继续升级——每行新增 ✎ 编辑（行内改型号/名称/参数，可把产品挪到别的选项值下）、操作列固定在弹窗右缘（宽表横向滚动时 ✓/编辑按钮始终可见）、参数列不再重复出现第二列「型号」、新增/编辑时拦截同分类重复型号（草稿默认带首行数据，未修改直接确认不再产生重复产品）；② 选项卡片列表实时跟随产品数据——在反查弹窗里批量修改/新增/删除产品后，选项值卡片与角标计数即时增删，不再需要退出选项设置重新进入；③ 选型页（用户侧）带图选项卡悬停/选中时，白色图片底不再盖住边框的左上/右上圆角。全部为前端改动，无数据库迁移。

## 修复清单

### 1. 反查弹窗：单行编辑（新功能）

- 每行行尾新增 ✎ 按钮：该行变行内编辑（型号/名称/全部参数列输入框，预填当前值）
- 当前选项值列也可改——改完保存产品即移动到对应选项值下（反查弹窗与选项卡片实时联动）
- 回车或 ✓ 保存、Esc 或 ✗ 取消；与底部「新增产品」草稿互斥（同时只开一个行内编辑）
- 保存时 `specs['型号']` 与型号编号自动同步镜像

### 2. 反查弹窗：操作列 sticky 右侧固定（修复）

- **现象**：参数列多的分类里，表格横向超宽，「新增产品」草稿行的 ✓/✗ 按钮在最右列——不横向滚动根本看不到
- **修复**：操作列（编辑/确认/取消）固定在弹窗右缘，横向滚动时始终可见（实测滚动后按钮位置不变）；表头同步增加「操作」列

### 3. 选项卡片实时刷新（修复）

- **现象**：在反查弹窗里批量修改了产品的选项值/新增/删除产品后，「选项设置」里的选项值卡片不更新（新值不出现、旧值计数不变），必须退出选项设置重新进入
- **修复**：卡片列表增量跟随产品数据——新出现的值追加卡片、无产品使用的值移除、角标计数即时变化；保留未保存的手动排序不受影响

### 4. 反查弹窗两列「型号」（修复）

- **现象**：表格出现两列「型号」
- **根因**：`specs['型号']` 是型号编号的镜像列（批量导入会写入），被当作普通参数列重复渲染
- **修复**：参数列跳过镜像键（与导出、批量修改下拉同规则），型号统一由专用列展示；新增/编辑保存时镜像自动同步

### 5. 同型号重复拦截（新功能）

- 草稿默认带首行数据，此前不改任何内容直接确认会创建出与现有产品同型号的重复产品
- 新增时型号撞上分类内已有产品 → 拦截并提示「型号已存在，请修改型号后再新增」
- 行内编辑把型号改成其他产品的型号 → 同样拦截

### 6. 选型页选项图片圆角（修复）

- **现象**：带图选项卡悬停/选中出现彩色边框时，图片白底的左上/右上角盖住边框圆角，看着边框缺了一小块
- **修复**：卡片外层 `overflow-hidden` 把白色图片底裁进 12px 圆角内，边框圆角完整
