# v6.1.3

发布日期：2026-11-07

## 更新标题

3DPartHub v6.1.3 - 修复安卓/鸿蒙等手机浏览器（华为等）下载模型显示「下载失败」的问题（下载令牌改为时效内可复用，同时惠及 PC 端中断续传/下载工具/重开链接场景）；旧内核浏览器报错页改为「浏览器版本过低」升级指引

## 更新描述

两处改动：

1. **修复国产手机浏览器模型下载失败**：此前模型下载令牌是「一次性」的——浏览器第一次请求就把令牌销毁。华为/鸿蒙（HMSCore）等手机的系统下载管理器对同一下载链接会发起**第二次请求**（重拉或断点续传），撞上已销毁的令牌返回 401，下载列表即显示「下载失败」（服务端日志仍是 200，因为第一次请求已成功打点）——表现为「模型下不了、只能下 PDF 图纸」（图纸令牌本就是可复用的）。本次将模型下载令牌改为**时效内（默认 5 分钟）可多次校验**，与图纸/备份令牌同款语义（备份下载当年因迅雷/IDM 分段下载已改过一次，模型通道本次补齐）。配套两项保障：**下载打点去重**——同一令牌的多次请求只计 1 次下载量、只通知模型作者 1 次（原子标记文件，华为二次请求不会导致计数翻倍）；**每日限额拒绝时归还标记**——防止「首请求被限额 429、重试请求因已打点跳过限额检查」的绕过。该修复同时惠及：小米/OPPO/vivo 等系统浏览器与国产浏览器下载内核、PC 端下载中断后的续传重试（Range 206 正常续传而非失败重下）、迅雷/IDM 等下载工具接管链接、用户复制下载链接在新标签页重开（时效内有效）。

2. **旧内核浏览器友好提示**：此前极旧内核的浏览器（Chrome/Edge < 94、Safari/iOS < 16.4，如旧国产浏览器兼容模式、多年未升级的 macOS Safari）打开 3D 视图时会因 three.js 的 class static block 新语法抛 `Unexpected token '{'`，错误页直接裸显这行英文天书。现在错误边界（ErrorBoundary）识别此类语法解析错误，改显示「浏览器版本过低」及升级建议（Chrome / Edge 111+，iOS 16.4+ 或新版 Safari），用户至少知道该怎么办；其他错误的提示不变。

## 变更清单

- `server/src/lib/downloadTokenStore.ts`：移除一次性 `consumeModelDownloadToken`；新增 `claimModelDownloadRecordMark` / `releaseModelDownloadRecordMark`（wx 原子标记文件，与令牌同 TTL，清理任务回收）
- `server/src/routes/models/download.ts`：GET/HEAD 统一走 `verifyModelDownloadToken`（TTL 内可复用）；打点块加同令牌去重；每日限额 429 时归还打点标记；失效提示文案去掉「一次性」措辞
- `server/src/lib/downloadTokenStore.test.ts`：模型令牌改为「TTL 内可复用」「标记一次认领/可归还」新语义测试（7 个用例）
- `client/src/components/shared/ErrorBoundary.tsx`：识别 SyntaxError / "Unexpected token" 类解析错误 → 「浏览器版本过低」专属提示（devices 图标 + 升级建议）
- `client/src/i18n/locales/zh-CN.ts` / `en-US.ts`：`errorBoundary.outdatedTitle` / `outdatedDescription` 两个 key

## 审计确认

- 无新增出网请求、无配置变更
