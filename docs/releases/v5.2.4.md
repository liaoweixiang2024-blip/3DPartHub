# v5.2.4

发布日期：2026-09-29

## 更新标题

3DPartHub v5.2.4 - 移动端选型页冻结头零位移（标题/搜索框从滚动第一像素起完全固定）

## 标签描述

v5.2.4 makes the mobile selection page's frozen header truly motionless. Previously the sticky block (title card + stats + search toolbar) sat 16px below the top of the scroll area at rest, so the first scroll gesture shifted the whole header up by 16px before it locked — the title and search box visibly "scrolled" for a moment. The breathing space now lives inside the sticky block (pt-4) while the page wrapper drops its top padding (pt-0), making the rest position equal to the stuck position: from the very first pixel of scrolling the header never moves, and only the category cards and wizard options scroll beneath its page-colored mask. Verified frame-by-frame: header/title/toolbar tops stay constant at every scroll offset and through the entrance animations, phase transitions, option selection, and search typing — the phase entrance animation only transforms the content subtree and cannot reach the header. Rest-state layout is pixel-identical to v5.2.3. No database migrations.

## 更新描述

本次为 **移动端选型页交互修复** 版本，无数据库迁移，需同时更新两端镜像。

## 冻结头零位移

### 问题

移动端选型页的整块冻结头（标题卡 + 统计/搜索工具栏）静止时悬在滚动区域顶部下方 16px 处（外层包装默认 `py-4` 的顶部内边距所致）：开始滚动的瞬间，整块标题+搜索框会先上移 16px、碰到顶才冻结——用户看到「标题在滚动」。

### 修复

- 16px 呼吸间距挪进冻结头块内部（`pt-4`），滚动容器包装层同步去掉顶部内边距（`pt-0`），使**静止位 = 吸顶位**
- 从滚动第一个像素起标题卡、统计、搜索工具栏零位移，只有大类卡片与选项内容滚动（内容从冻结头底部的同色遮罩下穿过）
- 静止状态布局与 v5.2.3 像素级一致（标题卡位置不变）

### 验证

- 滚动 5px / 50px / 滚到底、进大类、返回首页：标题/工具栏 top 全程恒定，位移 0.0px
- 逐帧采样入场动画全程（117 帧）：动画在内容区跑（分类卡 251→241 弹簧），冻结头一帧未动
- 冻结头内部要素（标题 h1/描述/工具栏/搜索框）位置全程恒定；标题区无任何动画/过渡（计算样式实锤 animation: none、transition: 0s）

## 升级说明

- 无数据库迁移（schema 未变更）
- 服务器更新：`docker-compose pull && docker-compose up -d`，手机浏览器强制刷新后到选型页滚动验证：标题与搜索框全程纹丝不动
