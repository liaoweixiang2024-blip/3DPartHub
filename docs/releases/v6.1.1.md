# v6.1.1

发布日期：2026-10-29

## 更新标题

3DPartHub v6.1.1 - 选型向导搜索结果页补上分类标签按钮：从全局搜索点结果落地（或向导内搜索）的结果卡片右上角现在也有「进入该分类选型向导」的标签按钮，点击按产品自身参数把选项一次选满、直达该分类向导结果页——与「查看全部」全站搜索列表的标签行为完全一致

## 更新描述

上一版全站搜索「查看全部」列表的产品卡上有分类标签按钮（点击按产品参数选满直达该分类向导结果页），但从搜索结果落地的向导搜索结果页没接这个按钮——两个页面长得一样、行为却不一致。本版补齐：向导搜索结果页（全局搜索下拉点某条结果落地、或向导内搜索框搜词两个入口共用同一渲染块）的每张产品卡右上角现在同样显示分类标签按钮。因该页面人已在所属分类的向导内，点击走专用落地逻辑：按产品参数换算 specs/skipped 直接落结果页（不重走分类切换），搜索词一并清空退出搜索视图，产品参数全空时退回向导第一步，落地时滚动归零。

## 变更清单

- 向导搜索结果列表的 ResultCard 接上 `categoryName` / `onCategoryClick`（source 图标小按钮，悬停显示分类名）
- 新增 `wizardTagGoCategory` 处理器：与「查看全部」列表的 `goToListCategory` 同款「参数选满直达结果页」语义，适配「已在向导内、slug 不变」的场景（preset effect 依赖 slug 不会重跑，须直接换算落地）
- ResultCard 注释同步更新（原「向导内不渲染」设计说明已过时）
