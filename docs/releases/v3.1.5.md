## 更新标题

3DPartHub v3.1.5 - Docker 部署兼容修复版

## 标签描述

3DPartHub v3.1.5 hotfix release for Docker deployment compatibility, restoring legacy one-click compose defaults while keeping production security warnings visible.

## 更新描述

- 修复 v3.1.4 升级后旧 Docker 一键部署环境可能导致 `3dparthub-api` unhealthy 的问题。
- 旧版默认 DB/JWT/Redis 密钥不再直接阻止 API 启动，改为启动日志安全提醒，避免升级时站点被打挂。
- `docker-compose.yml` 恢复一键部署兼容默认值；新部署仍建议通过 `.env` 设置随机 `DB_PASSWORD`、`REDIS_PASSWORD`、`JWT_SECRET` 和 `ADMIN_PASS`。
- README 增加 API unhealthy 排查说明，提醒已有 PostgreSQL volume 不会因修改 `.env` 自动变更数据库用户密码。
- 镜像已同步更新：api/web 均发布 v3.1.5 与 latest 标签。
