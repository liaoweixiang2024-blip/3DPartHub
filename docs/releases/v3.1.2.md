## 更新标题

3DPartHub v3.1.2 - 首页滚动与移动端浏览器外观优化版

## 标签描述

3DPartHub v3.1.2 production release with smoother home model-list scrolling, tighter desktop theme scroll alignment, cleaner empty-list behavior, synced mobile browser chrome colors, and refreshed Docker images.

## 更新描述

- 优化 PartHub 工作台与经典版首页模型列表滚动，移除影响滚轮手感的自定义插值，恢复浏览器原生滚动。
- 滚动模型列表时临时暂停悬浮按钮过渡，降低鼠标经过卡片时的重绘开销。
- 修复首页选择分类、切换排序和返回顶部时标题区块没有完全对齐的问题，减少顶部补位抖动。
- 优化无模型结果页的高度和加载触发器显示，避免空列表仍可继续滚动。
- 修复移动端 Safari/PWA 顶部浏览器区域颜色，跟随亮色/暗色主题与动态配色同步。
- 保持新旧主题首页列表底层数据和滚动逻辑一致，减少主题切换后的体验差异。
- 发布前验证通过前端类型检查、构建、格式检查与全量前端验证。
- 镜像已同步更新：api/web 均发布 v3.1.2 与 latest 标签。

Web image title: `3dparthub-web:v3.1.2`

Web image: `ghcr.io/liaoweixiang2024-blip/3dparthub-web:v3.1.2`

Web image description: React/Vite frontend for theme-driven model libraries, smoother desktop model-list scrolling, synchronized mobile browser chrome colors, unified theme shells, 3D viewing, product selection sharing, upload progress, batch downloads, product gallery browsing, inquiry/quote workflows, profile management, admin pages, legal pages, and responsive mobile flows.

```bash
# Default deployment follows latest and uses Watchtower for api/web auto-updates.
# Run this when you want to update immediately:
cd /opt/3dparthub
curl -L -o docker-compose.yml https://raw.githubusercontent.com/liaoweixiang2024-blip/3DPartHub/main/docker-compose.yml
touch .env
grep -q '^IMAGE_TAG=' .env && sed -i 's/^IMAGE_TAG=.*/IMAGE_TAG=latest/' .env || echo 'IMAGE_TAG=latest' >> .env
docker compose pull
docker compose up -d --force-recreate

# Verify health
curl http://localhost:3780/api/health
```
