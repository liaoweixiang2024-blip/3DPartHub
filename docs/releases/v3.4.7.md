## 更新标题

3DPartHub v3.4.7 - 首页页脚备案号 / PWA 安装入口 / 模型详情紧凑化

## 标签描述

3DPartHub v3.4.7 minor release. (1) 首页页脚支持 ICP 备案号与公安备案号：后台「设置 → 友情链接与版权 → 网站备案信息」填写后，前台页脚版权下方展示，留空不显示。ICP 号点击跳转工信部查询页（beian.miit.gov.cn），公安备案号自动从号码提取数字生成全国互联网安全管理平台查询链接（beian.gov.cn）。三套页脚（工作台 / 经典 / 共享）一致。无数据库迁移（settings 键值表，新键默认空）。(2) PWA 可安装：注册最小 Service Worker（不缓存、纯 network 透传），Chrome / Edge 地址栏可显示「安装应用」入口；nginx 对 /sw.js 设置 no-cache 防止旧 SW 卡住更新。(3) PC 模型详情右侧栏紧凑化：收紧各区块间距与下载行高度，版权更易在不滚动情况下看到；文件下载列表整行可点（原先只能点右侧下载图标），并修复了 div 套 button 的无效嵌套。

## 更新描述

- **首页页脚备案号**：后台「设置 → 友情链接与版权」新增「ICP 备案号」「公安备案号」两个填入项。填写后在首页页脚版权信息下方展示；ICP 号点击跳工信部 beian.miit.gov.cn，公安备案号自动生成 beian.gov.cn 查询链接（号码不含足够数字时降级为纯文本）。留空则完全不显示，不影响现有站点。备案号显示为纯文本链接、无图标，保持页脚简约。需要 HTTPS 生产环境才会出现浏览器安装入口之外的备案展示（备案号本身 http/https 都显示）。
- **浏览器安装入口（PWA）**：注册了一个极简 Service Worker，让 Chrome / Edge 等浏览器在地址栏右侧显示「安装应用」快捷入口，可把站点作为桌面/移动应用安装。该 SW 不缓存任何内容（所有请求照常走网络），不影响加载速度与更新；nginx 对 /sw.js 设置不缓存，确保新版本能正常推送。本地 localhost 与生产 HTTPS 均可触发安装提示；首次访问需等 Service Worker 激活，通常第二次访问 / 刷新后出现。
- **PC 模型详情右侧栏紧凑化**：收紧头部、规格、下载、底部版权各区块的间距与下载行高度，右侧内容整体更紧凑，多数屏幕下无需滚动即可看到底部版权信息；头部保留舒展呼吸感。文件下载列表改为整行可点击（不再只能点右侧下载图标），与图纸行的可点行为一致；同时修复了原本「div 内套 button」的无效 HTML 结构，无障碍标签更规范。
- 前端「检查更新」会读取本更新描述（GitHub Release 内容），展示最新版本号与更新内容。

## 部署备注

本次改动**不涉及 docker-compose / 数据库迁移**，纯镜像内的代码与前端资源变更。默认跟随 latest 的部署由 Watchtower 自动更新；需要立即更新时执行：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v3.4.7 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

# 快速健康检查
curl http://localhost:3780/api/health
curl -s http://localhost:3780/api/settings/version   # 应显示 v3.4.7
```

启用 PWA 安装入口需要生产环境为 HTTPS；备案号在 http/https 下均会展示（只要后台填入）。
