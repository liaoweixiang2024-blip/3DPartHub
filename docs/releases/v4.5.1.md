## 更新标题

3DPartHub v4.5.1 - 上传弹窗三优化（分类记忆/先确认再传/多文件夹队列）+ PDF 图纸一键下载

## 标签描述

3DPartHub v4.5.1 improves the upload modal and adds PDF drawing downloads. Upload modal: the selected category is remembered per browser (localStorage; auto-cleared if that category is later deleted), so repeat uploads don't re-select it; dropped folders and archives no longer upload immediately — they land in a pending list (folder name, file count, size) where each entry can be removed, and uploading starts only after clicking 开始上传; multiple folders can be dropped in sequence (each drop is a separate group), uploaded as independent ZIPs through the batch channel so folder-name-based titles/variant skipping/PDF pairing never mix across groups; folders and loose files can be mixed in one queue. Model detail: clicking a PDF drawing row now downloads the file directly (server adds ?download=1 → Content-Disposition attachment on both drawing endpoints; default stays inline for preview), while the ↗ button opens the in-browser preview — desktop and mobile layouts both updated; the global tooltip no longer pops text hints on these rows (data-tooltip-ignore, aria-label kept for screen readers). No DB migration.

## 更新描述

本次为**体验优化**版本，无数据库迁移。

**① 上传弹窗三处优化**

1. **记住上次选择的分类**：选过一次分类后，下次打开上传弹窗自动带出（存在本机）；若该分类事后被删除则自动回退为空，不会挂错
2. **先确认再上传**：拖入文件夹/压缩包不再立即上传，先进待传列表（显示文件夹名、文件数、大小，每条可删），点「开始上传」才真正开始；文件夹在拖入瞬间只做轻量校验（有无模型文件、总大小），不提前打包
3. **支持连续拖入多个文件夹**：每次拖入是一组独立条目，追加进列表；上传时每组打独立 ZIP 走批量通道——文件夹名做标题、变体子夹跳过、PDF 配对都按组解析，多次拖入互不混淆；文件夹与散文件/压缩包混拖也支持

**② 模型详情页 PDF 图纸可下载**

- 点击 PDF 行的文件名区域 → **直接下载 PDF 文件**（此前点击只会跳转预览页）
- 右侧 ↗ 按钮 → 在线打开预览（原行为）
- 服务端两个图纸端点新增 `?download=1` 参数（attachment 保存为文件），默认仍为 inline 预览，权限/短令牌校验完全不变
- PC 端与移动端布局同步更新；悬停不再弹文字提示（保留读屏 aria-label）

## 部署备注

```bash
cd /opt/3dparthub
docker-compose pull
docker-compose up -d
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）
```

默认跟随 latest 的部署由 Watchtower 自动更新。本次无 docker-compose.yml 改动，无 DB 迁移。

**建议升级后验证**：上传弹窗选个分类关掉重开看是否记住；拖两个文件夹点「开始上传」看列表与结果；模型详情 PDF 行点文件名确认触发下载、点 ↗ 确认打开预览。
