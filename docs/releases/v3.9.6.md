## 更新标题

3DPartHub v3.9.6 - 细节修复合集：iOS 分享报错、用户管理体验、版本记录缓存

## 标签描述

3DPartHub v3.9.6 is a collection of seven fixes with no DB migration. iOS: tapping the Safari share / add-to-home-screen button on a 3D page could surface a raw "Script error." toast — that string is the browser's muted-error placeholder, and the global error toast now silently drops it (local operations fall back to a localized message). User admin: role-tab counts (全部/管理员/编辑者/访客/内部) update immediately after role changes / disable / delete / batch operations — the stats cache is now invalidated on every write path; the role-permission help text was corrected to match actual code (editor's only privilege is being assignable as inquiry contact; the per-user share toggle was removed in v3.8.0); mobile toolbar no longer squeezes the 导出 button into two lines (flex-wrap + shrink-0 + nowrap) and the export button now matches the sort select's font size (iOS native selects don't inherit font-size). Settings: the 当前配置已保存 / 有未保存的修改 badge texts are now both 7 characters so toggling doesn't shift the layout. About page: version-update history is now cached long-term — the server keeps the full release list cached and only re-fetches when the lightweight /releases/latest probe detects a new version (probe itself cached 10 min); the browser caches entries in localStorage so revisiting the tab renders instantly without a request. Manual refresh button still forces a re-check.

## 更新描述

本次为细节修复合集，共 7 项，**无数据库迁移**。

- **[修复] iOS 点击系统分享/添加主屏幕时提示 "Script error"**
  - 该提示是浏览器对「被脱敏错误」的固定占位文案（跨域/WebKit 内部错误不提供细节），之前被全局错误 Toast 原样弹出。
  - 现在全局错误 Toast 对纯 "Script error." 静默处理；局部操作遇到时显示本地化的「操作失败，请稍后重试」。
- **[修复] 用户管理角色 tab 数字不实时**
  - 后端 stats 接口有 60 秒缓存，但改角色/禁用/删除/批量操作后未清缓存，tab 计数最长延迟 60 秒。
  - 现在所有影响统计的写操作成功后立即失效缓存，数字即时更新。
- **[修复] 角色权限说明与实际权限不符**
  - 编辑者：实际唯一特权是「可被指定为询价业务对接人（优先分配）」，原文案描述的上传/审核权限均不准确。
  - 内部：v3.8.0 已移除按用户的「可分享模型」开关，原文案不再适用。
  - 访客：补充分享模型能力（受总开关控制）。
- **[修复] 移动端用户管理「导出」按钮被挤成上下两行**
  - 搜索框不再挤压同排按钮（flex-wrap + shrink-0 + whitespace-nowrap），移动端为「排序+导出」一行、「搜索」通栏一行。
- **[修复] 「导出」与「注册时间」下拉字号不一致**
  - iOS 原生 select 不继承页面字号；两者统一 text-sm 并对 select 显式声明字号。
- **[修复] 设置页「当前配置已保存/有未保存的修改」宽度不一致导致页面抖动**
  - 两个文案统一为 7 个字，切换时宽度不变。
- **[优化] 版本更新记录长期缓存**
  - 服务端全量列表拉到后长期缓存，仅用轻量的 /releases/latest 探测最新版本号（探测本身 10 分钟缓存），**有新版本发布才重新全量拉取**。
  - 前端 localStorage 缓存，进「关于系统」页直接渲染不发请求；手动刷新按钮保留强制校验。

前端「检查更新」会读取本更新描述展示最新版本号与更新内容。

## 部署备注

本次**无数据库迁移**。升级步骤：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v3.9.6 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

curl -s http://localhost:3780/api/settings/version   # 应显示 v3.9.6
```

升级后注意：

- iOS Safari 点系统分享/添加主屏幕不应再弹 "Script error"；如仍有其他报错请截图反馈。
- 用户管理改角色后 tab 数字立即变化（不再需要等 1 分钟或手动刷新页面）。
- 版本更新记录首次仍需拉取（约 1-2 秒），之后长期缓存，发新版本自动更新。

默认跟随 latest 的部署由 Watchtower 自动更新。
