## 更新标题

3DPartHub v3.9.0 - 工单来源可点击直达

## 标签描述

3DPartHub v3.9.0 makes support-ticket sources clickable. When a user submits a ticket from a model detail page, a selection result, or a homepage search, the originating in-site URL is now stored on the ticket (new nullable source_url column) and displayed as a labeled link in the admin ticket list, ticket detail, and My Tickets pages — 来源模型/来源选型/来源搜索 followed by a blue link that opens the source page in a new tab. The server only accepts whitelisted relative paths (/model/, /selection, /?q=) and silently strips anything else, so external/phishing URLs can never be stored or rendered. Older tickets without a source keep their plain-text base-part display. One safe additive DB migration (add nullable column, no data touched).

## 更新描述

本次让**工单来源可以点击直达**，管理员查看工单时能直接打开用户提交工单时所在的页面，包含一个数据库迁移（仅新增可空列，无数据风险）。

- **[功能] 工单来源链接化**
  - 从**模型详情页**、**选型结果页**、**首页搜索**提交工单时，自动记录来源页面路径。
  - 后台工单列表、工单详情、我的工单（PC 表格 + 移动卡片）中，来源按类型标注并渲染为可点击链接（新窗口打开）：
    - 「来源模型: 零件名 ↗」→ 打开模型详情页
    - 「来源选型: 型号 ↗」→ 打开匹配的模型或选型页
    - 「来源搜索: 关键词 ↗」→ 打开带搜索词的首页
  - 老工单（无来源记录）保持原有纯文字零件名展示，完全兼容。
  - 后台搜索工单时支持按来源路径检索。
- **[安全] 来源白名单校验**
  - 服务端仅接受 `/model/`、`/selection`、`/?q=` 开头的站内相对路径，其余（外链、钓鱼链接）一律丢弃不保存，前端渲染前二次校验，双重防护。
- **[数据库] 一个迁移（仅加列，无数据风险）**
  - `support_tickets` 新增可空列 `source_url`。

前端「检查更新」会读取本更新描述展示最新版本号与更新内容。

## Docker Images

API image title: `3dparthub-api:v3.9.0`

API image: `ghcr.io/liaoweixiang2024-blip/3dparthub-api:v3.9.0`

API image description: Express/Prisma API service. v3.9.0 stores an optional source_url on support tickets at creation, validated against a strict in-site whitelist (/model/, /selection, /?q= prefixes, relative paths only — external URLs are stripped). Ticket list and detail APIs return the field. One additive migration adds the nullable source_url column. Includes all v3.5.0–v3.8.1 functionality.

Web image title: `3dparthub-web:v3.9.0`

Web image: `ghcr.io/liaoweixiang2024-blip/3dparthub-web:v3.9.0`

Web image description: React/Vite frontend. v3.9.0 passes the originating page URL when submitting tickets from model detail (desktop+mobile), selection results, and homepage search (both theme templates); a new TicketSourceLink component renders the source as a labeled clickable link (来源模型/来源选型/来源搜索, zh/en) in the admin ticket list, ticket detail, and My Tickets pages, falling back to plain text for legacy tickets. Includes all v3.5.0–v3.8.1 functionality.

## 部署备注

本次**有数据库迁移**（仅新增可空列，API 容器启动时自动执行，无数据风险）。升级步骤：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v3.9.0 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

curl -s http://localhost:3780/api/settings/version   # 应显示 v3.9.0
```

升级后注意：

- 来源链接只对**新提交**的工单生效（老工单没有来源记录，显示不变）。
- 建议让用户从模型详情页/选型页提交工单，管理员即可一键跳回来源页面。

默认跟随 latest 的部署由 Watchtower 自动更新。
