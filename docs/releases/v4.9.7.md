## 更新标题

3DPartHub v4.9.7 - 全站注释产物剥离 + 三轮安全审计修复（CSV 公式注入/开放重定向/令牌吊销/权限加固）+ 依赖升级

## 标签描述

v4.9.7 ships a full security hardening pass (three audit rounds: route permissions, auth/session/SSRF/file-handling/business-logic, then an injection-specific sweep) plus production comment stripping. Injection fixes: the admin users CSV export was vulnerable to spreadsheet formula injection — a user setting their company field to `=HYPERLINK(...)` or `=cmd|...` would execute when an admin opened the export in Excel; CSV fields and the client-side Excel export now neutralize `= + - @ Tab CR` prefixes. Backup restore tar calls gained `--` end-of-options separators and archive entries starting with `-` are rejected, closing an argument-injection path (`--checkpoint` / `--use-compress-program`). Email template vars are now CRLF-stripped before escaping (future-proof header-injection immunity), and selection-result PDF/catalog URLs pass an `isSafeUrl` protocol whitelist before entering iframes and generated document windows. Auth fixes: password reset now revokes all existing tokens (consistent with the change-password policy — a stolen session can't outlive a reset), the login page `?redirect=` parameter is validated as a same-site path (open redirect), and `trust proxy` is env-configurable (`TRUST_PROXY=0`). Route/permission fixes: `/api/models/count` joins the browse gate, the anonymous web-vitals endpoint gets a dedicated rate limit with metric-name whitelist and 4kb body cap, product-wall community uploads join the upload rate limiter, and ticket/inquiry attachment download-tokens no longer trust the embedded role snapshot (DB-verified, matching the JWT branch). The home footer link hrefs are protocol-validated. Dependencies: adm-zip 0.6.1, nodemailer 9.1.1, multer 2.4.0, @xmldom/xmldom 0.9.12, fflate 0.8.3 — both packages now audit-clean (0 vulnerabilities). Production artifacts no longer contain developer comments: index.html is stripped at build time (SSI directives preserved) and sw.js / maintenance.html are post-processed. Frontend-only + server hardening, no database migration.

## 更新描述

本次为 **三轮安全审计修复 + 注释产物剥离 + 依赖升级**，前后端均有改动，无数据库迁移，前后端镜像均需更新。

**① 注释产物剥离（生产 view-source 不再暴露开发注释）**

- index.html：构建期剥离 HTML 注释与内联 script 的 `//` 注释（nginx SSI 指令 `<!--# -->` 保留）
- sw.js（23 行）/ maintenance.html（2 条）：public/ 静态直出文件，新增构建后处理脚本统一剥离，剥离后语法校验通过；源码注释保留给开发者

**② 注入漏洞修复（第三轮审计）**

- **用户导出 CSV 公式注入（medium）**：普通用户把「公司」等字段设为 `=HYPERLINK(...)` / `=cmd|...`，管理员打开导出表即触发 Excel 公式执行 —— 服务端 CSV 与客户端 Excel 导出统一对 `= + - @ Tab CR` 前缀加 `'` 强制文本
- **备份恢复 tar 参数注入（low，仅 admin 可达）**：解压命令补 `--` 终止符 + 条目名拦 `-` 前缀，封死 `--checkpoint` / `--use-compress-program` 类参数注入
- 邮件模板变量统一剥 CRLF（面向未来：用户文本进 subject 也不构成头注入）
- 选型结果卡 PDF/目录 URL 进 iframe / 新窗口前过协议白名单

**③ 认证与会话修复（第二轮审计）**

- **忘记密码重置后吊销全部既有令牌**：与「改密码」策略对齐，被偷会话的攻击者无法熬过受害者的密码重置
- **登录页 `?redirect=` 开放重定向修复**：仅允许站内路径（`/` 开头且非 `//`、`/\`）
- `trust proxy` 可用 `TRUST_PROXY=0` 关闭（防端口直连时伪造 XFF 绕过 IP 限流）

**④ 路由权限与限流加固（第一轮审计）**

- `/api/models/count` 补浏览门槛（匿名不可再探测模型总量）
- web-vitals 匿名上报：专属限流 60/min + 指标名白名单 + 4kb body 上限（防日志注入/洪泛）
- 产品图库社区上传补上传限流（200/h）
- 工单/询价附件 download_token 分支的 role 快照改为查库确认（降权/禁用后 5 分钟 TTL 内不再能凭旧快照越权）
- 首页友情链接 href 加协议白名单

**⑤ 依赖安全升级（两端 npm audit 全清零）**

- 服务端：adm-zip 0.6.0→0.6.1（high×2）、nodemailer 9.0.5→9.1.1（high×4）、multer 1.x→2.4.0（已停维护 + multipart DoS 公告）、qs→6.16.0
- 客户端：@xmldom/xmldom 0.9.12、fflate 0.8.3/0.6.11（high 修复）
