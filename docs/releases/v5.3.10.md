## 改动：移动端画册捏合缩放失效

- **现象**：选型结果 → 画册资料「放大查看」，手机上双指捏合缩放没反应（弹窗能开、双击/按钮也不见效）
- **根因**（两层叠加，v5.3.8 缩放改造引入）：
  1. v5.3.8 把图片缩放从 `transform: scale`（视觉变换）改成**布局尺寸驱动**（width/height = 适应尺寸 × 缩放倍数），图片布局宽度开始超过弹窗容器
  2. Tailwind Preflight 有全局规则 `img { max-width: 100%; height: auto }`——布局宽一旦超过容器，used width 被钳回容器宽（实测：`style.width` 已设 564px、computed 仍是 364px）；图片又是 flex 子项，还会被 flex-shrink 二次压缩
  3. 桌面弹窗容器约 1280px 宽，缩放 2.2 倍以内不超容器、钳制不触发，所以桌面看起来正常；移动端容器仅 ~364px，第一下捏合就超、立刻被钳住——「缩放失效」
- **修复**：fit 模式给图片 inline `maxWidth/maxHeight: none`（掀掉 preflight 钳制）+ `shrink-0`（关掉 flex 压缩）
- **验证**：
  - 移动端仿真（CDP 双指捏合）：100% → 169%，图片宽 364px → 617px（= 364×1.69），平移偏移正确；修复前宽度纹丝不动
  - 桌面滚轮 ×5：100% → 249%，宽 2217px 不再被容器钳制（旧版深放大其实也被钳，一并修好）
  - 桌面拖拽平移、双击复位不受影响
