# v5.8.3

发布日期：2026-10-15

## 更新标题

3DPartHub v5.8.3 - 移动端全页搜索操作行移至搜索框正下方 + 滑返回恢复列表滚动位置 + 返回退出还原进入来源 + 空态闪帧/旧词残留修复

## 更新描述

v5.8.2 之后对移动端选型搜索的一轮集中打磨：全页搜索的「共 N 结果 / 查看全部 / 关闭搜索」操作行从屏幕底部移到**搜索框正下方**（与「查看全部」列表页同构，常驻可见、软键盘天然不遮挡，页面级固定条删除）；列表页工具卡到首张产品卡的间距对齐**产品卡之间的 12px**；点标签进向导后**边缘滑/浏览器返回恢复列表原滚动位置**（已加载页数不丢）；「返回」退出列表**还原进入来源**（标题不再带上与本场搜索无关的大类名）；「查看全部」离开面板后旧搜索词不再残留；全页搜索面板计数行/空态的加载闪帧补齐 settled 守卫。随版附带一轮代码审查修复：列表态 groupId 还原严格框在列表会话内，✗ 清空回路与向导「重新选择」不受影响。

## 新增功能

### 1. 移动端全页搜索操作行移至搜索框正下方

- 与「查看全部」列表页同构：搜索框 → 计数/操作行 → 结果区
- 操作行在滚动区外常驻：结果滚动/翻页它不动，「查看全部 / 关闭搜索」随时可点
- 位于页面顶部区域，软键盘弹出永远遮不住（原页面级固定条要么被键盘盖住、要么追键盘跳到屏幕中间，两难就此消失）
- 页面级固定条与占位垫删除（fixed 层 -1）

### 2. 滑返回恢复列表滚动位置

- 移动端列表页点产品标签进向导后，边缘滑/浏览器返回 pop 回列表时**写回离开时的滚动位置**（双 rAF 等布局落定 + clamp 防图片加载中过冲）
- 已加载的页数在列表 hook 内保留，返回即原位（数据 + 位置都不重头翻）
- 连续多轮「标签 → 返回」每轮都恢复；「查看全部」全新进入仍从顶部开始
- 桌面浏览器返回同样生效

## 修复清单

- **「返回」退出列表标题带无关大类**：列表会话里点过标签会把 groupId 改成标签所属大类，退出落在该大类子页、标题带其大类名——现在 pop 恢复列表与「返回」退出都还原到进入来源（首页进 → 回首页无分类段；大类子页进 → 回原子页，标题逐字一致）
- **查看全部后旧词残留**：点「查看全部」进列表 → 返回 → 再点搜索按钮，面板不再显示上一场的搜索词和结果（离开面板即清词，与关闭搜索/选中结果行一致；桌面下拉不受影响）
- **移动端列表页间距**：工具卡（搜索框+计数）到首张产品卡从 47px 对齐为产品卡间距同款 12px（桌面不变）
- **面板加载闪帧**：计数行 / 结果区空态 / 「查看全部」按钮补齐 settled 守卫，首搜 query 提交间隙不再闪一帧「没有匹配的产品」（SearchRows 与列表页工具栏同款判定）
- **审查修复（groupId 还原作用域）**：还原严格框在真处于列表态的分支内——`clearGlobalList` 同时被 ✗ 清空回路（goToGroupCategories）和向导「重新选择」（resetCurrentCategory）复用，无条件执行会覆盖它们自己的 groupId 设定（子页发起的 ✗ 回路会回错首页）
