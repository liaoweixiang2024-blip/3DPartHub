## 更新标题

3DPartHub v4.3.1 - 数据备份页全面改版：模块选择平铺、保障状态一目了然

## 标签描述

3DPartHub v4.3.1 redesigns the data-backup settings page around clarity. The backup-scope dropdown (whose 9 options overflowed the viewport bottom when triggered from the lower half of the screen) is replaced by a flat card grid — all backup types visible at once on any screen size (5 columns desktop / 3 tablet / 2 mobile), each card showing its live count (e.g. "3,438 models", "1 account"), with the create button reflecting the selected scope. The separate "backup health" and "create backup" sections are merged into one "备份与保障" block: four protection items (recovery points / automation / off-site copy / encryption) render as a single row of status pills — items with issues expand on tap into a plain-language explanation plus a jump button straight to the relevant setting (automation and mirroring link to their toggles, no-backup scrolls to create); encryption, which has no UI toggle, spells out the docker-compose env-var steps inline. The 10-card stats overview is removed (counts now live on the selector cards), policy-check details collapse behind a "view details" toggle, and the advice list plus mirror/auto-status info lines are dropped — the block shrinks from ~500px to ~32px by default, putting the primary action (pick a module, create a backup) at the top of the screen. All flows regression-tested end to end: create → list → verify → restore (users merge semantics intact), restore/cancel/import dialogs, and every list action button. Server-side backup logic unchanged from v4.3.0.

## 更新描述

本次为**体验优化**，无数据库迁移，后端逻辑与 v4.3.0 一致。

**数据备份页改版**

- 备份范围选择从下拉框改为**平铺卡片**：9 种备份类型全部直接可见（桌面 5 列 / 平板 3 列 / 手机 2 列），不再有弹出菜单被屏幕底边裁剪、最后一个选项只显示一半的问题
- 每张选择卡显示当前数量：如「模型库 3,438 个模型」「用户 1 个账号」，选什么、备多少一目了然
- 创建按钮文案跟随所选模块：「创建整站备份」「创建审计日志备份」……
- 「备份保障概览」与「创建备份」两个区块合并为一个「备份与保障」区块，页面从 6 个区块精简到 3 个

**保障状态改为胶囊 + 通俗文案**

- 恢复点 / 自动化 / 异地副本 / 加密 四项保障压成一行状态胶囊，默认仅占一行高度（原先约半屏）
- 有问题的项点击展开：通俗解释（现状 + 风险）+ **直达开启入口的跳转按钮**——「去开启自动备份」「去配置镜像目录」直接跳到设置开关；加密无界面开关，直接给出 docker-compose 环境变量配置步骤
- 删除与保障卡重复的「备份范围概览」10 张统计卡、「当前建议」列表等信息冗余区块
- 体检结论压缩为一行（徽标 + 时间），逐项检查明细按需展开

**建议升级后验证**：后台管理 → 系统设置 → 运维维护 → 数据备份，体验新的模块选择与保障胶囊；点「去开启自动备份」确认跳转正确。

前端「检查更新」会读取本更新描述展示最新版本号与更新内容。

## 部署备注

本次**无数据库迁移**，后端逻辑与 v4.3.0 相同，直接升级：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v4.3.1 api / web 镜像
docker-compose up -d --force-recreate   # 强制重建容器（确保换用新镜像）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

curl -s http://localhost:3780/api/settings/version   # 应显示 v4.3.1
```

> 本次改动集中在前端：若更新后页面样式仍是旧版，请强制刷新浏览器（Ctrl/Cmd+Shift+R）或清除站点缓存后再看。

默认跟随 latest 的部署由 Watchtower 自动更新。
