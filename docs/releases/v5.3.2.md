# v5.3.2

发布日期：2026-10-06

## 更新标题

3DPartHub v5.3.2 - 移动端选型大分类卡滑动按压反馈根治（悬停/按压动画改为真鼠标专属，iPad/横屏手机触摸滑动零反馈）+ 桌面鼠标动画完整保留

## 标签描述

v5.3.2 finally eliminates the press feedback on selection category cards while sliding on mobile devices - including iPad and landscape phones (viewport ≥768px) which use the desktop card styles. Root cause: the desktop card class still relied on CSS `:hover`/`:active` pseudo-classes and framer-motion `whileTap`/`whileHover` - all of which fire and then stick to the touched card during iOS touch scrolling, making the card under the finger visibly darken as if selected. Pressing with a desktop mouse reproduced the exact same visual change, which pinpointed it. Fix: all hover/press feedback (hover tint, 1px lift, arrow turning orange, press scale+dim) now hangs on `data-mouse-hover`/`data-mouse-press` attributes that are only ever set by pointer events with `pointerType === 'mouse'` - touch devices physically cannot set them, so press-and-drag gives zero feedback at any viewport width. Additional touch defenses on the same cards: children (thumbnail/text/icon) no longer respond to pointers at any width (no iOS long-press preview, no text-drag selection), and a touch-slop guard swallows clicks that end more than 10px away from the touch start (slow drags misjudged as taps). Desktop mouse behavior is visually identical to before (hover lift/tint/arrow, press scale/dim, click selection highlight). No database migrations.

## 更新描述

本次为 **移动端选型触摸反馈根治** 版本，无数据库迁移，更新前后端镜像即可。

## 根因：为什么前几轮修复后 iPad/横屏手机上还是会变

- 大分类卡的「桌面样式」与「移动样式」按视口宽度 768px 切分
- 手机竖屏（<768px）走移动样式——前几轮已清理干净，确实不再有反馈
- **iPad / 横屏手机（≥768px）走桌面样式**，而桌面样式里一直是：
  - CSS `:active` 伪类（`active:opacity-80`，按住整卡变深）
  - CSS `:hover` 伪类（`group-hover:bg-surface-container/80`，底色变实；箭头变橙）
  - framer-motion `whileTap` / `whileHover`（按压缩放、悬停上浮）
- iOS 触摸滚动时这些状态会**全程粘在手指落点那张卡上不释放**——即用户反复反馈的「滑动按压背景还是会变」
- 桌面浏览器鼠标按住能复现一模一样的变化，成为定位线索

## 修复方案：反馈只属于真鼠标

| 层                | 改动                                                                                                                              |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 悬停/按压样式载体 | `:hover`/`:active` 伪类 → `data-[mouse-hover=true]` / `data-[mouse-press=true]` 属性变体                                          |
| 属性设置门槛      | 只有 `pointerenter`/`pointerdown` 且 **`pointerType === 'mouse'`** 才设置；触摸（含 Apple Pencil）永远设置不了                    |
| framer-motion     | `whileTap`/`whileHover` 彻底移除（其触发不看指针类型，触摸设备照样触发且滚动时粘滞）                                              |
| 子元素防御        | 卡内缩略图/文字/图标全宽度 `pointer-events: none`（原仅 <768px）：图片长按不呼出 iOS 预览、文字不可拖选，事件只落在卡片 button 上 |
| 拖动误判点击      | 位移 >10px 的 touchend 吞掉后续 click（iOS 把慢速拖动判成 tap 时不再闪选中高亮）                                                  |

## 桌面鼠标效果对照（视觉与改前完全一致）

- 点击：橙色选中高亮后进入分类（所有设备一致，含触摸）
