## 更新标题

3DPartHub v4.9.0 - 登录浏览门槛重构（选型独立开关/锁屏直达登录）+ iOS 主屏下载卡死修复 + 用户「最近活跃」追踪

## 标签描述

v4.9.0 overhauls the login-gated browsing experience and ships several long-standing fixes. The browse gate now has two fully independent switches: 登录浏览 (models, existing) and the new 登录浏览选型 (selections). Anonymous visitors get a blurred lock screen whose centered card is the single login prompt — 前往登录 goes straight into the auth modal (or /login when the modal is disabled), with no auto-popup, no "登录失效" toasts, no forced redirects; a genuinely expired session is reported once and returns the user to where they were after re-login. Selection share links are no longer subject to any login gate (token is the credential), which also fixes GLB models failing to load in WeChat / anonymous webviews on model share pages (the viewer now streams through a token-verified model-preview endpoint). iOS home-screen PWA downloads no longer freeze at "请选择存储到文件或分享目标": the download overlay is now a save/share action card (file name + size), the share sheet is invoked from the focused window (auto attempt + manual button), with a direct-download fallback via the anchor download channel. User management gains real activity tracking: a new `last_active_at` column (migration included, refreshed on login and throttled authenticated requests) powers the 最近活跃 sort, detail view and CSV export. Selection admin kits support bulk-importing child components (paste from Excel, comma/space separated, live parse preview with bad-line hints, append or replace). Legacy Edge/Chromium < 111 get their colors back: the Tailwind v4 build now emits hex fallbacks (oklch/color-mix fully downgraded). Also fixes the share-page "reset view" button not responding. Includes one Prisma migration (`20260917071709_add_user_last_active_at`).

## 更新描述

本次为 **登录浏览门槛重构 + iOS 下载修复 + 活跃追踪** 版本，含 1 个数据库迁移，前后端镜像均需更新。

**① 登录浏览门槛重构（体验 + 正确性）**

- 匿名访问首页/选型页：模糊锁屏背景 + 居中提示卡是**唯一**登录提示（去掉进页面自动弹窗，不再重复打扰）；「前往登录」一步直达登录弹窗
- 匿名访客零打扰：不再弹「登录失效」toast、不再强制跳登录页、受门槛约束的请求在判定前暂停（零无效 401）；会话真失效只提示一次，登录后返回原页面
- 锁屏文案按页面区分：首页「浏览模型库需要先登录账号」/ 选型页「浏览选型需要先登录账号」

**② 选型独立登录开关（后台 → 设置 → 访问控制）**

- 新增「登录浏览选型」开关，与「登录浏览」互不影响，文案按统一规范（不带对比描述）
- 选型分享链接不再叠加登录门槛（分享凭 token 授权，微信等匿名 webview 可直接打开）

**③ 微信/匿名 webview 分享页模型加载失败修复**

- 根因：开启「登录浏览」后 `/static/models/*` 对匿名请求 401，未登录的微信内置浏览器拉不到 GLB
- 分享页查看器改走凭分享令牌鉴权的 `model-preview` 端点（校验分享权限/密码/有效期后流式下发），未登录也可正常预览

**④ iOS 主屏应用（PWA）下载卡死修复**

- 下载浮层升级为「保存到文件 / 分享」操作卡（文件名 + 大小 + 双按钮）
- 分享面板改在聚焦窗口内拉起（自动尝试一次 + 手动按钮双保险，挂起不再卡死页面）；「直接下载」按钮走 Safari 官方下载通道兜底
- 覆盖应用内所有下载入口（模型下载 / 打包 zip / 分享页下载 / 图纸下载）

**⑤ 用户「最近活跃」真实追踪**

- 新增 `last_active_at` 字段（迁移 `20260917071709_add_user_last_active_at`，部署自动应用）；登录 + 带凭证请求均会刷新（5 分钟节流）
- 后台用户列表「最近活跃」排序（活跃时间优先）、用户详情、CSV 导出均已接入

**⑥ 套件子零件批量导入（选型管理）**

- 产品弹窗开启「套件」后新增「批量导入」：支持 Excel 直接粘贴、逗号/空格分隔；实时解析预览 + 无法识别行提示；支持追加导入或替换现有清单

**⑦ 旧版 Edge / Chromium(<111) 颜色失效修复**

- Tailwind v4 构建产物 oklch/color-mix 全部生成 hex 回退（产物 oklch 归零），修复按钮变黑等颜色问题
- 若个别电脑仍现「字体偏大」，一般为浏览器缩放或系统显示缩放，非样式问题

**⑧ 其他修复**

- 分享预览页工具栏「重置显示」点击无反应（补相机复位事件）

## 升级步骤

```bash
cd /opt/3dparthub
docker-compose pull && docker-compose up -d --force-recreate
```

> **注意**：① 含 1 个数据库迁移，容器启动时自动应用；② 若希望选型页也需登录，升级后到 **后台 → 设置 → 访问控制** 单独打开「登录浏览选型」（新开关默认关闭，与「登录浏览」互不影响）；③ 升级后浏览器强制刷新（Cmd/Ctrl+Shift+R），iPhone 主屏应用需完全退出后重新打开（或删除重装）以更新缓存的前端资源。
