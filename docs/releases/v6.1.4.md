# v6.1.4

发布日期：2026-11-07

## 更新标题

3DPartHub v6.1.4 - 修复未登录/会话过期时右上角弹出英文错误提示；iPhone 的「翻译为…」建议改为按设备语言智能抑制（读不懂页面的海外访客仍保留浏览器翻译）；模型详情页 PDF 图纸文件名与模型文件名风格统一；整站安全审计后 7 项加固（临时预览属主校验、邮件链接 Host 注入防护、忘记密码接口限流等）

## 更新描述

两部分改动：

1. **未登录/会话过期弹英文错误修复**：令牌刷新链路此前用裸 `new Error('Session expired')` 拒绝请求——它不是 axios 错误，全站所有「会话过期静默」漏斗（SWR 全局 onError、unhandledrejection、页面兜底）都只认 axios 401，认不出它。于是未登录访客碰到需登录的接口时，右上角 toast 直接弹出英文原文 "Session expired"（看着像错误代码）。本次新增 `SessionExpiredError` 类（消息为中文「登录状态已过期，请重新登录」），刷新链路 4 处裸 Error 全部替换，所有静默漏斗按类型识别并静默（会话过期已由跳转登录页/页面级登录引导统一承接，toast 纯属打扰）；SWR 对会话过期不再自动重试（重试必然同样失败）。

2. **iPhone 翻译建议按语言感知抑制**：页面语言声明本来就正确（`lang="zh-CN"` 且切语言时同步更新），Safari 弹「翻译为…」是因为那台 iPhone 的首选语言不是简体中文（浏览器按「设备语言 ≠ 页面语言」的设计行为）。站点自带 6 语种界面切换，机器翻译整页只会把界面翻花，但一刀切禁止又会让读不懂中文的海外访客失去浏览器翻译这条生路（语言切换按钮本身也是中文，他们未必找得到）。本次改为语言感知：首帧内联脚本读设备语言列表 + 上次手选语言，**读得懂当前页面语言 → 整页标记 `translate="no"` 抑制翻译建议；读不懂 → 不标记，保留浏览器翻译能力**；站内切换语言时同规则重算。

3. **文件下载列表视觉统一**：桌面端模型详情页 PDF 图纸文件名补上与模型文件（STEP 等）一致的等宽字体，同一列表内不再大小不一（此前两者同为 14px，但一个等宽一个非等宽，视觉上像字号不同）。

4. **整站安全审计后加固 7 项**（四路并行深扫 + 高危发现逐条复核，无高危漏洞，以下为收紧项）：
   - **临时预览属主校验**：`/static/temp-previews/` 静态读取从「登录即可」收紧为「登录 + 属主比对」（与上传/删除接口同一套 ownerKey），其他登录用户拿到/猜到 URL 也拖不走别人的 STEP 转换产物（可能含商业机密图纸）；不匹配一律 404 不暴露存在性，ADMIN 可查看全部
   - **邮件/通知链接 Host 注入防护**：`SITE_URL` 未配置时，通知链接的兜底域名必须精确命中 `ALLOWED_ORIGINS` 白名单才采用，否则回落为无链接——伪造 Host 头改写不了密码重置/通知邮件里的链接（现网已配置 SITE_URL，此项为纵深防御）
   - **忘记密码接口补限流**：对齐登录口径挂 authLimiter（50 次/15 分钟/IP）
   - **管理端「我的 IP」改用 req.ip**：与限流/IP 守卫判定源一致，不再回显可伪造的 X-Forwarded-For 首段（抄进 IP 白名单才真正生效）
   - **静态服务显式 `dotfiles: 'ignore'`**（三处，防配置漂移）
   - **图纸查看弹窗 `<a>`/`<iframe>` 加 `referrerpolicy="no-referrer"`**：带令牌的 URL 不随 Referer 外泄
   - **报价单打印页公司 logo 过 `isSafeUrl` 白名单**：管理端可配 URL 拒绝 `javascript:` 等非法 scheme，回落为文字 logo
