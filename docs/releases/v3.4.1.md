## 更新标题

3DPartHub v3.4.1 - 前端体验修复与图标补全版

## 标签描述

3DPartHub v3.4.1 patch release fixing 25 silently-broken icons across admin pages, adding a show/hide toggle to the first-login password change, resetting settings tab scroll on switch, and completing the README maintenance command reference. API image is rebuilt for version alignment with no behavioral changes.

## 更新描述

- 修复全局共 25 个静默失效图标：后台管理页（用户管理、系统设置、选型管理、颜色配置、列编辑器、结果卡片、操作按钮等）多处图标因图标映射缺失而显示为空白方块，现已补全全部 25 个图标映射，涵盖删除、排序、PDF 导出、历史记录、认证标识、取色吸管、配色方案、网络、下载、提示等常用图标。
- 首次登录强制修改密码对话框增加密码「显示 / 隐藏」小眼睛：新密码与确认密码两个输入框均可点击眼睛图标切换查看当前输入，避免凭记忆输错。
- 系统设置切换分类标签页时，内容区滚动位置自动回到顶部：之前在某个分类里向下滚动后切换到其他分类，滚动位置不会重置、会从中间位置开始；现已修复为切换时回到顶部。
- 完善部署文档（README）运维命令：新增「运维命令速查」章节，覆盖服务管理、版本与健康检查、查看管理员账号、进入容器、资源与磁盘占用、更新与回滚等常用维护命令；补充 docker-compose（带连字符旧版）兼容说明；修正常见问题中的 `docker exec` 写法与默认管理员邮箱示例。
- 前端「检查更新」会读取本更新描述（GitHub Release 内容），展示最新版本号与更新内容。
