# v5.3.8

发布日期：2026-10-07

## 更新标题

3DPartHub v5.3.8 - 选型页三连修：画册放大模糊（transform 位图拉伸 → 布局尺寸光栅化，原生像素内始终清晰）+ 选项过多时右侧搜索框/生成链接/全部分类被挤压 + 短视口下掉选回退时步骤标题被折叠线裁一半

## 更新描述

本次为**选型页体验修复**版本，无数据库迁移（schema 未变更），只涉及前端，更新 web 镜像即可（api 镜像例行同步）。

## 改动一：画册放大模糊修复

- **现象**：选型结果里点画册资料放大查看，图片越放大越糊；但用「新窗口打开」看同一张原图却很清晰（说明源图分辨率没问题）
- **根因**：弹窗缩放用的是 `transform: scale()`——图片先在布局阶段被压到适应窗口的小尺寸（如原生 2000px 压到 565px）完成光栅化，再由 transform 把这张**小位图**拉伸 3 倍显示，等于把 565px 位图糊到 1695px
- **修复**：缩放改为**布局尺寸驱动**（width/height = 适应尺寸 × 缩放倍数），浏览器按最终显示尺寸重新光栅化——原生像素内始终清晰；transform 只保留平移（平移不改变光栅化尺寸）
- 滚轮朝光标缩放 / 拖拽平移 / 双指捏合 / 双击复位 / 头部按钮组全部保持原交互不变；适应窗口基准由 ResizeObserver 跟随容器尺寸重算

## 改动二：选项过多挤压右侧控件

- **现象**：PC 端选型向导进行中，工具栏左侧已选 chips 越积越多（字段多的系列如水枪 8 个字段），把右侧的搜索框、「生成分类链接」、「全部分类」挤变形
- **根因**：chips 容器 `shrink-0` 只增不让，flex 空间全从右侧容器克扣
- **修复**：左侧允许收缩（内层横向滚动接管溢出，chips 仍可左右滑看全部），右侧「全部分类」按钮加 `shrink-0` 不换行不压缩，搜索框保住可用宽度

## 改动三：掉选回退时步骤标题被裁一半

- **现象**：水枪系列 8 个字段全部选完后，点工具栏「管型」chip 掉选回退重选，步骤区的「2 选择管型」标题只剩上半截（视口高度 ≤768px 的屏幕必现，如 1366×768 / 1280×720；高屏正常）
- **根因**（连环因果）：
  1. 桌面端掉选回退时，负责滚动的两个 effect 一个被抑制标志拦截后**裸返回**、另一个因无待滚标志直接跳过——没有任何代码去定位回退后的步骤
  2. 掉选瞬间结果区卸载、页面内容变矮，浏览器把滚动位置强制收窄到残留值，恰好把标题留在折叠线（置顶工具栏底边）上方约 105px
  3. 视口够高时残留位置碰巧无害，短视口下标题正好骑在折叠线上——字被裁一半
- **修复**：被抑制的滚动分支不再裸返回，改为延迟兜底——仅当步骤顶边在视口外时重新顶对齐拉回（正常路径零副作用）；另给两条自动滚动路径追加「滚动完成后复核」，防御选项图片异步加载导致高度变化造成的定位过冲
- **验证**：1366×768 / 1280×720 / 1440×760 / 1440×900 四视口实测，标题全部完整可见（修复前三个短视口均被裁）
