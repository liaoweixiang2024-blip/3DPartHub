## 更新标题

3DPartHub v3.4.2 - 后台备份记录增强与 404 页面优化

## 标签描述

3DPartHub v3.4.2 patch release: backup records in admin settings now show each archive's host-relative file path with a one-click copy button, and the 404 page is rebuilt to live inside the public layout (desktop header / mobile header + bottom nav), fill the mobile viewport, drop the bordered card for a clean centered borderless layout, and remove the now-duplicate header logo.

## 更新描述

- 后台「设置 → 数据备份 → 备份记录」每条新增「路径」行：显示备份文件在宿主机上的相对路径（如 `server/static/backups/backup_xxx.tar.gz`，与 docker-compose 文档一致），旁边带一键复制按钮，方便运维直接 scp / cp / ls 定位备份文件；路径在读取时实时计算，不落库、不写进备份 JSON，旧记录无需迁移自动生效。
- 404 页面复用整站公开页框架：PC 端显示顶部页头，移动端显示顶部页头 + 底部菜单，不再是孤立全屏页，观感与正常页面一致。
- 404 页面移动端铺满视口（修复浏览器地址栏遮挡导致内容被裁切 / 出现滚动条）。
- 404 页面去掉原带边框 / 阴影 / 背景色的卡片，改为纯居中无框布局；内容体去掉与页头重复的 logo。
- 前端「检查更新」会读取本更新描述（GitHub Release 内容），展示最新版本号与更新内容。
