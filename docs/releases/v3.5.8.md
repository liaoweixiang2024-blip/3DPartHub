## 更新标题

3DPartHub v3.5.8 - 设置页长耗时操作加二次确认弹窗（防误触卡死）

## 标签描述

3DPartHub v3.5.8 adds a lightweight confirmation dialog before triggering long-running / heavy settings actions, so an accidental click no longer immediately ties up the system for minutes or kicks off an irreversible job. Five actions now confirm first: backup policy health-check (策略体检, ~1–2 min), create backup (创建备份, minutes, locks backup subsystem), start storage sync (开始同步, can run long; warns when "delete extraneous files" is on that the deletion is irreversible), cleanup scan (开始扫描, ~30–60 s, read-only), and per-backup verify (校验, ~1–2 min). Each dialog states the expected duration and side effects; confirming launches the original task unchanged (progress / locking / validation logic untouched). Reuses the existing `ConfirmDialog` component with an informational (non-destructive) style. Test-only buttons (test storage / Redis / test email) and the restore flow (which already has its own confirmation panel) are intentionally left as-is. Frontend-only, no DB migration, no breaking change.

## 更新描述

本次给系统设置里的**长耗时 / 重操作**加了**二次确认弹窗**——以前点一下就直接触发，可能让页面长时间处于 busy、占用系统资源又没法撤销；现在会先弹窗确认。

- **[体验] 5 个操作点「确认」后才真正执行**：
  - **策略体检**（约 1–2 分钟，全面体检磁盘空间 / 权限 / 归档完整性）
  - **创建备份**（数分钟，期间备份功能锁定、不能同时跑别的备份）
  - **开始同步**（可能持续很久、占用带宽；若开启了「删除多余文件」会额外提示**不可撤销**）
  - **开始扫描**（约 30–60 秒，只读、不删任何文件，删除仍需扫描后单独确认）
  - **校验备份**（备份列表每行，约 1–2 分钟，解压逐文件比对 SHA256）
- 弹窗会写清**预计耗时和副作用**，确认后才启动原任务；任务进行中按钮变灰 / 显示百分比，**无法再开第二个**。
- 复用现有确认组件，**信息蓝**样式（非红色危险提示），文案与「删除备份 / 清理缓存」风格一致。
- **不加**：测试存储 / 测试 Redis / 发送测试邮件（点「测试」就是求即时反馈，加弹窗反而碍事）；「恢复」已有自己的确认面板（含跨服务器勾选框），不重复加。

纯前端改动，**无数据库迁移、无破坏性变更**。前端「检查更新」会读取本更新描述展示最新版本号与更新内容。

## 部署备注

本次**纯前端、无数据库迁移、无破坏性变更**。直接升级即可：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v3.5.8 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

curl -s http://localhost:3780/api/settings/version   # 应显示 v3.5.8
```

默认跟随 latest 的部署由 Watchtower 自动更新。
