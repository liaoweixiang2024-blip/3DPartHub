# v6.1.8

发布日期：2026-11-27

## 更新标题

3DPartHub v6.1.8 - iPhone Safari 弹窗上下被裁/按钮被底部工具栏遮挡修复（svh 最小可视高度限高 + 动态让开 Safari 悬浮工具栏 + 旧内核浏览器 dvh 兜底）；注册/登录页底部协议被裁修复（卡片被挤压裁切改限高卡片+表单区滚动）

## 更新描述

v6.1.7 发布后用户在 iPhone 15 Pro Max Safari 实测反馈两个残留问题，本版修复：

### 1. iOS Safari 上弹窗顶部被裁 + 取消/保存按钮被底部工具栏盖住

两个叠加根因，均为 iOS 特有行为：

- **dvh 在 fixed 弹窗场景拿到大视口值**：iOS Safari 的 `dvh` 不随悬浮工具栏状态实时更新（页面本身不滚动时永远拿工具栏收起的大视口高度），弹窗限高虚高 → 顶部标题被屏幕顶边裁掉一截
- **`env(safe-area-inset-bottom)` 只算 Home 指示条**：iOS Safari 悬浮底部工具栏（约 83px）不在安全区数值里，fixed 弹层又不触发工具栏收起 → 贴底的取消/保存按钮被工具栏盖住

修复方案（纯 CSS，全部弹窗统一受益）：

- 限高改用 **`svh`**（small viewport height，恒按「工具栏展开」的最小可视高度计算）——弹窗高度永远落在最保守的可视范围内，顶部不再被裁
- 新增 `.pb-sheet` 底部 padding：`max(0px, 100dvh - 100svh)` 差值 = 当前工具栏占据的高度，工具栏展开时让开、收起后自动贴合；旧内核浏览器回退 `env()` 版
- 同步为**所有依赖 dvh 的弹窗加了 `@supports` 兜底链**：不支持 dvh/svh 的旧内核浏览器（Chromium <108 等）回退 `vh` 版限高，不再整条声明失效导致弹窗无限高

### 2. 注册/登录页底部「用户协议/隐私声明」被裁切

生产实测定位：登录卡片被外层 flex 布局挤压（内容 741px 被压到 713px），卡片自身 `overflow-hidden` 直接把底部协议行裁掉一截；表单区还嵌套在过小的内部滚动区。修复为「卡片整体限高 + 头部固定 + 表单区滚动」结构（与弹窗同款已验证模式），协议行滚到底完整可见，桌面居中不受影响。

- `client/src/components/model-admin/ConversionQueuePanel.tsx` / `client/src/components/inquiry/InquirySalesAssignmentDialog.tsx` / `client/src/components/category-nav/NodeCategoriesModal.tsx`：遮罩 padding 与面板限高统一到 `.pb-sheet` / `.dialog-safe-max-h`（间距变体合并为同款）

## 审计确认

- 纯前端改动：无后端、无数据库 schema、无迁移、无新增依赖
- 视觉等价性：支持 svh/dvh 的现代浏览器中，限高值与 v6.1.7 的 dvh 版在工具栏收起时一致、展开时更保守（弹窗略矮但完整可见）；桌面（无动态工具栏）行为完全不变
- pb-sheet 依赖 unlayered CSS 覆盖 Tailwind utilities 的级联顺序（与既有 `[data-selection-category-card]` 先例同款做法）
