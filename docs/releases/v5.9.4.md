# v5.9.4

发布日期：2026-10-20

## 更新标题

3DPartHub v5.9.4 - 全站安全审计加固（依赖漏洞清零 + 前端 URL 协议白名单统一 + 密码保护分享元数据收紧 + Sentry 上报脱敏）

## 更新描述

对全站做了一次系统性安全审计——覆盖认证/授权（40+ 路由文件全量核对）、SQL/命令注入、路径遍历、文件上传、XSS、CSRF、SSRF、IDOR、安全响应头、部署配置与依赖供应链。审计确认核心链路无可利用的高危漏洞（授权纪律、SSRF 的 DNS rebinding 防护、上传魔数白名单等基建扎实），本版把审计发现的全部中低危缺口逐项修复加固。

## 修复清单

### 1. 依赖漏洞清零（npm audit）

- server 生产依赖树 critical/high 清零：proxy-addr（critical，IP 欺骗）、compression（high，响应中断内存泄漏）、nodemailer 升 v10（high，SMTP 凭据跨租户泄露等多项）、ip-address、brace-expansion；email.ts 适配 v10 类型导出
- client：brace-expansion（high）修复
- 剩余记录：minio 依赖链 4 条 moderate（攻击面仅限管理员自配的 S3 端返回恶意数据，修复需 breaking 降级，暂缓）；patch-package 链为 dev-only 不进产物

### 2. 前端 URL 协议白名单统一（防 javascript:/data: 注入）

- `openBrowserDocument` 入口统一过 `isSafeUrl`：全站画册/附件/图纸/选型分享页 pdfUrl 的「新窗口打开」全部汇经此一处（站内 /api 路径与 http/https 不受影响）
- 选型分享页 pdfUrl 按钮、系统设置页 GitHub Release 链接 ×3、工单/询价附件链接补齐校验（与选型结果卡既有防护对齐）
- 页脚友情链接改在数据源 `getFooterLinks` 统一过滤（首页/主题模板/移动端三个消费点一次覆盖，管理后台编辑表单不受影响）

### 3. 密码保护分享的元数据收紧

- `GET /api/shares/:token/info` 此前仅 gltfUrl 受密码门控，description/缩略图/图纸文件名清单未验证密码即返回；现与 gltfUrl 同口径收在密码验证之后。无密码分享行为不变，密码墙页面不受影响（验证密码后自动带访问令牌重新拉取完整信息）

### 4. RAR 批量上传解压纵深防御

- 解压后实测遍历临时目录，断言所有产物真实位于目录内，越界即终止任务（zip-slip 同款防御，不再仅依赖解压库对条目名的处理承诺；ZIP 分支原有校验不变）

### 5. Host 头投毒防护 + Cookie secure 生产默认

- 新增 `SITE_URL` 配置：设置后邮件/通知里的链接一律用它，不再从请求头 Host/X-Forwarded-Host 推断（防应用端口绕过反代直连时，密码重置等带 token 的链接被改写到钓鱼域）
- docker-compose 生产默认 `AUTH_COOKIE_SECURE=true`：HTTPS 反代下登录 Cookie 自动带 secure 标志

### 6. 备份下载令牌收紧

- 备份下载 token 有效期 24 小时 → 8 小时（URL 泄漏暴露窗口压到 1/3；多线程下载工具/断点续传兼容性保留，下载端回库复核签发者身份的护栏不变）

### 7. Sentry 错误上报脱敏

- 错误事件的 breadcrumb（fetch/xhr 请求轨迹）、event.request、tracing span 里所有 URL 统一剥掉 query 参数——`share_access_token`/`download_token` 等一次性凭据不再发往第三方（token 只活几分钟，但错误事件在 Sentry 留 90 天）

## 审计确认无问题的关键面（未改动）

认证链路（防爆破/防账号枚举/token 轮换与吊销/字段白名单）、全部路由守卫与资源归属校验（无 IDOR）、SQL 全参数化、子进程全数组参数无 shell、上传（魔数白名单/服务端生成文件名/大小熔断/解压限额）、自研 HTML sanitizer 覆盖全部注入点、CSRF（SameSite=lax + 严格 CORS 白名单）、SSRF 防护（禁内网段 + DNS rebinding 防护 + 拒绝重定向）、CSP/HSTS 响应头、备份 AES-256-GCM 加密、.env 未入库且 .dockerignore 覆盖完整、生产 sourcemap 关闭。

## 验证

- 三层 verify 全绿：client（主题契约/typecheck/lint/构建/33 测试）、server（typecheck/193 测试 fail 0）、仓库根 verify:deploy
- 复查专项：isSafeUrl 全部调用点误伤排查（无 blob:/data: 合法用法被拦）、分享密码墙渲染流与验证后重拉闭环、页脚链接管理表单不受数据源过滤影响、RAR 遍历规模评估

## 升级说明

- 无数据库迁移（schema 未变更）
- **服务器 .env 建议增加一行**（防钓鱼链接，强烈建议）：
  ```bash
  SITE_URL=https://你的域名
  ```
- `AUTH_COOKIE_SECURE` 已默认开启：HTTPS 反代访问不受影响；**纯 HTTP 方式访问（http://服务器IP:3780）更新后将无法登录**，如有这种访问方式请在 .env 显式设 `AUTH_COOKIE_SECURE=false`
- 服务器更新（标准自动流程）：
  ```bash
  cd /opt/3dparthub
  docker-compose pull
  docker-compose up -d
  ```
  更新后强制刷新浏览器（Cmd+Shift+R / Ctrl+Shift+R）
- 上线后验收：
  - 正常登录、模型/画册打开、分享页密码墙输密码后信息完整
  - 系统设置 → 数据备份：下载备份正常（令牌 8 小时内有效）
  - 首页页脚友情链接正常显示（若此前配置过 javascript: 等异常协议的链接会被过滤不显示）
