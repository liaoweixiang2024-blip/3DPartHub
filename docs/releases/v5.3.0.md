# v5.3.0

发布日期：2026-10-06

## 更新标题

3DPartHub v5.3.0 - 移动端滑动误触反馈彻底修复（选型导航产品大类卡不再粘色/向导选项弹跳动画移除）+ 批量生成产品组合支持「代码|显示名」语法（型号拼代码、参数存显示名，空代码自动收缩分隔符）

## 标签描述

v5.3.0 finishes the mobile scroll mis-touch fix and adds model-code mapping to the bulk product generator. On iOS, WebKit keeps :hover/:active styles stuck on the card under the touching finger for the entire drag, so any press-feedback style inside a scrollable area looks like a phantom "selected" state. v5.2.9 fixed the selection page category list; this release sweeps the rest: the category-nav page product cards (the real culprit - hover lift + colored shadow stuck on the touched card) are now desktop-only (min-width 768px), and the selection page wizard option buttons, frozen-header breadcrumbs, selected-params strip and inquiry rows drop their hover/press-scale feedback on mobile. Desktop hover effects are unchanged. The selection admin "batch generate" modal now accepts `code|label` per option line: the code goes into the generated model number (e.g. `02` for `2分 (1/4)`), the label is stored as the spec value shown to users; an empty code (e.g. `|无球阀开关`) means the segment is omitted from the model and consecutive separators collapse automatically (`4M--02` becomes `4M-02`). Plain option lines behave exactly as before. Covered by 13 new unit tests. No database migrations.

## 更新描述

本次为 **移动端体验修复 + 管理端功能增强** 版本，无数据库迁移，更新前后端镜像即可。

## 移动端滑动误触彻底修复

### 问题

- v5.2.9 修复了选型页分类列表的滑动粘色，但仍有两处残留：
  - **选型导航页（/category-nav）产品大类卡**：滑动时按住的那张卡全程上浮 + 主色投影 + 标签变主色，像被选中（真元凶——该页当时未处理）
  - **选型页向导选项按钮**：按下缩小、抬手弹回的「弹跳动画」（active:scale 在滑动手势下粘滞）
  - 另有已完成步骤卡底色、冻结头面包屑、横向已选参数条、询价清单行/底栏按钮等约 20 处同类按压/悬停反馈

### 根因与修复

- iOS WebKit 触摸滚动时 `:hover`/`:active` 全程粘在手指落点元素上不释放（Chromium 会释放，模拟器无法复现，只能机制分析）
- **修复原则**：移动端（<768px）可滚动区域内一律不挂 hover/active:scale/group-hover；点击确认由选中态高亮承担
- `.hover-card` 的 `:hover` 效果用 `@media (min-width: 768px)` 门控（不用 `(hover:hover)` 查询——触摸主指针设备插鼠标会被误杀）；Tailwind 类用 `md:` 前缀/`isDesktop` 条件拆分
- 桌面端 hover 上浮、投影、变色效果全部保留

### 验证

- Playwright 触摸模拟（CDP dispatchTouchEvent 按下→拖动→抬手全程探针 computed style）：大类卡 transform/filter/标签色纹丝不动
- 遍历 styleSheets 确认 `.hover-card:hover` 规则被 `min-width: 768px` 包裹（移动端 CSS 不可达）
- 桌面视口鼠标 hover 仍正常上浮 `translateY(-2px)`

## 批量生成「代码|显示名」语法

### 问题

- 很多系列的型号段是代码（如外螺纹接头 `02/03/04/06`、球阀 `MK`、前段选配 `GL/N`），但参数值是给人看的显示名（`2分 (1/4)`、`有球阀开关`、`过滤装置`）
- 原批量生成直接拿参数值拼型号，生成 `SQB-PAU1208-6M-2分 (1/4)` 这种错误型号

### 方案

- 选项框每行支持 `代码|显示名`（如 `02|2分 (1/4)`）：**型号模板用代码渲染，参数值存显示名**（选型页展示/匹配不受影响），名称模板仍用显示名
- 竖线前留空（`|无球阀开关`）表示该段不进型号，自动收缩多余分隔符（`4M--02` → `4M-02`，首尾横线也裁干净）
- 不写竖线的行 code=值，行为与旧版完全一致（向后兼容）；排除规则仍按显示名匹配
- 无空段时不收缩字面连续横线（不破坏故意写的分隔符）

### 验证

- 13 个新增单测全过：代码/显示名分离、空代码收缩（首/中/尾三种位置）、球阀 MK 场景、名称模板用显示名、排除规则按显示名、旧语法回归
- client `npm run verify` 全链绿（测试 33/33、tsc、lint 0 错误、格式检查、构建）
