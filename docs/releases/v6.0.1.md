# v6.0.1

发布日期：2026-10-22

## 更新标题

3DPartHub v6.0.1 - 用户弹窗补「分享」统计卡与登录记录折叠修复、「注册于」图标补映射；移动端动画手感大修——侧滑抽屉/导航抽屉常驻挂载+弹簧曲线、模型详情页上滑 sheet 从 height 动画改为纯 GPU 位移（低端机「卡一下再滑」根因清除）

## 更新描述

本版是 v6.0.0 后的体验修补批次，主线是移动端交互动画手感。① 用户编辑弹窗：「最近登录」折叠失效根因在后端只下发 5 条（正好等于折叠条数，展开按钮永不出现），改为与操作记录同取 30 条；新增「分享」统计卡（下载/收藏/分享三个一行），分享数为该用户创建的模型分享链接数；「注册于」卡片图标不显示是 lucide 映射表缺 event 键（渲染成空格子），已补 Calendar 映射。② 移动端侧滑抽屉（导航+首页分类）此前点击瞬间才创建 DOM，首帧要同时建整棵分类树+算样式+启动动画，低端机掉帧表现为「卡一下再滑」——改为常驻挂载（关闭态 visibility:hidden 不参与绘制），打开首帧零构建、只剩合成器位移；动画曲线从 0.28s 长尾减速（结尾近乎爬行、感知黏滞）改为弹簧物理，与 iOS 原生侧滑一致；同时修复 aria-hidden 焦点告警（改用 inert 属性+关闭时主动移焦）。③ 模型详情页/临时查看页的上滑 sheet 此前动画 height 属性——每帧重新布局整棵内容树（规格/文件列表/相关模型），是三处动画中最重的一处——改为固定高度+translateY 位移（纯 GPU），展开内容常驻渲染消除展开瞬间挂载，顺带修复收起再展开丢滚动位置的问题。

## 变更清单

### 1. 用户编辑弹窗（用户管理）

- **登录记录折叠修复**：后端登录日志 take 5 → 30（与操作记录对齐）；此前「显示全部 N 条」按钮因数据正好 5 条永不出现
- **新增「分享」统计卡**：下载 / 收藏 / 分享 三个一行；注册时间挪至第二行（注册/最后登录/最后活跃）；分享数 = 该用户创建的模型分享链接数（后端 `_count.shareLinks` 下发），实测与数据库一致
- **「注册于」图标修复**：Icon 组件是 lucide 映射表而非 material 字体，`event` 名缺映射渲染成空格子——补 `event → Calendar`

### 2. 移动端侧滑抽屉（导航 + 首页分类）

- **常驻挂载**：抽屉 DOM 页面加载时建好、关闭态 `visibility: hidden`（不绘制/不参与合成/不响应命中测试），打开首帧零 DOM 构建与布局——条件挂载在低端机首帧建整棵树超时是「卡一下」的根因
- **动画改弹簧**：0.28s emphasized 长尾曲线（结尾近乎爬行、感知黏滞）→ 与弹窗同款弹簧物理（无固定时长、快速到位无长尾）；实测 80ms 内滑完 67% 路程
- **无障碍告警清零**：`aria-hidden` 包住仍持焦点的关闭按钮触发浏览器告警——改用 `inert` 属性（自动清理焦点+完整可访问性语义）+ 关闭时主动 blur 兜底
- 覆盖：interfaceThemes/mobileThemes 两套导航抽屉渲染器 + 首页分类 MobileDrawer；遮罩保持轻量条件渲染

### 3. 模型详情页 / 临时查看页上滑 sheet

- **height 动画 → translateY 位移**：height 过渡每帧 layout 整棵内容树（规格/文件/相关模型，三处动画中最重）；固定 94% 高 + translateY(calc(100% - peek)) 纯 GPU 合成
- **展开内容常驻渲染**：原来收起态 `display:none`、每次展开瞬间挂载整棵内容树首帧双重负担；改为常驻 + `inert`（与抽屉同款）
- **顺带修复**：收起再展开不再丢滚动位置（display:none 切换会重置 scrollTop）
- 手势拖拽（上拉展开/下拉收起/回弹限位）逻辑原样保留，拖拽位移与基础位移合成实测正确

### 4. 性能取舍说明（常驻挂载）

进页面时一次性渲染隐藏抽屉（分类树约 200 节点、几毫秒级、混在加载期不可感知），换来每次打开零构建；关闭态不占渲染帧，常驻内存约 1-2MB 合成层纹理。若后续实测进详情页变慢，备选「页面空闲时预挂载」方案。
