# v6.0.0

发布日期：2026-10-22

## 更新标题

3DPartHub v6.0.0 - 系统设置「所见即所得」大修：上传限制死字段清零与隐形限制补全、邮件模板编辑器改版（显示修复+下拉分组+补 2 缺失模板）、新增站点级邮件发送开关（默认只发验证码类）、用户弹窗折叠、个人通知偏好按角色分化；发布前双代理全量安全/质量审查加固

## 更新描述

本版对系统设置与通知体系做了一次「显示必须等于实际」的全面校准。① 后台「上传与限制」此前存在双数据源错位：编辑器里的工单附件字段是被个体设置覆盖的死快照（显示 5MB、实际执行 100MB），另有三个真实生效的限制没有界面可改。本版以个体设置为唯一权威、死键保存时自动剥离、补齐三个隐形字段、新增附件数量上限设置。② 邮件模板编辑器三处显示缺陷（名称显示原始代码、主题框显示 i18n key、5 个管理员模板实为「仅站内」却无标注）全部修复，左侧长列表改为分组下拉（重要事务置顶），并补上服务端在用但编辑器缺失的换绑邮箱/密码重置两个模板。③ 新增站点级「邮件发送开关」：按「邮件=重要事务」的产品方向，通知类邮件（工单/询价/收藏/转换/下载）默认只进站内通知中心，需要邮件的管理员可在后台按类开启；验证码、密码重置等必要邮件不受影响、始终发送。④ 用户编辑弹窗操作记录默认折叠 5 条防撑爆；⑤ 个人设置通知偏好按角色分化（普通用户隐藏仅管理员可见的备份项、管理员隐藏对其无意义的邮件列）。发布前对全部 25 个文件改动做了双代理并行审查（服务端安全 + 客户端质量），2 个 Medium（公开下发未夹取、stale closure）及全部 Low/Nit 已修复。

## 变更清单

### 1. 上传与限制：显示 = 实际

- **死字段移除**：编辑器里「工单附件上限 MB / 工单附件格式」两个字段是被个体设置覆盖的死快照（此前出现显示 5MB、实际 100MB），移除后同 tab 个体设置字段为唯一真入口
- **死键剥离**：保存设置时自动从 `upload_policy` JSON 剔除被个体设置覆盖的 6 个键，数据库不再残留误导性快照
- **补 3 个隐形限制**：模型图纸 PDF（500MB）/ 批量上传压缩包（50GB）/ 选型迁移包（200MB）——此前服务端在执行但后台无 UI 可改
- **新增「工单附件数量上限」**（默认 5，1-20）：此前前后端硬编码，工单/询价创建页的提示文案现跟随设置实时变化
- **写入侧夹取**：上传限制个体键（附件大小/数量、图片墙三项）在写入时即夹取到与执行侧相同范围，API 直存越界值不再产生「显示值 ≠ 执行值」（实测 999→20、-5→1）
- **语义澄清**：工单附件描述注明「工单与询价共用」；图片墙单图上限注明「同时适用于模型封面图」（五语言）

### 2. 邮件模板编辑器改版

- **显示修复**：模板名称此前大部分显示 `adminSettings.xxx` 原始代码（渲染漏了 t() + 历史快照污染），现全部正常翻译显示；主题输入框从 i18n key 改为文案直存（所见即所得）
- **补 2 个缺失模板**：换绑邮箱验证码、密码重置——服务端在发送但客户端注册表缺失，编辑器里此前根本看不到
- **下拉化 + 分组**：左侧长列表改为分组下拉（SelectMenu 新增分组标题项支持），四组重排：重要事务邮件（始终发送）置顶 → 系统运维 → 通知类·发用户 → 通知类·发管理员
- **收件人标注**：全部 20 个模板名称带「（发用户/发管理员/发上传者）」后缀，成对模板（如「询价提交通知」vs「新询价提醒」）不再貌似重复
- **「仅站内」标注**：5 个收件人为管理员的模板（新询价/新工单提醒、用户回复提醒、备份体检）带徽标与说明——这类模板只生成站内通知、永不发邮件
- **快照防污染**：双端模板合并改为 label/description 始终以注册表为准，历史 DB 快照不再压住注册表改名

### 3. 邮件发送开关（新）

- 后台「邮件服务」新增「邮件发送开关」区块（5 个开关，标题明确标注「只管邮件，站内通知不受影响」）
- **通知类邮件默认全关**：工单/询价/收藏/转换/下载类事件默认只进站内通知中心，不发邮件；需要哪类在后台打开
- 三层控制架构：验证码类（注册/换绑/找回/测试）始终发送 → 站点开关（管理员全局控制）→ 收件人个人偏好（个人设置自助细化）
- 行为级实测：两层 AND 组合矩阵全过（站点关→邮件停/站内照发；双开→邮件真实发出；个人邮件关→停；个人站内关→站内不产生）

### 4. 用户编辑弹窗折叠

- 「最近管理操作」（最多 30 条）此前全部平铺撑爆弹窗，现默认显示 5 条 + 「显示全部 N 条」展开（限高滚动）+ 可收起；「最近登录」同样机制

### 5. 个人通知偏好按角色分化

- 普通用户：隐藏「备份通知」（仅管理员会收到的死开关），站内+邮件双列 + 语义说明
- 管理员：含备份项、仅站内列 + 「管理员通知仅站内显示」说明
- auth 未水合时按完整列表渲染，管理员首帧不闪变

### 6. 审查加固（发布前双代理全量审查）

- 服务端：无 Critical/High；修复公开下发未夹取（Medium）、注释与默认值相反（Low）
- 客户端：无 Critical/High；修复工单附件预检 stale closure（Medium）、清理 95 行孤儿翻译 key（19 个旧 key × 5 语言）、t() 查询噪音、个数语义 helper 正名
- 已核无问题方向：邮件开关键名注入面（全部来源为服务端字面量）、设置白名单类型化、上传策略保存白名单 13 字段零遗漏、i18n 五语言逐 key 零缺口、老库快照兼容无 undefined 传播

## 审计确认

- 无数据库 schema 变更、无迁移（settings 为 key-value 存储，新键自动生效）
- 新增出网请求：无
- 行为变更说明：存量站点部署后，通知类邮件（工单/询价/收藏/转换/下载给用户的确认与提醒邮件）默认停发、改走站内通知中心——需要邮件的管理员到「系统设置 → 邮件服务 → 邮件发送开关」按类开启；验证码/密码重置不受影响

## 服务器更新

```bash
cd /opt/3dparthub
docker-compose pull
docker-compose up -d
```

- 全部为前后端代码改动，无配置/数据库操作
- 部署后如需恢复某类通知邮件，到「系统设置 → 业务内容 → 邮件服务」打开对应开关
- 浏览器强制刷新（Cmd+Shift+R / Ctrl+Shift+R）
