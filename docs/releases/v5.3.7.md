# v5.3.7

发布日期：2026-10-07

## 更新标题

3DPartHub v5.3.7 - 用户管理新增「新增用户」（角色分段选择器 + 随机临时密码 + 首登强制改密）+ 管理员直改任意用户邮箱（旧邮箱收不到验证码的死局解法）+ 版本更新记录乱码修复（跨 TCP 分块的中文字符被拆成 ���）+ 排序下拉站点风格化

## 更新描述

本次为**用户管理增强**版本，无数据库迁移（schema 未变更），更新前后端镜像即可。

## 改动一：管理员新增用户

- **背景**：用户管理只能编辑/删除已有用户，没有新增入口；注册通道受「允许注册/邀请码/邮箱验证码」三层开关约束，管理员想直接开账号（如给新同事开内部账号）无路可走
- 工具栏新增「**新增用户**」按钮 → 弹窗表单：用户名 / 邮箱（登录账号）/ 角色 / 公司 / 部门 / 电话
- **角色分段选择器**：4 个角色按钮直接点选（不展开下拉），选中态深色反白，无多余装饰
- **随机临时密码**：一键生成 12 位 crypto 随机密码（剔除易混淆字符），带复制按钮方便转交；默认勾选「首次登录强制改密」
- **服务端**（`POST /api/admin/users`，仅 ADMIN）：与注册**同一套校验策略**（用户名长度/字符集、密码长度、邮箱/手机号格式，读安全设置）+ 重名重邮箱 409；管理员操作可信：免邮箱验证码、免邀请码；非法角色回退访客；操作入审计日志

## 改动二：管理员直改用户邮箱

- **背景**：个人设置的「换绑邮箱」是防盗号双向验证（旧邮箱验证码 + 新邮箱验证码）——当旧邮箱是收不到邮件的默认邮箱（如种子账号 `admin@model.com`）时，第一步就走不通，**等于无解**
- **方案**：用户编辑弹窗顶部新增「邮箱（登录账号）」输入框，管理员可直接改任意用户的邮箱
- 安全边界：
  - 仅 ADMIN 可操作（普通用户改自己仍走双向验证，防盗号设计不受影响）
  - 格式强校验 + 占用查重（409），传入相同邮箱零副作用（不误登出）
  - 邮箱是登录凭证：改后该账号登录态作废，需用新邮箱 + 原密码登录（与自助换绑行为一致）
  - 每次修改入操作审计日志
- 管理员改**自己**的邮箱时，本地界面同步显示新邮箱

## 改动三：排序下拉站点风格化

- 用户管理的排序原生 `<select>`（系统样式突兀、展开跳系统面板显卡顿）→ 自定义下拉组件 `AdminSortMenu`（shared）：触发按钮与工具栏其他按钮同款样式，浮层淡入缩放动画、当前项打勾、点外收起
- 后续其他管理页可直接复用该组件

## 改动四：版本更新记录乱码修复

- **现象**：关于系统页版本时间线里**部分**版本（如 v5.3.0、v5.3.1）的标题描述显示 `���`
- **根因**：拉取 GitHub Releases 的响应按 TCP 分块到达，旧代码逐块 `data += chunk`（每块各自隐式转 UTF-8）——恰好跨在分块边界的中文字符（3 字节 UTF-8）被拆成两段无效字节，各自变成替换符 `�`。是否中招纯看运气（哪个版本的正文里有汉字恰好落在块边界），与 GitHub 数据、浏览器渲染都无关
- **修复**：先攒完整 Buffer 再一次性按 UTF-8 解码（`update.ts` `fetchJsonFromGithub`），边界永远不会再切在字符中间
- 顺带修时间线布局：长标题不再把一条记录撑成多行，改为单行「版本号徽章 + 日期 + 截断省略标题 + 展开箭头」
