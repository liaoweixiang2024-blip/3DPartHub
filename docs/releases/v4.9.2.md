## 更新标题

3DPartHub v4.9.2 - 路由骨架补齐标题描述 + 个人设置标题卡去抖动（移动端切换体验）

## 标签描述

v4.9.2 polishes the route-transition experience introduced in v4.9.1. The title-stable route skeleton now carries the exact description text of each page's header card (all 20 mapped routes, admin pages included), so the skeleton-to-page handoff is seamless — previously the title appeared first and the description line popped in a moment later, visibly growing the header. 个人设置 (personal settings, mobile) no longer jitters on entry: its header card was the only one wrapped inside the animated PageBody container (220ms slide-up + fade); it now sits outside the animation like every other management page — the header stays still while only the content below animates in. Frontend-only release, no database migration.

## 更新描述

本次为 **移动端页面切换体验打磨** 补丁，纯前端改动，无数据库迁移，前后端镜像均需更新。

**① 路由骨架补齐标题描述（修复「先出标题、再补描述」跳变）**

- v4.9.1 的路由加载骨架只渲染标题，真实页面挂载时描述行才插入，标题卡会先矮后高跳一下
- 骨架现在携带与各页面逐字一致的标题 + 描述（个人设置/我的收藏/下载历史/工单/全部后台页等 20 个路由），骨架 → 真实页面无缝衔接

**② 个人设置标题卡去抖动**

- 根因：个人设置的标题卡被包在带 220ms 上滑+淡入动画的容器里，是全站唯一，切入时标题卡整体上滑造成抖动
- 修复：标题卡移出动画容器，与其他管理页一致 —— 标题静止、只有内容区进场动画
