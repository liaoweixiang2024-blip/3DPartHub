## 更新标题

3DPartHub v4.8.0 - 产品图库后台大改版（真分页/回收站/上传权限/独立管理页）+ PDF 交互统一

## 标签描述

v4.8.0 is a major feature release for the product image gallery (产品图库). The admin panel moves from an in-page dialog that eagerly loaded the entire library to a dedicated admin page (`/admin/product-wall`) with true server-side pagination and infinite scrolling (40/page), plus a full recycle-bin workflow: deleted images are soft-deleted and kept for 30 days (`deleted_at` migration included), restorable or permanently purgeable, with automatic lazy sweeping. Upload permission is now a two-layer whitelist (role whitelist + designated user whitelist) enforced server-side (403) and reflected in login/profile responses. The upload dialog is rebuilt to match the model-upload experience (drag & drop with confirmation, per-file rename, folder upload, zip auto-extract, batched progress). A long-standing mojibake bug on Chinese filenames across all 14 upload endpoints is fixed (multer `defParamCharset: utf8`). The front gallery also switches to infinite scrolling with server-side kind/search filtering and a dedicated counts endpoint. This round also polishes the admin toolbar (custom-styled category dropdown replacing the native select, reordered controls, sticky tabs on both ends, floating batch-action bar, fixed first-tab-switch width jump via stale-while-revalidate + `scrollbar-gutter: stable`). Finally, PDF drawing rows are unified across model detail (desktop & mobile) and share pages: clicking the row opens the inline viewer, the right-side button downloads the file (same style as the STEP download button). Includes one Prisma migration (`20260914071211_product_wall_trash`). After upgrading, add the 图片管理 entry to the admin navigation in 后台 → 导航管理 if your database already stores a custom admin nav (see upgrade notes).

## 更新描述

本次为 **产品图库大改版 + PDF 交互统一** 版本，含 1 个数据库迁移，前后端镜像均需更新。

**① 图库后台管理：从弹窗迁移为独立后台页面 `/admin/product-wall`（图片管理）**

- 全新「图片管理」后台页：状态 tabs（全部/待审核/已通过/已拒绝/回收站）+ 搜索 + 分类筛选 + 批量操作 + 管理分类，工具栏吸顶、手机端全屏适配
- 服务端真分页 + 无限滚动（40/页），告别全量拉取导致的浏览/操作卡顿；缩略图懒加载
- 批量操作升级：选择模式跨搜索/翻页保留已选、批量删除（进回收站）、批量移动分类；操作条吸底悬浮，不用滚到底也能操作
- 「管理分类」弹窗：点击分类筛选 + 重命名/删除/新建，美化样式

**② 回收站（软删除）**

- 删除的图片进入回收站保留 30 天，可恢复或彻底删除；过期自动惰性清理
- 新增数据库迁移 `20260914071211_product_wall_trash`（`deleted_at` 字段 + 索引），部署时自动应用

**③ 上传权限白名单（后台 → 设置 → 上传与限制）**

- 角色白名单（管理员/编辑/内部/普通用户）+ 指定用户白名单（搜索添加，不受角色限制）
- 服务端强制校验（无权限 403），登录/注册/资料接口返回 `canUploadProductWall` 控制前端按钮显隐；管理员始终可传

**④ 上传弹窗对齐模型上传体验**

- 拖拽/粘贴先弹窗确认；待传列表可重命名（保留扩展名）；支持选择文件夹、zip/rar 自动解压；分批上传带字节进度与速度；非管理员必填标题/描述（进待审核）

**⑤ 性能与修复**

- 前台图库同步改为无限滚动（50/页）+ 服务端分类/搜索过滤 + 专用计数接口，进页不再全库预取
- 修复中文文件名乱码（GBK 鏀瑰悕鍚庣殭 一类）：全站 14 处上传端点启用 UTF-8 文件名解码
- 修复公开接口 60s 浏览器缓存导致上传后计数不刷新（列表/计数请求带时间戳击穿）
- 修复后台切 tab 首次点击整条 tabs 左右拉伸（列表换数据不塌陷 + 滚动条预留 gutter）
- 后台所有列表页空/长内容切换不再引起宽度跳动（`scrollbar-gutter: stable`）

**⑥ PDF 图纸交互统一（详情页 + 分享页，PC 与手机一致）**

- 点击 PDF 文件行 → 弹窗在线查看；右侧按钮 → 下载 PDF 文件（与 STEP 文件下载按钮同款样式）
- 覆盖：模型详情页（PC/手机）、模型分享预览页（PC/手机底部抽屉）

## 升级步骤

```bash
cd /opt/3dparthub
docker-compose pull && docker-compose up -d --force-recreate
```

> **注意（一次性）**：若生产数据库已保存过后台导航设置（`nav_admin_items`），新菜单项「图片管理」（`/admin/product-wall`，仅管理员）不会自动出现——请到 **后台 → 导航管理** 手动添加；未自定义过后台导航的站点会自动显示。升级后浏览器强制刷新（Cmd/Ctrl+Shift+R）。
