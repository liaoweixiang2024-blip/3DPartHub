## 更新标题

3DPartHub v3.1.1 - 移动端分享预览与登录弹窗统一修复版

## 标签描述

3DPartHub v3.1.1 production release with unified auth dialogs across themes, corrected auth prompt routing, smoother mobile model/share previews, safer native sharing, and refreshed Docker images.

## 更新描述

- 统一 PartHub 经典版与 PartHub 工作台的登录/注册弹窗外壳，注册表单在两个主题下保持一致。
- 修复登录提示弹窗总开关与页面内下载、收藏、申请等登录动作的判断分流，关闭/开启逻辑更稳定。
- 优化移动端模型详情和模型分享预览的底部下载区域、模型居中与安全区间距，减少抽屉与底部菜单割裂感。
- 修复选型分享连续触发原生分享时的 InvalidStateError，增加分享中状态避免重复调用。
- 优化系统设置标题菜单右对齐与保存状态宽度，减少保存后菜单轻微抖动。
- 微调后台管理通用标题、表格和主题弹窗样式，让新旧主题交互保持一致。
- 发布前验证通过前端类型检查、构建和格式检查。
- 镜像已同步更新：api/web 均发布 v3.1.1 与 latest 标签。

Web image title: `3dparthub-web:v3.1.1`

Web image: `ghcr.io/liaoweixiang2024-blip/3dparthub-web:v3.1.1`

Web image description: React/Vite frontend for theme-driven model libraries, unified auth/register dialogs, mobile model/share previews, 3D viewing, product selection sharing, upload progress, batch downloads, product gallery browsing, inquiry/quote workflows, profile management, admin pages, legal pages, and responsive mobile flows.

```bash
# Default deployment follows latest and uses Watchtower for api/web auto-updates.
# Run this when you want to update immediately:
cd /opt/3dparthub
curl -L -o docker-compose.yml https://raw.githubusercontent.com/liaoweixiang2024-blip/3DPartHub/main/docker-compose.yml
touch .env
grep -q '^IMAGE_TAG=' .env && sed -i 's/^IMAGE_TAG=.*/IMAGE_TAG=latest/' .env || echo 'IMAGE_TAG=latest' >> .env
docker-compose pull
docker-compose up -d --force-recreate

# Verify health
curl http://localhost:3780/api/health
```
