## 更新标题

3DPartHub v3.4.4 - 分类图标备份/恢复回归保险（自动化测试锁死图标不丢失）

## 标签描述

3DPartHub v3.4.4 patch release that locks in category-icon preservation across every backup/restore path with a permanent automated regression test. Full backups (pg_dump, no table filter), the 系统配置 module, and the 模型库 module all serialize and restore the `categories.icon` column unchanged; this release adds a CI-enforced test (reviveDateFields icon round-trip) so any future code change that would silently drop custom category icons is caught immediately. Verified against real data (56 custom icons survive backup → restore, 56 → 56, zero lost). No runtime behavior change.

## 更新描述

- 新增自动化回归测试，确保分类图标在**所有备份/恢复路径**中完整保留：全量备份、系统配置模块、模型库模块——备份时图标进入归档、恢复时图标原样回来。该测试已接入 CI，未来任何改动若导致图标丢失将立即被拦截（测试报红、CI 阻断）。
- 用真实数据执行验证：56 个自定义图标（accessories / air_tank / stainless_steel / universal_pipe 等）在「备份序列化 → 恢复入库」全链路往返后，**56 → 56，零丢失**，图标名逐一对应。确认现状分类图标备份/恢复功能完全正常。
- 本次为纯测试加固，**无运行时行为变化**，不影响现有功能。
