## 更新标题

3DPartHub v2.9.8 - 移动端选型、产品图库与主题体验优化版

## 标签描述

3DPartHub v2.9.8 production release with smoother mobile selection flows, optimized product gallery thumbnails, refined interface themes, cache/storage settings, and refreshed Docker images.

## 更新描述

- 移动端选型页继续优化：分类/步骤切换更顺滑，回退步骤顶部对齐，自动选择项灰显禁用，数量口径改为选项数量，搜索框与已选状态分层展示。
- PC/移动端选型交互统一细节，减少分类切换、结果加载和已选参数变化时的抖动。
- 产品图库补齐服务端缩略图生成、缓存复用、列表预览与详情原图加载策略，降低大图解码和瀑布流滚动卡顿。
- 模型详情骨架屏、移动端抽屉动画、3D 查看器全屏/手势细节和分享预览显示继续打磨。
- 规格查询移动端表格增强固定表头/首列、方向锁定、长规格截断，减少横纵滚动混乱。
- 新旧主题隔离继续加固，新主题页头、侧栏、首页模型库、模型详情和分享页布局细节优化，旧主题保持原有行为。
- 后台询价、工单、图标按钮、导出操作、快捷词和底部输入框体验持续统一。
- 系统设置缓存与云存储配置、图片资源策略和连通性测试相关接口继续完善。
- 后端产品图库、模型管理、静态资源与版本检查相关逻辑同步加固。
- 镜像已同步更新：api/web 均发布 v2.9.8 与 latest 标签。

Web image title: `3dparthub-web:v2.9.8`

Web image: `ghcr.io/liaoweixiang2024-blip/3dparthub-web:v2.9.8`

Web image description: React/Vite frontend for 3D preview, mobile-friendly product selection, product gallery browsing, inquiry/quote workflows, sharing, profile management, admin pages, and interface themes.

```bash
# Default deployment follows latest and uses Watchtower for api/web auto-updates.
# Run this when you want to update immediately:
cd /opt/3dparthub
curl -L -o docker-compose.yml https://raw.githubusercontent.com/liaoweixiang2024-blip/3DPartHub/main/docker-compose.yml
touch .env
grep -q '^IMAGE_TAG=' .env && sed -i 's/^IMAGE_TAG=.*/IMAGE_TAG=latest/' .env || echo 'IMAGE_TAG=latest' >> .env
docker compose pull
docker compose up -d --force-recreate

# Verify health
curl http://localhost:3780/api/health
```
