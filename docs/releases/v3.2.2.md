## 更新标题

3DPartHub v3.2.2 - 多语言前台与移动体验增强版

## 标签描述

3DPartHub v3.2.2 production release with multilingual front-office coverage, localized legal/error/download flows, mobile navigation fixes, collapsible display menu behavior, backup/deploy hardening, and refreshed GHCR images.

## 更新描述

- 前台多语言覆盖继续完善：简体中文、繁体中文、英文、日文、韩文、德文资源 key 全量对齐，前台主流程补充日/韩/德译文，减少英文兜底。
- 法律页支持多语言默认正文：隐私声明和用户协议新增日文、韩文、德文版本；后台自定义法律条款仍优先显示。
- 通用错误和下载提示本地化：频率限制、网络失败、登录失效、无权限、资源不存在、上传过大、下载打包失败、下载未登录等前台提示会跟随当前语言。
- 移动端体验修复：左上角导航抽屉的工单入口改为“我的工单”，主题浅色/深色切换、语言选择和界面主题选择后下拉菜单会自动收起。
- 前台 i18n 架构完善：新增统一的前台翻译资源、导航文案、语言设置和本地化工具，后台管理导航继续按中文兜底。
- 模型详情、临时看图、选型、图库、询价、工单、个人资料、分享、下载和首页等前台页面持续接入多语言文案。
- 备份、部署、缩略图、Redis/存储测试、Safari/PWA、下载文件名、搜索别名等前序修复一起进入 v3.2.2 发布包。
- 发布前验证包含前后端类型检查、Lint、格式检查、生产构建、部署工具校验、Git 空白检查和前台 i18n key 完整性扫描。
- 镜像已同步更新：api/web 均发布 v3.2.2 与 latest 标签。

```bash
# 默认部署跟随 latest，并由 Watchtower 自动更新 api/web 镜像。
# 需要立即更新时执行：
cd /opt/3dparthub
curl -L -o docker-compose.yml https://raw.githubusercontent.com/liaoweixiang2024-blip/3DPartHub/main/docker-compose.yml
touch .env
grep -q '^IMAGE_TAG=' .env && sed -i 's/^IMAGE_TAG=.*/IMAGE_TAG=latest/' .env || echo 'IMAGE_TAG=latest' >> .env
docker-compose pull
docker-compose up -d --force-recreate

# 快速健康检查
curl http://localhost:3780/api/health

# 只读部署自检并生成报告
curl -fsSL -O https://raw.githubusercontent.com/liaoweixiang2024-blip/3DPartHub/main/scripts/deploy-health-check.sh
sh deploy-health-check.sh --report deploy-health-report.txt --json deploy-health-report.json

# 采集脱敏证据包用于支持和最终验收
curl -fsSL -O https://raw.githubusercontent.com/liaoweixiang2024-blip/3DPartHub/main/scripts/collect-deploy-evidence.sh
sh collect-deploy-evidence.sh
```

把 `deploy-evidence-*.tar.gz` 和同名 `.sha256` 回传到仓库后可执行：

```bash
npm run deploy:acceptance -- deploy-evidence-YYYYMMDD-HHMMSS.tar.gz
npm run deploy:report:verify -- deploy-evidence-YYYYMMDD-HHMMSS.tar.gz --max-age-hours 24 --summary deploy-health-acceptance.md --summary-json deploy-health-acceptance.json
```
