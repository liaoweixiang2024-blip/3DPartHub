# v5.8.4

发布日期：2026-10-15

## 更新标题

3DPartHub v5.8.4 - 移动端键盘态页面滚动锁死（选型两个搜索态外层不滚 + 底部导航键盘期彻底隐藏 + window 幻影滚动钳制）

## 更新描述

修复一组 iOS 移动端键盘态滚动问题：此前点搜索框弹出输入法后，页面可以被整体拖动、底部导航栏被拽到键盘上方飘着（退出搜索框又恢复锁定）。根因有二：一是 iOS WebKit 键盘态允许拖动 window（fixed 根被整体拖起的幻影滚动，页面本无合法可滚内容）；二是选型「查看全部」列表页的外层容器本就是滚动容器。本版三层修复：选型全页搜索与全站列表两态**页面本体完全锁死**（标题/搜索框/计数行钉死，内容在面板内部滚动）；键盘弹出期间底部导航 **visibility:hidden 彻底隐藏**（WebKit 再怎么重定位 fixed 元素也画不出隐藏元素，全站生效）；键盘态把 **window 钉回原点**钳制幻影拖动（全站生效）。

## 新增功能

### 1. 选型两个搜索态：页面本体锁死、内容内部滚动

- 全页搜索 + 「查看全部」全站列表：外层滚动容器 `overflow: hidden`，键盘弹出/收起、拖动都不会带动整页与底部导航
- 列表页升级为与全页搜索同款结构：标题卡 / 搜索框 / 计数行常驻顶部，产品卡在面板内滚动（滚到底自动翻页照常）
- 滑返回滚动位置恢复改走新的内部滚动容器（行为不变）

## 修复清单

- **键盘期底部导航飘到键盘上方**（全站）：键盘弹出期间导航 `visibility: hidden`——此前仅靠 `bottom` 偏移把它推出屏幕，WebKit 键盘态会把 fixed 元素重定位到可视视口，拖动时导航跟着被拽起；隐藏后无元素可画，机制性根治
- **键盘态 window 幻影滚动**（全站）：键盘开时 window 被拖离原点立即钉回（html/body 本就 `overflow:hidden` + fixed，文档没有合法可滚内容，此拖动纯属 WebKit 键盘态行为）
- **列表页外层滚动**：原布局列表在外层页面滚动（标题随滚动、键盘期可拖整页），现改内部滚动
