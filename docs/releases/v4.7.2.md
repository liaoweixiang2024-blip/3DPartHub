## 更新标题

3DPartHub v4.7.2 - 首页分类侧栏极限滚动抖动修复（Windows Chrome）

## 标签描述

v4.7.2 fixes a subtle but very visible jitter reported on Windows Chrome: after scrolling the desktop home model list to the very bottom, the entire category filter panel (all rows, icons and counts) would hop up by a sub-pixel and snap back whenever the wheel settled at the scroll limit. Root cause: the sticky-positioned sidebar's constraint boundary (the content grid's bottom edge) landed exactly at zero-pixel slack at maximum scroll — a pure coincidence of layout constants — and Windows font metrics make real heights fractional by ±0.3px, so the sticky bottom constraint repeatedly engaged and released at the limit. The fix reserves a stable 8px slack below the grid (footer margin-bottom 0.5rem, main scroll container padding-bottom reduced by the same amount, net visual unchanged), raising the slack from 0.00px to ~7.7px so the constraint can never bite. Sidebar row backgrounds are also now genuinely opaque (tints mixed into the panel background instead of `transparent`, pixel-identical result) to keep text anti-aliasing mode stable on hover under Windows ClearType, while the original 150ms hover transitions are preserved. CSS-only change, no database migration, no API changes.

## 更新描述

本次为 **单一修复** 版本，纯 CSS 变更，无数据库迁移、无接口改动。

**① 修复：首页分类侧栏滚到底部时整体抖动（Windows Chrome 特有）**

- 现象：滚轮把模型列表滑到最底部后，分类筛选面板的全部分类、图标、数量会往上抖 0.3px 再弹回，鼠标悬停分类时尤其明显；仅 Windows Chrome 可复现（macOS 高度恰好取整，咬合不上）
- 根因：侧栏是 sticky 吸顶元素，吸附范围以内容网格底边为界——这套布局在极限滚动位置余量恰好为 0.00px（布局常数巧合），Windows 字体度量让实际高度带 ±0.3px 小数，滚轮在底部极限附近每次微动，sticky 底部约束就「咬合→松开」一次，整面板被顶起 0.3px
- 修复：给网格底边留出稳定的 8px 余量（页脚底部 0.5rem + 主容器 padding-bottom 同步减 0.5rem，净视觉完全不变），极限滚动余量 0.00px → 7.72px，约束永远够不到，咬合消失；已在复现机器上验证不再抖动

**② 侧栏底色稳定性加固**

- 分类/子分类行与数量角标的底色改为真正的不透明色（主题色混入面板底色，逐像素等价），消除悬停时文字抗锯齿模式翻转的隐患（Windows ClearType 下的另一类「文字抖动」根源）
- 悬停 150ms 过渡动画保持原设计不变
