## 更新标题

3DPartHub v4.7.1 - SW 看图模式缩小消失修复 + 服务端错误提示简化 + 后台交互打磨

## 标签描述

v4.7.1 fixes the long-standing "model disappears when zooming out in SW view mode" bug — two independent causes: a cursorZoom extrapolation defect in the trackball controls library that made the camera target drift exponentially (patched with a wrapper), and a stale change-event listener that froze the camera far plane after toggling controllers (fixed with a controls-epoch re-attach). Server error toasts are now simplified across the whole app: known verbose diagnostics (conversion OOM/SIGABRT with file size and memory quota, nginx HTML error pages, Prisma internals) map to one-line friendly messages, anything else is trimmed to a single sentence, and the full original text stays in the browser console under a [server-error] prefix. Admin UX polish: the conversion-failed cleanup actions now use the standard confirm dialog (and cancelling no longer leaves rows stuck in "clearing"), "select all" in model admin visibly checks loaded rows while keeping server-side all-matching semantics, the model-import completion notification links to the model detail when exactly one model was imported, the preview-ops and import buttons plus the selection "more settings" button share the same rounded gray style, save buttons no longer jump on hover, the nav manager shows a saved toast, and the nav manager page is now properly adapted to mobile (stacked page-copy card, wrapping node rows). No database migration.

## 更新描述

本次为 **修复 + 体验打磨** 版本，无数据库迁移。

**① 修复：SW 看图模式缩小后模型完全消失（两个叠加原因）**

- 库缺陷：three-stdlib 轨迹球「光标缩放」把缩放因子直接当插值参数，缩小（因子 > 1）时变成外插——每滚一格观察锚点向外漂 10% 并复利发散，模型滑出视锥。已用包装层修复：缩小时锚点锁定，放大保留「朝光标收敛」
- 应用缺陷：SW 开关换装控制器后，相机裁剪面跟随的 change 监听器留在已卸载的旧实例上——SW 模式下缩放时 far 裁剪面冻结在贴合视角的值，缩小越过即整个模型被裁掉（v4.5.8 起存在）。新增控制器世代标识，监听器随换装重挂，缩放全程裁剪面实时跟随

**② 服务端错误提示简化（全站统一）**

- 已知冗长文案一句话化：转换内存诊断（SIGABRT/heap out of memory/配额建议）→「服务器内存不足，转换失败：大文件请拆分上传，或联系管理员调大服务器内存配置」；nginx/express 上传超限（含整页 HTML 错误页）→「文件过大，超出服务器上传限制」；Prisma 内部错误 →「数据服务异常，请稍后重试」
- 兜底：任何未知服务端文案剥 HTML、去堆栈换行、超 80 字截到首句——弹窗最多一句话
- 原始完整诊断保留在浏览器控制台（`[server-error]` 前缀），排查不丢信息
- axios 拦截器统一改写错误 message：直接用 `err.message` 的页面（此前弹英文 "Request failed with status code 500"）同样拿到友好文案

**③ 后台交互打磨**

- 转换失败清理（单个/选中/全部）：原生 confirm 换标准确认弹窗；**弹窗点取消不再把行卡在「清理中」**
- 模型管理「选择全部」：已加载行全部打勾（可见反馈），批量操作仍按服务端全选语义（跨页生效）
- 「模型导入完成」通知：恰好导入 1 个时「打开详情」直达该模型详情页
- 预览运维 / 导入模型 / 选型「更多设置」按钮统一为灰底大圆角同款样式
- 系统设置与导航管理的「保存设置」去掉悬停上浮跳动；导航管理保存成功增加 toast 提示
- 导航管理移动端适配：页面文案卡逐行堆叠、节点行可换行（描述输入框不再被挤没）、分类项下拉最小宽度
