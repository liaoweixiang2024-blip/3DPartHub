## 更新标题

3DPartHub v4.9.8 - DevTools 提示级问题全站清零（懒加载图片尺寸 / 全站表单 id·name / \_blank noopener）

## 标签描述

v4.9.8 clears every advisory-level Chrome DevTools / Lighthouse issue across the site (public pages, admin console, desktop and mobile). Lazy-loaded images now carry explicit dimension hints: model-grid thumbnails (96 per page on the homepage) declare width/height attributes and product-wall masonry thumbnails carry the same CSS aspect-ratio as their wrapper — both are display-only hints, actual layout still comes from the pre-sized containers, so visual behavior is unchanged while layout-shift (CLS) advisories disappear. Every form field in the app now has an id or name attribute: the shared SearchField input auto-generates a stable useId, the TopNav desktop search panel, login/auth "remember me" checkboxes, share dialogs, the homepage sort dropdown, and the shared Pagination page-size selector were fixed individually, and 221 admin-side controls (settings, selection admin, model admin, inquiry, product wall, thread tool, user admin…) received semantic name attributes derived from their value bindings via a codemod — a pure attribute addition with zero behavioral impact on controlled components. Security-adjacent hardening in the same pass: nine admin "open model in new tab" links gained rel="noopener", the share-page access password field gained autocomplete="off" plus an id, the admin temp-password field gained an id, the user CSV export window.open call passes noopener, and the inquiry print window nulls its opener (matching the existing browserDownload pattern). A runtime sweep (Playwright over the five public pages in desktop + iPhone viewports) confirmed zero console warnings, zero page errors and zero 4xx/5xx; backend response headers (helmet set with HSTS preload, COOP/CORP, nosniff, Referrer-Policy) already exceed best practice and needed no change. Frontend-only, no database migration.

## 更新描述

本次为 **前端体验/规范打磨**：把 Chrome DevTools「问题（Issues）」面板里的提示级条目全站清零（前台 + 后台、PC + 移动）。纯前端改动，无数据库迁移，仅需更新 web 镜像（api 镜像同步发布但不包含行为变化）。

**① 懒加载图片尺寸提示（CLS）**

- 首页/模型卡缩略图（每页最多 96 张）补 `width/height` 占位属性 —— 显示尺寸仍由容器的 `w-full h-full object-cover` 决定，纯审计满足项，视觉零变化
- 图库瀑布流缩略图补与外层容器一致的 `aspect-ratio`

**② 表单控件 id/name（浏览器自动填充提示）**

- 用户侧手修：搜索框组件（useId 自动补）、顶栏搜索弹层、登录/注册弹窗「记住我」、模型分享弹窗 3 个输入框、选型结果卡勾选框（按产品 id 唯一）、首页排序下拉、分页每页条数下拉
- 后台批量：codemod 为 34 个文件、221 处控件补语义化 `name`（取自各控件自身的 value 绑定），受控组件零行为影响；复扫确认全站剩余为 0

**③ 新窗口打开加固（提示级安全）**

- 后台「新窗口打开模型」9 处链接补 `rel="noopener"`
- 分享页访问密码框补 `id` + `autocomplete="off"`；管理员临时密码框补 `id`
- 用户导出 `window.open` 补 `noopener`；询价打印窗口 `opener` 置 null

**④ 全站巡检结论（无改动，备档）**

- Playwright 巡检 5 个公开页面 × PC/iPhone 视口：控制台零警告、零报错、零 4xx/5xx
- 后端响应头（CSP/HSTS preload/COOP/CORP/nosniff 等）已达标；viewport 未禁缩放；`html lang` 随语言切换已同步
