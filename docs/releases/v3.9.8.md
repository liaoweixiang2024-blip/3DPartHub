## 更新标题

3DPartHub v3.9.8 - 全站安全加固：依赖漏洞清零 + JWT/备份防护 + 内部角色计数修复

## 标签描述

3DPartHub v3.9.8 is a full-codebase security hardening release with no DB migration. All dependency vulnerabilities are eliminated (server 13→0, client 6→0): nodemailer 8→9 (CRLF injection / TLS / SSRF fixes), adm-zip 0.5→0.6 (crafted-ZIP memory allocation), puppeteer-core 24→25, plus ws/qs/ip-address/axios/brace-expansion/form-data patch releases; react-router-dom upgrades 6→7 (future flags removed — v7 behaviors are default), verified with WebKit smoke tests on six key routes with zero JS errors. JWT now explicitly pins HS256 on both sign and verify (rejects any other algorithm). The backup import worker's spawn arguments are validated before launch (path must be absolute + existing + null-byte-free; filename rejects control chars/line breaks/>255 chars). Also fixes the user-admin role-tab count for the INTERNAL role — the frontend roleCounts mapping omitted the internal field so the tab always showed 0 even though the backend returned correct data. Full-codebase audit (auth/session/rate-limit/info-leak/injection/XSS) confirmed: refresh-token rotation with replay detection, dual-layer login brute-force lockout, sanitized print templates, masked sensitive settings, no path traversal/SSRF/command-injection findings.

## 更新描述

本次为全站安全加固 + 一个计数修复，**无数据库迁移**。

- **[安全] 依赖漏洞清零**
  - 服务端 13 个漏洞（10 高危）→ 0：nodemailer 8→9（CRLF 注入/TLS/SSRF）、adm-zip 0.5→0.6（恶意 ZIP 内存分配）、puppeteer-core 24→25、ws/qs/ip-address 等补丁版。
  - 客户端 6 个漏洞（3 高危）→ 0：axios、brace-expansion、form-data 补丁；react-router-dom 6→7（大版本，已实测验证）。
- **[安全] JWT 显式固定 HS256 算法**
  - 签发与校验均显式声明算法，拒绝任何非 HS256 的 token（纵深防御）。
- **[安全] 备份导入 worker 启动参数校验**
  - 路径必须为已存在的绝对路径且不含 null 字节；原始文件名拒绝控制字符/换行/超 255 字符，杜绝子进程参数注入。
- **[修复] 用户管理「内部」tab 计数恒为 0**
  - 前端 roleCounts 映射遗漏 internal 字段导致；后端数据一直正常。

本次同步完成了全站源码安全审计（认证/会话/速率限制/信息泄露/注入/XSS/依赖），确认：refresh token 轮换+重放检测、登录双层防爆破（邮箱 5 次/IP 20 次锁定）、打印模板转义完整、敏感配置打码、无路径遍历/SSRF/命令注入风险。

前端「检查更新」会读取本更新描述展示最新版本号与更新内容。

## 部署备注

本次**无数据库迁移**。升级步骤：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v3.9.8 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

curl -s http://localhost:3780/api/settings/version   # 应显示 v3.9.8
```

升级后注意：

- 升级后所有用户需**重新登录一次**（JWT 算法声明变更不影响已有 token——仍为 HS256 签发，正常免登录；仅当此前有异常 token 时会被拒绝）。
- 用户管理「内部」tab 计数即刻恢复正常显示。
- 邮件发送（验证码/密码重置）依赖 nodemailer 9，升级后建议实测一次验证码邮件。
