# v5.2.1

发布日期：2026-09-28

## 选型「名称」体系修复（显示 / 清洗 / 导出全链路）

### 结果卡副标题显示实际内容

- 副标题（型号下方的中文名）改为显示「实际内容」：剥掉名称里型号的**所有**出现（历史数据名称常以「系列号 描述 完整型号」结尾，只剥第一次会留尾巴），再剥掉与型号重复的系列号首段（如 `TKN-PZA` 之于 `TKN-PZA10`、`PAW` 之于 `PAW4-01`）
- 系列号内部连字符保留，只按空格分段，不再把 `TKN-PZA` 错拆成 `TKN PZA`

### 参数面板与副标题去重

- 参数列的值若与名称副标题相同（如「接头形态」拼进了产品名），参数面板跳过该行，结果卡不再出现同一句话两遍

### 复制型号统一规则

- 复制按钮统一为「型号 + 空格 + 中文名」（有中文名就带上），不再出现有的带有的不带

### 批量导出四列 + 名称剥型号

- 询价关闭态的选中导出固定四列：型号 / 名称 / 数量 / 单位
- 名称列剥掉型号尾巴后输出，与型号列不再重复

### 导入清洗剥全部出现

- 产品导入/新建/编辑的名称清洗（cleanProductName）由「只剥第一次」改为剥型号的所有出现，新导入数据不再产生型号尾巴（前后端同步）

## 管理端增强

### 产品列表新增「名称」列

- 桌面端产品表格在全选框后新增名称列（超长截断 + 悬停全文），移动卡片本就有名称副标题
- 之前名称只能点开编辑弹窗才能看到，排查「名称哪里来的」不再需要逐个点开

### 选项值反查弹窗新增「批量修改」（X 型弹窗）

- 弹窗底栏新增批量修改：小号下拉（选列：**名称** + 该分类全部参数列）+ 输入框 + ✓ 应用
- 一次把该选项值命中的**全部产品**（含隐藏）所选列统一设置为填写的值——解决「多个型号名称不一致」的批量统一
- 布局细节：描述文字固定最左、控件紧贴「批量修改」按钮左侧；收起/展开行高一致不跳动；控件配色与「批量修改」按钮同款；Esc 收起 / 回车应用
- 服务端新端点 `POST /api/admin/selections/products/batch-update-field`：
  - 改名称走与导入一致的型号清洗（填的值里含型号自动剥掉）
  - 改参数列逐行合并 specs JSON，其他列不动
  - 防护：「型号」列拒绝批量改（由型号编号自动维护）、值必填 ≤200、单次 ≤1000 个产品

## 升级说明

- 无数据库迁移（schema 未变更）
- 服务器更新：`docker-compose pull && docker-compose up -d`，浏览器强制刷新（Cmd/Ctrl+Shift+R）
