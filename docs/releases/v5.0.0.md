## 更新标题

3DPartHub v5.0.0 - 移动端下载体验升级（安卓主屏应用分享直达）+ 浏览门槛提示净化 + 下载趋势图数字标注

## 标签描述

v5.0.0 upgrades the mobile download experience and cleans up the browse-gate prompts. Android home-screen app (PWA) downloads now use the same "share / save" action card as iOS: tapping download fetches the file and opens the system share sheet for one-tap sending to WeChat or any app, with "Direct download" still available as a card button — Android browsers, iOS browsers and desktop keep native direct downloads unchanged, and batch ZIP downloads follow the same routing. The share card uses platform-specific wording (Android no longer shows the iOS-only "Save to Files" phrasing). The second fix silences the annoying top-right error toast that anonymous visitors saw when "login to browse" gates were enabled: browse-gate 401s are now centrally suppressed (SWR global error handler + unhandled rejections) and no longer pointlessly retried by SWR; more importantly, the settings cache previously never refreshed within its 2-minute TTL, so visitors with a stale cache never saw the center login lock at all (page stuck on an empty list) — the gate is now reactive: public settings schedule an idle refresh on every page load and the lock screen takes over as soon as fresh settings arrive. Third, the admin download trend chart now labels each bar with its download count (aligned baselines via fixed-height number rows) and draws no bar at all for zero-download days. Playwright-verified across Android PWA / Android browser / Android WeChat / iOS PWA / desktop flows; frontend-only, no database migration.

## 更新描述

本次为 **移动端下载体验 + 门槛提示** 双主题改版，纯前端改动、无数据库迁移，仅需更新 web 镜像（api 镜像同步发布但不包含行为变化）。

**① 安卓主屏应用：下载即可分享（对齐 iOS）**

- 安卓「添加到主屏幕」的应用内下载，从直接落盘改为弹「分享/直接下载」操作卡：点**分享**直达系统分享面板，可一键把模型文件发到微信/QQ/蓝牙等；点**直接下载**保持原行为
- iOS 主屏应用体验不变（本就是技术必需的通道）；安卓/iOS **浏览器**、桌面端不变（仍为零步骤直接下载）
- 微信内打开：原有的「优先文件级分享、失败回退直接下载」链路不变
- 批量打包下载走同一分流；操作卡文案按平台区分（安卓不再显示 iOS 专属的「存储到文件」措辞），中/英/日/韩/德五语言补齐

**② 浏览门槛提示净化（登录才能浏览选型/模型库开启时）**

- 匿名访客不再看到右上角「需要登录后才能浏览模型/选型」错误 toast：浏览门槛 401 在全局错误漏斗中心静默，由页面居中锁屏统一承接；SWR 也不再对必 401 的请求无脑重试 3 次
- **根因修复**：公开设置缓存在 2 分钟 TTL 内从不触发后台刷新——管理员刚开门槛时，带旧缓存的访客整个访问期拿不到新设置、居中锁屏根本不出现（页面卡在空列表）。现在每次页面加载都会在空闲期排一次刷新，门槛判定改为订阅式，设置一到锁屏立即接管
- 首访（无缓存）与登录用户行为完全不变（Playwright 三场景回归验证）

**③ 管理端下载趋势图**

- 每根柱子顶部标注当天下载数（数字行固定高度保证基线对齐）
- 0 下载的日期不再画占位小柱，只剩浅色空轨道

```bash
cd /opt/3dparthub
docker-compose pull && docker-compose up -d --force-recreate
```

> 本次无数据库迁移。升级后浏览器强制刷新（Cmd/Ctrl+Shift+R）；iPhone/安卓主屏应用完全退出后重新打开（分享卡在新版本生效）。
