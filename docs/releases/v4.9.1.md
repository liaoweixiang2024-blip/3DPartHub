## 更新标题

3DPartHub v4.9.1 - 下载记录全量无限加载 + 页面切换保标题（移动端）+ 锁屏搜索框隐藏

## 标签描述

v4.9.1 upgrades the admin download statistics page and smooths route transitions. The 下载记录 tab previously showed only the latest 20 rows carried by the stats endpoint; it now streams the complete download history through a new paginated endpoint (`GET /api/admin/downloads/records`, 20/page, same search filters as the stats page: model / username / email / format / category), using the shared `InfiniteLoadTrigger` component for a consistent experience with share/user/ticket management — scroll to the bottom to auto-load more, or tap 加载更多; the tab badge and panel header now show the true total instead of capping at 20, and the refresh button revalidates stats and loaded record pages together. Route transitions get a title-stable skeleton: while a lazy page resolves on its first visit (个人设置, 我的收藏, 工单 and every admin page), the fallback renders the same header card with the exact same title text, so the title block no longer disappears and reappears — the same treatment model detail pages already had. With 登录浏览 enabled and the visitor not logged in, the mobile home/model-detail lock screen no longer shows the useless search box. No database migration in this release.

## 更新描述

本次为 **后台下载统计增强 + 切换体验打磨** 版本，无数据库迁移，前后端镜像均需更新。

**① 后台下载统计：下载记录可加载全部（无限滚动）**

- 新增分页接口 `GET /api/admin/downloads/records`（20 条/页，支持与统计页同一套搜索：模型名/用户名/邮箱/格式/分类）
- 「下载记录」tab 无限滚动：滚动到底自动加载下一页，也可点「加载更多」按钮，可翻完全部历史记录
- 交互与分享管理/用户管理/工单处理完全一致（共用 InfiniteLoadTrigger 组件）
- tab 角标与面板徽标显示**真实总条数**（不再封顶 20）；右上角刷新按钮同时刷新统计与已加载记录

**② 页面切换不再闪标题（移动端体验）**

- 所有懒加载页面首次进入期间渲染「保标题骨架」：标题卡与真实页面同款样式、同款文案，加载完成后无缝衔接
- 修复移动端首次进入「个人设置」等页面时，标题区块消失约 0.3 秒再重新出现的闪断；收藏/工单/全部后台页同样受益

**③ 登录浏览锁屏细节**

- 开启「登录浏览」且访客未登录时，移动端首页/模型详情顶部不再显示无意义的搜索框（锁屏状态下无处可搜）

## 升级步骤

```bash
cd /opt/3dparthub
docker-compose pull && docker-compose up -d --force-recreate
```

> 本次无数据库迁移。升级后浏览器强制刷新（Cmd/Ctrl+Shift+R）；iPhone 主屏应用完全退出后重新打开。
