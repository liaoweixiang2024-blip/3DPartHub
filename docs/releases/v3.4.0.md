## 更新标题

3DPartHub v3.4.0 - 后台设置治理与分享策略修复版

## 标签描述

3DPartHub v3.4.0 production release with backend dead-config cleanup (11 misleading settings made honest and read-only), share expiry/download policy fixes, and backup schedule format validation.

## 更新描述

- 后台设置死配置治理（共 11 项）：水印、Redis 连接、缓存开关、私有签名 URL、上传分片大小、下载加速等「管理员可改但后端实际不执行」的设置，文案统一改为真实行为说明；其中 8 项在前端加入真只读保护（标注「只读」且无法修改），避免管理员误以为修改已生效。
- 水印设置如实标注：水印功能实际仅在 3D 模型查看器界面显示，不会写入下载的文件（原文案「下载水印」易误解为下载文件带水印）。
- Redis 连接设置如实标注：实际连接由环境变量 REDIS_URL 控制，后台该项仅显示当前值、修改不生效，避免管理员误以为可在后台切换 Redis。
- 修复分享默认过期天数超过最大上限的 bug：当管理员配置「默认过期天数」大于「最大过期天数」时，用户创建分享不指定过期会得到超过上限的有效期，现已钳制到最大上限（与下载次数的钳制逻辑对称）。
- 修复分享「无限下载」被系统默认覆盖的 bug：用户在分享对话框选择「无限下载」时，若系统设置了默认下载次数，会被强制覆盖为默认值；现已区分「用户显式选择无限」与「未指定」，仅未指定时才套用系统默认。
- 备份自动执行时间加 HH:MM 格式校验：管理员误填（如 25:99、9am）不再被原样存入导致备份静默回退到默认时间，保存时即规范化或回退到默认 03:00。
- 前端「检查更新」会读取本更新描述（GitHub Release 内容），展示最新版本号与更新内容。
