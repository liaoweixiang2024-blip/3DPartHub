## 更新标题

3DPartHub v3.1.0 - 主题架构、后台设置与弹窗统一增强版

## 标签描述

3DPartHub v3.1.0 production release with hardened theme isolation, unified admin dialogs, refined auth prompt controls, cache/storage sync settings, upload/download reliability fixes, and refreshed Docker images.

## 更新描述

- 完善 PartHub 经典版与 PartHub 工作台主题隔离，统一前后台主题切换偏好、移动端主题兜底和主题开发规范。
- 优化后台系统设置，将缓存与云存储拆成 Redis、对象存储、资源目录、本地云同步、图片优化和缓存清理等同级配置页。
- 修复登录提示弹窗按页面控制、未登录下载提示闪烁和登录/注册表单弹窗跳转逻辑，前台入口体验更一致。
- 统一后台危险操作确认弹窗，覆盖缓存清理、用户删除、审计日志清理、模型分组、转换队列、预览诊断和规格数据管理。
- 强化模型上传、压缩包批量识别、路径安全、上传上限、下载文件名、STEP/PDF 绑定、回收站和批量下载稳定性。
- 优化产品图库缩略图、图片预览手势、移动端交互和大图加载，降低图库浏览和图片详情卡顿。
- 增强备份恢复、存储同步、审计日志保留策略、清理工具、数据库索引和 502 压力场景下的可靠性。
- 发布前验证通过前后端类型检查、构建、主题/加载/UX 合约检查和关键服务端单元测试。
- 镜像已同步更新：api/web 均发布 v3.1.0 与 latest 标签。

Web image title: `3dparthub-web:v3.1.0`

Web image: `ghcr.io/liaoweixiang2024-blip/3dparthub-web:v3.1.0`

Web image description: React/Vite frontend for theme-driven model libraries, unified auth dialogs, 3D preview, upload progress, batch downloads, product selection, product gallery browsing, inquiry/quote workflows, sharing, profile management, admin pages, legal pages, and responsive mobile flows.

```bash
# Default deployment follows latest and uses Watchtower for api/web auto-updates.
# Run this when you want to update immediately:
cd /opt/3dparthub
curl -L -o docker-compose.yml https://raw.githubusercontent.com/liaoweixiang2024-blip/3DPartHub/main/docker-compose.yml
touch .env
grep -q '^IMAGE_TAG=' .env && sed -i 's/^IMAGE_TAG=.*/IMAGE_TAG=latest/' .env || echo 'IMAGE_TAG=latest' >> .env
docker-compose pull
docker-compose up -d --force-recreate

# Verify health
curl http://localhost:3780/api/health
```
