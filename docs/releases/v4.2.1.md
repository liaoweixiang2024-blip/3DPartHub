## 更新标题

3DPartHub v4.2.1 - 新功能：我的通知中心 + 分享与下载记录去重 + 分享页全面升级（3D 工具栏/文件下载卡片）

## 标签描述

3DPartHub v4.2.1 ships a notification center, dedup for shares/downloads, and a full share-page upgrade. New "My Notifications" page (/notifications) lists the complete history with read-status/type filters and pagination — the bell dropdown only showed the latest 30; batch management (checkbox select, select-page, confirm-delete) replaces the dangerous one-click "clear read" which permanently deleted rows (the panel's clear-read now only hides entries locally). Broken notification links no longer offer "open details" when the related model/ticket/inquiry was deleted. Share & download dedup: creating a share for a model you already shared reuses your existing link (token unchanged, settings updated; expired links get new ones), and download history keeps one row per user+model+format (repeated downloads refresh the timestamp; note the daily download limit now counts distinct models per day). Share page parity with model detail: full CAD viewer toolbar (view modes, camera angles, dimensions, edges, section clip, fullscreen, measurement, materials, screenshot) on desktop and mobile, file-download cards styled like the detail page (format badge + filename + size + action button), a mobile "File downloads" bottom drawer, a compact metadata line with relative expiry (30min/5h/3d/never), and a fix for the desktop 3D model not rendering. Also: profile notification toggles match the settings-page switch style, and the version-history cache refreshes within an hour so post-publish release-note edits take effect. DB migration included (dedup unique index + legacy row cleanup, auto-applied on start).

## 更新描述

本次为**功能更新**，含数据库迁移（容器启动时自动执行，无需手动操作）。

**新功能：我的通知中心**

- 新增「我的通知」独立页面：完整历史分页浏览（每页 20 条）——此前通知浮窗只显示最新 30 条，更早的记录无处可看
- 状态筛选（全部/未读/已读）+ 类型筛选（工单/询价/收藏/下载/模型转换/备份/评论）
- **批量管理**：勾选通知 → 确认后批量删除（对齐「我的分享」交互）；单条删除按钮改为垃圾桶图标，桌面悬停浮现、手机常显
- 移除了原「清除已读」按钮（一键永久删除太易误触）；通知浮窗的「清除已读」改为**仅隐藏**已读条目，不再删数据库记录
- **修复**：关联的模型/工单/询价被删后，通知「查看详情」跳空白页——现在失效通知不再显示跳转入口

**新功能：分享与下载记录去重**

- 同一用户对同一模型重复分享 → **复用已有链接**（token 不变、老链接继续有效），仅更新权限/密码/有效期/次数设置；分享弹窗自动展示已有链接，「创建」变「更新分享设置」
- 下载历史去重：同用户+同模型+同格式只保留**一条记录**，重复下载仅刷新时间置顶，不再刷屏（含批量打包下载）
- ⚠️ 语义变化：每日下载限额按「当天下载的**不同模型数**」计——同一模型反复下载不消耗额度

**分享页全面升级（对齐模型详情页）**

- 3D 查看器完整工具栏：视图模式（实体/线框/透明/爆炸）、相机角度、尺寸标注、线框边缘、**剖面**（方向/位置/反转）、重置、**全屏**、测量、材质预设、截图——桌面与手机都有
- 文件下载区改为详情页同款卡片（格式徽章+文件名+大小+操作钮）
- 手机端底部「文件下载」按钮唤起底部抽屉展示全部文件
- 元信息行：`STEP · 898KB · 3天`（有效期相对时间，永久显示一项）
- 修复桌面端 3D 模型/工具栏不显示的问题（flex 布局层级错误导致渲染进 0 高区域）

**其他修复**

- 个人中心通知偏好开关与设置页配色规格统一
- 版本历史缓存加 1 小时兜底时效（发布说明事后编辑最多 1 小时生效）

**建议升级后验证**：铃铛 → 查看全部 → 筛选/批量删除；重复分享同一模型确认链接不变；分享页桌面端工具栏/剖面/全屏。

前端「检查更新」会读取本更新描述展示最新版本号与更新内容。

## 部署备注

本次**含数据库迁移**（downloads 复合唯一索引 + 存量重复行清理），容器启动时自动执行：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v4.2.1 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

curl -s http://localhost:3780/api/settings/version   # 应显示 v4.2.1
```

升级后注意：

- 迁移会清理 downloads 存量重复行（每组保留最新一条）——线上行数多时该 DELETE 可能稍慢，建议低峰升级
- 已有分享链接全部继续有效；用户再次分享同一模型时会复用原链接而非新建

默认跟随 latest 的部署由 Watchtower 自动更新。
