## 更新标题

3DPartHub v3.1.4 - 临时看图与备份安全增强版

## 标签描述

3DPartHub v3.1.4 production release with STEP temporary viewer, safer Safari/mobile downloads, complete modular backup restore coverage, hardened Docker secrets, accurate update version reporting, and refreshed Docker images.

## 更新描述

- 新增临时看图页面，支持 STEP/STP 临时上传预览，不加入模型库、不生成产品记录。
- 临时看图加入 50 MB 单文件限制、最多 5 条有效记录、上传限流、自动清理、删除同步清理源文件与预览文件。
- 临时看图支持最近有效模型自动打开、拖拽上传、复制分享链接、移动端底部导航和贴近模型详情页的全屏预览布局。
- 移除 XT/X_T 临时预览与转换入口，避免服务器缺少商业内核时误导用户。
- 优化 Safari/PWA/移动端下载流程，避免下载模型时进入系统打开方式页面造成卡死。
- 分模块备份补齐关联数据：模型收藏、下载、评论、分享链接，选型分享，产品图库收藏；`/thread-size` 规格数据随选型模块与整站备份。
- 备份页显示真实资源统计，策略体检展示目录权限、磁盘空间、自动化、异地副本、加密和最近备份可用性。
- 生产 Docker 部署强制配置 DB/Redis/JWT/Admin 初始密码，服务端拒绝生产弱密钥。
- 检查更新版本识别改进，源码/本地部署不再显示 unknown，当前版本统一为 v3.1.4。
- 批量归档上传保持中文文件名修复、ZIP/RAR 路径编码兼容与安全路径检查。
- 发布前验证通过前后端类型检查、构建、核心单元测试、更新检测测试和页面路由抽检。
- 镜像已同步更新：api/web 均发布 v3.1.4 与 latest 标签。

```bash
# Default deployment follows latest and uses Watchtower for api/web auto-updates.
# Run this when you want to update immediately:
cd /opt/3dparthub
curl -L -o docker-compose.yml https://raw.githubusercontent.com/liaoweixiang2024-blip/3DPartHub/main/docker-compose.yml
touch .env
grep -q '^IMAGE_TAG=' .env && sed -i 's/^IMAGE_TAG=.*/IMAGE_TAG=latest/' .env || echo 'IMAGE_TAG=latest' >> .env
docker compose pull
docker compose up -d --force-recreate

# Verify health
curl http://localhost:3780/api/health
```
