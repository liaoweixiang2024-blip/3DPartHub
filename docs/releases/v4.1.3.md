## 更新标题

3DPartHub v4.1.3 - 体验优化：下载/图纸/附件链接失效改为友好提示页（含站点品牌），修复关闭按钮点不动

## 标签描述

3DPartHub v4.1.3 is a UX polish release. Browser-direct resource URLs (model file download, PDF drawings, ticket/inquiry attachments, batch archives, backup downloads) used to answer expired/invalid token errors with raw JSON — users saw a blob of code in a new tab. These endpoints now do content negotiation: browser navigations (Accept: text/html) receive a friendly branded error card (site logo + title from admin settings, same source as the maintenance page) with a countdown auto-close and a working fallback action; programmatic API calls (fetch/XHR) still get JSON so all existing frontend toasts keep working. The "关闭本页" button previously appeared dead on user-opened tabs because window.close() only works on script-opened windows — it now counts down 5s trying to auto-close, and when the tab can't be closed the button transforms into "返回首页" so it always does something. Covers model download (all 6 error branches), drawing download, ticket/inquiry attachments, batch zip download, and backup download. No DB migration.

## 更新描述

本次为**体验优化**，无数据库迁移。

**问题**：模型下载/图纸/附件/批量打包/备份下载这类「浏览器直开」链接，令牌失效（5 分钟过期或一次性已用）时返回一坨 JSON 代码（如 {"success":false,"message":"..."}），用户在新标签页看到非常难懂。

**修复**

- **友好提示页**：浏览器打开失效链接时，显示与站点同风格的提示卡片——站点 Logo + 名称（读取后台「站点设置」，与维护页同源）、明确的标题、怎么办的说明（如「请回到模型详情页重新打开图纸」）、有效期/一次性说明
- **API 调用不受影响**：按请求类型自动分流——浏览器导航拿 HTML 页，前端 fetch/axios 调用照旧拿 JSON（现有 toast 提示逻辑全部不变）
- **覆盖全部直开入口**：模型文件下载（列表/详情/收藏/下载历史都在用）、PDF 图纸、工单附件、询价附件、批量打包 ZIP、备份下载——每个入口的令牌失效/需登录/无权限/文件不存在等所有错误分支
- **修复「关闭本页」按钮点不动**：浏览器只允许关闭脚本打开的窗口，用户自己开的标签页点关闭无反应——现在 5 秒倒计时自动尝试关闭，关不掉时按钮自动变成「返回首页」，任何情况下按钮都有真实作用

**验证过的场景**：失效链接浏览器打开 → 品牌提示页；API 调用 → JSON 照旧；倒计时与按钮切换逻辑。

前端「检查更新」会读取本更新描述展示最新版本号与更新内容。

## 部署备注

本次**无数据库迁移**，仅 API 端改动。升级步骤：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v4.1.3 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）

curl -s http://localhost:3780/api/settings/version   # 应显示 v4.1.3
```

升级后可验证：找一个失效的下载/图纸链接（或等 5 分钟过期）用浏览器打开，应看到带站点 Logo 的提示页而非 JSON 代码。

默认跟随 latest 的部署由 Watchtower 自动更新。
