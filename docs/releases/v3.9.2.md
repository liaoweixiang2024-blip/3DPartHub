## 更新标题

3DPartHub v3.9.2 - 品牌设置增强：应用名称/图标可自定义 + Favicon 修复 + 首开标题不闪跳

## 标签描述

3DPartHub v3.9.2 makes the PWA identity fully admin-configurable and fixes the custom favicon never showing. New settings under 站点与品牌: 应用名称 (install prompt / home-screen name, falls back to 网站名称) and 应用图标 (Chrome install icon + iOS apple-touch-icon, uploaded PNG ≥192×192 recommended). The static site.webmanifest is now generated by the API from these settings (nginx proxies /site.webmanifest with a build-time fallback when the backend is down). The browser-tab title flash on first visit is eliminated: index.html embeds an nginx SSI include that injects the admin-configured title/description/favicon links server-side, so the very first HTML byte already carries the right brand (works for all SPA routes; graceful fallback to build-time defaults when the API is unreachable). Root cause of the favicon bug: index.html declared three static icon links (SVG any + PNG 32/16) while the runtime updater only rewrote the first, letting the built-in PNGs out-rank the configured icon — icon declarations are now single-sourced from the server-rendered head fragment and the runtime updater rewrites ALL icon links. Brand text settings (site_title/site_browser_title/site_app_name) are trimmed and capped at 60 chars; icon URLs restricted to in-site paths or http(s) URLs. No DB migration.

## 更新描述

本次让**浏览器安装应用、手机添加到主屏幕的名称和图标**都可在后台自定义，修复 **Favicon 图标设置了不显示**的问题，并消除**首次打开网站时标题闪一下**的现象。无数据库迁移。

- **[新增] 应用名称（后台 → 设置 → 站点与品牌）**
  - 浏览器「安装应用」弹窗、手机主屏图标下显示的名称，留空则使用「网站名称」。
- **[新增] 应用图标**
  - Chrome/Edge「安装应用」的图标和 iPhone「添加到主屏幕」的图标（苹果走 apple-touch-icon，不读 manifest），支持 PNG/JPG/SVG/ICO 上传，推荐正方形 ≥192×192，留空使用内置图标。
  - /site.webmanifest 改为按后台设置实时生成；后端不可用时自动回退镜像内置默认。
- **[修复] Favicon 图标设置了不显示**
  - 根因：页面头部静态声明了 3 条内置图标（SVG + 32/16 PNG），切换设置时只更新第一条，浏览器按尺寸优先选中了内置 PNG。
  - 现在图标声明全部由服务端统一输出（单一来源），运行时切换也会更新全部图标链接。
- **[优化] 首次打开标题不再闪跳**
  - 之前首次访问（无缓存）会先显示内置的 "3DPartHub" 再跳成设置的标题；现在标题/描述/图标由服务端直接注入 HTML，第一眼就是正确的品牌信息，所有页面均生效。
- **[安全] 品牌文本设置统一去首尾空白并限长 60 字符；图标 URL 仅允许站内路径或 http(s) 外链**

前端「检查更新」会读取本更新描述展示最新版本号与更新内容。

## Docker Images

API image title: `3dparthub-api:v3.9.2`

API image: `ghcr.io/liaoweixiang2024-blip/3dparthub-api:v3.9.2`

API image description: Express/Prisma API service. v3.9.2 adds site_app_name and site_app_icon settings (schema defaults + validation: 60-char cap on brand text, in-site/http(s)-only icon URLs), a /api/settings/head-fragment endpoint serving title/og/favicon links for nginx SSI injection, and a /api/settings/site-manifest endpoint generating the PWA manifest (name + icons) from admin settings. Upload endpoint accepts the new app-icon key. No DB migration. Includes all v3.5.0–v3.9.1 functionality.

Web image title: `3dparthub-web:v3.9.2`

Web image: `ghcr.io/liaoweixiang2024-blip/3dparthub-web:v3.9.2`

Web image description: React/Vite frontend. v3.9.2 removes static icon declarations from index.html (icons single-sourced from the server-rendered SSI head fragment), enables nginx SSI on index.html with graceful fallback to build-time defaults when the API is down, proxies /site.webmanifest to the dynamic API manifest (static fallback included), fixes applyFavicon to update ALL icon links (root cause of the favicon bug), adds 应用名称/应用图标 fields to the admin branding settings, and includes a dev-only Vite plugin injecting the default head fragment. Includes all v3.5.0–v3.9.1 functionality.

## 部署备注

本次**无数据库迁移**。升级步骤：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v3.9.2 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

curl -s http://localhost:3780/api/settings/version   # 应显示 v3.9.2
```

升级后注意：

- 「应用名称」「应用图标」在后台「设置 → 站点与品牌」，保存后即生效（无需重启容器）。
- 手机主屏已添加的旧图标不会自动更新：改名/改图标后需删除旧的主屏图标重新添加。
- Chrome 已安装过应用的，名称/图标更新可能需要重新安装一次应用。

默认跟随 latest 的部署由 Watchtower 自动更新。
