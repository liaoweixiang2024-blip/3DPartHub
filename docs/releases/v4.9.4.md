## 更新标题

3DPartHub v4.9.4 - 移动端标题卡零跳动（骨架对齐壳层）+ 技术支持对齐 + 项目空间页标准头

## 标签描述

v4.9.4 completes the mobile title-block stability work. The route-loading skeleton now renders inside `AdminPageShell`: previously the skeleton sat flush against the top while the real page's shell pushed the header card down ~16px on mount, producing the "card sticks to the top, then jumps once" flicker on first load and first navigation — position and height are now identical across the skeleton, loading and loaded phases (verified frame-by-frame on a production build: y=65/h=78 with zero drift across 20 pages). The 技术支持 (support) page had double padding on mobile (its own px-4/py-4 stacked on the shell's), leaving its header 16px lower than every other page — removed, now aligned. The 项目空间 (projects) page still used a legacy minimal header (breadcrumb + plain text); it is now standardized to the same AdminPageHero card with a description and the create-project action, and joins the route skeleton map. A full 20-route mobile sweep confirms every page renders the header card at the exact same position and size through all load phases. Frontend-only release, no database migration.

## 更新描述

本次为 **移动端标题卡稳定性收尾** 补丁，纯前端改动，无数据库迁移，前后端镜像均需更新。

**① 修复：标题卡「先贴合顶部、再抖动一下」**

- 根因：路由加载骨架没有经过 `AdminPageShell`（缺壳层的 16px 内边距），页面挂载时标题卡被整体下推 → 首次加载/首次切换页面必跳
- 修复：骨架与真实页面共用同一壳层，标题卡位置/尺寸从第一帧到数据完成完全恒定（骨架→加载→完成 y=65、h=78 零漂移）

**② 技术支持页对齐**

- 移动端自叠的内边距与壳层重复，标题卡比其他页面低 16px —— 已去除，与其他页面完全对齐

**③ 项目空间页标题标准化**

- 旧版「面包屑 + 极简文字头」统一为标准标题卡（标题 + 描述 +「新建项目」按钮），并纳入路由骨架映射

**④ 全站验证**

- 20 个路由（个人设置/收藏/下载历史/分享/工单/询价/通知/项目/技术支持 + 全部后台页）移动端逐页冷打开采样：标题卡位置、尺寸、样式三维度全程静止，20/20 达标
