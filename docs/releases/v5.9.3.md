# v5.9.3

发布日期：2026-10-17

## 更新标题

3DPartHub v5.9.3 - 选型型号匹配改精确规则（清除 295 个同号不同物错配）+ 选项画册状态一眼可辨（带上传时间）+ 子零件清单下载改 Excel 表格

## 更新描述

用户报告选型结果 TKN-PC4-01（铜快拧）匹配到了 PC4-01 的塑料快插模型——同号不同物。全库模拟（19,547 个产品型号 × 3,360 个模型）发现匹配算法的「包含兜底」层共产生 295 个此类错配（铜件系 ↔ 塑料快插、储气罐变体、球阀分数尺寸 1↔1/2、缺电压后缀等），本版砍掉兜底只走精确匹配。同时选型管理的选项画册增加状态可视化（卡片手柄变色 + 上传/更新时间），子零件清单下载从 txt 改为 xlsx 表格。

## 新增功能

### 1. 选项画册状态可视化（选型管理 → 选项设置）

- 选项卡片的拖拽手柄 ⠿ 变色指示：**有画册 → 主题强调色（亮橙），没有 → 默认弱化灰**，不用点进弹窗就能看出谁配了画册；悬停手柄提示「已上传画册 · 更新于 …」
- 选项弹窗画册区：文件名旁显示**上传/更新时间**（「更新于 2026/10/17 16:58」）
- 数据结构：optionCatalogs 条目从纯 URL 字符串扩展为 `{ url, updatedAt }`，新上传/粘贴/换链自动记录时间；**存量旧数据（纯字符串）全链路兼容**（前台解析、备份导出/导入、Excel 粘贴），只是没有时间可显示
- 列表视图同款手柄变色指示

### 2. 子零件清单标题图标 + Excel 下载

- 选型结果卡与分享页的清单标题行加 `inventory_2` 图标，与画册资料标题行视觉同构：`📦 组装清单（5）`
- 「下载清单」从 txt（制表符文本）改为 **.xlsx 表格**：序号 / 名称 / 型号 / 数量 + 子零件附加参数列（如编码），与页面清单表同列；文件名规则不变（`KACM-FR-V2-KD1-10-组装清单.xlsx`）；下载失败弹错误提示（六语言）；「复制清单」仍为文本（粘贴进 Excel 自动分列）

## 修复清单

- **型号匹配同号不同物错配（295 个）**：匹配只保留精确规则（归一化后逐字符一致，含「中文名\_型号」的型号尾段键），砍掉包含兜底——TKN-PC4-01（铜快拧）↔ 白色直快插\_PC4-01（塑料快插）、BZHF-W-1 ↔ BZHF-W-1/2（口径不同）、QG-W-20L-B-11 ↔ QG-W-20L（变体不同）、KP5404-25 ↔ KP5404-25-DC24V（电压配置不同）等全部不再错配；精确命中不受影响（TKN-PC4-01 → 铜直快拧模型、PU8 → 白色联管直通\_PU8 尾段键）。**宁可不配（结果卡不显示 3D 缩略图）不可错配**；需要 3D 图的产品请上传型号完全一致的模型文件
- **改名选项值画册失配**：rename-option 端点此前只迁移 optionImages 的键，optionCatalogs 挂在旧值下失配（改名的选项画册悄悄失效）；现同一事务内一起迁移

## 升级说明

- 无数据库迁移（schema 未变更）
- 服务器更新（标准自动流程）：
  ```bash

  docker-compose pull
  ```
