## 更新标题

3DPartHub v4.6.1 - 备份下载修复（兼容迅雷/IDM 等下载工具）+ 版本记录页优化

## 标签描述

v4.6.1 fixes backup archive downloads failing inside download managers (Thunder/IDM) with the "cannot extract the file from the website" error. Backup downloads used a single-use token: the download tool's initial HEAD probe or first Range segment consumed it, so every subsequent request returned 401 and the tool surfaced "cannot extract the file from the website, try logging in". Backup download tokens are now multi-use with a 24-hour TTL (matching the existing drawing/attachment token policy), so HEAD probes, segmented multi-thread fetches and resume-after-pause all succeed; tokens remain 32-byte random and bound to a single backup ID. Also on the About page: the version-history timeline now ends with a "More history" link to the GitHub Releases page (the repo has 113+ releases; the timeline keeps the latest 20), and the GitHub API fetch was trimmed from 50 to 30 releases per refresh. No database migration.

## 更新描述

本次为 **备份下载兼容性修复 + 关于页优化** 版本，无数据库迁移。

**① 修复：备份文件用迅雷/IDM 等下载工具下载失败（提示「无法从网站上提取文件，请尝试登录相应网站」）**

- 根因：备份下载令牌是**一次性**的——下载工具先发 HEAD 探测、再多线程分段拉取，第一次请求就把令牌消费掉，后续请求全部 401，工具端报「无法提取文件」
- 修复：备份下载令牌改为**可复用**（24 小时有效），HEAD 探测、分段下载、断点续传均正常；令牌仍为 32 字节随机且绑定单个备份，安全性由时效兜底
- 备份文件 GB 级、下载耗时长，24 小时窗口也避免慢速下载/续传中途令牌过期

**② 优化：关于页「版本更新记录」**

- 时间线底部新增「更多历史版本 ↗」链接，跳转 GitHub Releases 页查看全部历史版本（时间线保留最近 20 个）
- 服务端拉取量从 50 条降到 30 条，接口响应更轻
