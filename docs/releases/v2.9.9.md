## 更新标题

3DPartHub v2.9.9 - 移动端细节、主题隔离与法务阅读体验优化版

## 标签描述

3DPartHub v2.9.9 production release with refined mobile model details, unified auth dialogs, legal document reading navigation, stronger theme isolation, optimized gallery thumbnails, and refreshed Docker images.

## 更新描述

- 移动端模型详情页优化下载按钮与底部菜单距离，统一单行/双行标题骨架高度，减少抽屉加载和标题变化时的抖动。
- 用户协议与隐私声明页面重新排版：日期并入阅读说明，PC 阅读目录支持自然吸顶，移动端目录改为侧边展开、独立滚动并避开底部菜单栏。
- 登录/注册弹窗继续统一新旧主题移动端样式，注册弹窗底部用户协议与隐私声明留白更舒适。
- 新旧主题隔离继续完善：主题模板、共享渲染器、登录注册弹窗、首页模型库和页面宽度细节持续收拢，避免主题样式互相污染。
- 新主题首页模型库、侧边栏、页头、搜索框、排序筛选和模型列表间距继续优化，减少分类切换、搜索和排序时的抖动。
- 产品图库缩略图策略继续加固：列表优先使用轻量缩略图，图片详情再加载大图，降低移动端浏览和瀑布流滚动卡顿。
- 批量下载、收藏下载和下载文件命名继续修复，避免 STEP 压缩包混入多余 `.bin` 文件，并保留带斜杠型号的正确文件名。
- 工单、询价和选型页面继续统一标题、输入框、快捷词、附件上传和移动端底部输入体验。
- 后台系统设置的缓存、云存储、资源目录、版本检测和备份恢复相关交互继续完善。
- 镜像已同步更新：api/web 均发布 v2.9.9 与 latest 标签。

```bash
# Default deployment follows latest and uses Watchtower for api/web auto-updates.
# Run this when you want to update immediately:
cd /opt/3dparthub
curl -L -o docker-compose.yml https://raw.githubusercontent.com/liaoweixiang2024-blip/3DPartHub/main/docker-compose.yml
touch .env
grep -q '^IMAGE_TAG=' .env && sed -i 's/^IMAGE_TAG=.*/IMAGE_TAG=latest/' .env || echo 'IMAGE_TAG=latest' >> .env
docker-compose pull
docker-compose up -d --force-recreate

# Verify health
curl http://localhost:3780/api/health
```
