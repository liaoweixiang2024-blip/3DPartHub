## 更新标题

3DPartHub v3.9.4 - 修复刷新页面顶部闪乱码 + 新增「关于」页

## 标签描述

3DPartHub v3.9.4 fixes the gzip-garbage flash and adds an About tab. Fix: on every page load a short run of mojibake (boxes/question marks) flashed at the top before the app rendered. Root cause: nginx forwards the browser's Accept-Encoding: gzip header in its SSI subrequest for the head fragment, the API's compression middleware gzipped the fragment, and nginx SSI splices subresponse bytes verbatim without decompressing — raw gzip bytes landed inside <head>. The endpoint now declares Content-Encoding: none (compression skips it) and the nginx subrequest forces Accept-Encoding: identity as a belt-and-braces guard. Feature: the admin settings gains an 关于 tab (运维维护 group, alongside 数据备份) — version detection (current version, check-update, release notes, upgrade commands) moved out of the 数据备份 tab, and a program intro section shows the developer contact (廖为祥 · 全栈开发 · QQ 255955956 · liaoweixiang.com). No DB migration.

## 更新描述

本次修复**刷新页面时顶部闪现一串乱码（框框/问号）**的问题，并在设置页新增**「关于」**标签页。无数据库迁移。

- **[修复] 刷新页面顶部闪乱码后消失**
  - 根因：页面头部的服务端注入（SSI）子请求带上了浏览器的 gzip 请求头，API 把头部片段压缩后返回，nginx 不解压直接把 gzip 二进制拼进了页面 —— 浏览器把压缩字节当文字渲染，就出现了那串框框问号；应用加载完成后重绘，乱码消失。
  - 修复为双保险：API 端点声明不压缩 + nginx 子请求强制 identity。已在 Docker 环境用浏览器同款 gzip 请求实测，页面头部恢复干净。
- **[新增] 设置页「关于」标签（运维维护组，与数据备份同级）**
  - 版本检测（当前版本 / 检查更新 / 版本对比 / 更新内容 / 升级命令）从「数据备份」迁移到「关于」，数据备份页只剩备份功能。
  - 新增程序介绍与开发者信息：全栈开发 廖为祥 · QQ 255955956（可点击发起会话）· liaoweixiang.com。
