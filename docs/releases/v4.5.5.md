## 更新标题

3DPartHub v4.5.5 - gmsh 修复引擎完善 + 站点图标适配 + 多语言补全

## 标签描述

v4.5.5 ships the gmsh repair engine refinement for broken model previews, site brand-asset fixes, full 6-locale i18n coverage, and mobile delete repair. gmsh repair: curvature-adaptive meshing (clcurv=20, clmin=size/1000 aligned with the main engine's 0.001 deflection) so small fillets/holes are no longer flattened; msh2 shared-node output with 35° angle-threshold smooth normals replaces flat-shaded STL (cylinders/spheres render smooth like the main engine); thumbnails regenerated through the same software renderer as the main pipeline so background/lighting match the whole library (fixes over-bright thumbnails); vertex-weighted average material color keeps repaired thumbnails tonally consistent; the edit dialog now has separate "Regenerate (standard)" and "Repair (gmsh)" buttons with independent loading states, plus a GET /api/settings/gmsh-available probe so the dialog can tell admins upfront when gmsh is missing. Brand assets: nginx now serves favicon/logo/watermark with 5-minute must-revalidate instead of 30-day immutable (renamed brand files update promptly); manifest icons declare real PNG IHDR dimensions (desktop PWA install no longer discards icons with wrong size declarations); settings upload validates square icons and warns under 192px for app icons. i18n: all 6 locales aligned at 1642 keys — zh-TW gained 117 simplified→traditional character mappings plus word-level phrase overrides, ja/ko/de received ~77 missing translations (auth reset flow, notifications, invites, email change, share expiry, feature gates). Mobile: delete-from-detail SWR infinite cache updater now handles both cached shapes (single page object and array) so no more minified-source toast. No DB migration.

## 更新描述

本次为 **gmsh 修复引擎完善 + 站点品牌资源修复 + 多语言补全** 版本，无数据库迁移。

**① 修复预览（gmsh 引擎）精度与观感对齐标准引擎**

- **网格精度**：加入曲率自适应（每圈至少 20 段）+ 最小边长下限（模型尺寸/1000，与标准引擎 0.001 偏差同基准）。此前小圆角/小孔被最大边长切平（R1 的圆角只有 3 段），现在按曲率自动加密，精度与标准转换引擎同级，且不会对微小特征无限细分（无下限时曾冲到 220 万三角形）。
- **平滑着色**：gmsh 输出从 STL（每三角独立顶点+平面法线，圆柱/球面呈明显多面体棱面）改为 msh2 共享节点网格 + 35° 角度阈值平滑法线——曲面光滑渐变、棱边保持锐利，观感与标准引擎一致；文件体积还更小（浮球装配 32MB→14.8MB）。
- **缩略图一致**：修复引擎重转后的缩略图改用与上传主管线相同的软件渲染器（渐变浅灰底+统一光照），此前走浏览器渲染器（纯白底+更亮 HDR），修复过的模型在列表里明显偏亮、底色突兀。材质色取标准引擎各零件颜色的顶点加权平均，缩略图色调与周围模型协调。
- **双引擎按钮**：编辑弹窗里「重新生成（标准引擎）」「修复预览（gmsh）」两个按钮独立 loading、可分别重转互不影响；新增服务端 gmsh 可用性探测接口，服务器未安装 gmsh 时弹窗直接提示，不用点了按钮才报错。生产 Docker 启用方法见 docker-compose.yml 内注释（宿主机 apt install gmsh + 挂载给 API 容器）。

**② 站点图标/品牌资源修复**

- 后台改 favicon/logo/水印后 30 天内浏览器仍显示旧图——nginx 对品牌资源（固定文件名）从 30 天 immutable 缓存改为 5 分钟 must-revalidate，改完最多 5 分钟生效。
- PC 端 Chrome「安装应用」后图标丢失——manifest 图标的 sizes 声明此前写死 192x192，与实际 PNG 尺寸不符时 Chrome 桌面端直接丢弃；现在读取 PNG IHDR 真实尺寸声明。
- 设置页上传图标增加校验：非正方形直接中止，应用图标小于 192px 给出警告。

**③ 六语言全部对齐（1642 key × 6）**

- 繁体中文：补 117 个简繁转换字映射 + 词级台湾惯用语（软件→軟體、网络→網路等），此前界面夹杂简体字。
- 日/韩/德：补 ~77 条缺失翻译（密码重置流程、通知中心、邀请码、邮箱变更对话框、分享过期提示、功能开关等），此前这些位置直接显示英文或中文。

**④ 手机端删除模型不再弹源码报错**

与 v4.5.4 的首页列表修复同源——模型详情页（移动端布局）删除后的缓存更新写法兼容 SWR infinite 的两种缓存形态，不再把压缩后的函数源码当错误信息弹出。
