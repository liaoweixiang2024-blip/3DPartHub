## 更新标题

3DPartHub v3.8.0 - 新增「内部」用户角色 + 模型分享规则简化

## 标签描述

3DPartHub v3.8.0 adds an **INTERNAL user role** and **simplifies model sharing rules**. The new 内部 (INTERNAL) role is a pure label with permissions identical to VIEWER — for distinguishing internal staff from external customers — and appears throughout the admin user management page (role filter tabs with count, list badges, inline role select, batch role change, edit dialog) and on the profile page in both locales. Model sharing is simplified to a single switch: any logged-in user can now share **any** model on the site (the previous "you can only share models you uploaded yourself" restriction is removed), gated only by the existing feature_shares_enabled master switch (关闭后用户无法创建分享链接，已有分享链接也将失效 — admins bypass it so they can re-enable). The redundant per-user 可分享模型 (canShare) toggle that briefly existed in development is fully removed (DB column dropped), and the redundant 允许分享 (share_enabled) business setting is retired from the settings page, public settings API, and selection-shares route — both sharing entry points (model share + selection share) now respect the same single master switch. Two DB migrations ship: one adds INTERNAL to the Role enum, one drops the can_share column; neither touches existing data. No breaking change beyond the removed setting key being ignored.

## 更新描述

本次新增**「内部」用户角色**并**简化模型分享规则**，包含数据库迁移，无数据风险。

- **[功能] 新增「内部(INTERNAL)」用户角色——纯标签，权限同访客**
  - 用于区分内部员工 / 外部客户，不获得任何后台或上传权限，所有管理员权限判断天然不受影响。
  - 后台用户管理全面支持：角色筛选 tab（含计数）、列表角色徽章（青色）、行内改角色下拉、多选批量改角色、编辑弹窗角色下拉；用户统计接口新增 internal 计数；CSV 导出自动兼容。
  - 个人页角色显示「内部 / Internal」（中英文）。
- **[调整] 模型分享规则简化：只看「分享功能」总开关**
  - **移除「只能分享自己上传的模型」限制**——任何登录用户都可分享站内任意模型。
  - 不再提供按用户的「可分享」开关（开发阶段的中间方案，正式版未发布过，数据库列已清理）。
  - 开关行为：后台「分享功能」开启 → 所有人可创建分享；关闭 → 谁都不能创建（管理员除外，便于重新开启），**已有分享链接同步失效**。
  - **退役「允许分享」(share_enabled) 设置项**——与「分享功能」语义重复，已从后台设置页与接口中移除；模型分享与选型分享现在都只受同一个总开关控制。
- **[数据库] 两个迁移，均为结构变更、无数据风险**
  - `Role` 枚举新增 `INTERNAL` 值（PostgreSQL ALTER TYPE ADD VALUE，单向不可回滚值）。
  - 删除开发中间态的 `users.can_share` 列。

前端「检查更新」会读取本更新描述展示最新版本号与更新内容。

## 部署备注

本次**有数据库迁移**（新增枚举值 + 删除一列），API 容器启动时会自动执行，无数据风险。升级步骤：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v3.8.0 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

curl -s http://localhost:3780/api/settings/version   # 应显示 v3.8.0
```

升级后注意：

- 后台设置里不再有「允许分享」开关，分享只由「功能开关 → 分享功能」一处控制。
- 如需把某些用户标记为内部员工，到后台用户管理改角色为「内部」即可，权限不受影响。

默认跟随 latest 的部署由 Watchtower 自动更新。
