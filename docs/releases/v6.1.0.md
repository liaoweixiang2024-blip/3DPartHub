# v6.1.0

发布日期：2026-10-22

## 更新标题

3DPartHub v6.1.0 - 通知体系完整版：新增账号安全通知（带 IP/时间）、收藏模型更新通知、系统公告广播三大类通知 + 通知开关角色治理（普通用户隐藏管理员专属死开关）+ 收藏/下载通知显示操作用户名 + 换绑邮箱旧邮箱无条件预警 + 3 个新邮件模板全链接线；用户通知设置从 2 项扩到 5 项，全站通知开关全覆盖

## 更新描述

本版是对通知体系的完整补账，共四批改动。① 开关角色治理：收藏/下载/转换/备份四类通知的触发链路全部要求管理员权限（上传/重转/备份体检），普通用户此前在通知设置里看到的是永远收不到消息的死开关——现按角色隐藏，通知中心的类型筛选下拉同款治理。② 新增两类用户通知：账号安全通知（改密码/换绑邮箱成功后通知本人，附操作 IP 与 UTC 时间）、收藏更新通知（管理员给模型传新版本/回滚/替换文件/删除下架/恢复上架时通知收藏者，同模型同用户 24h 去重防轰炸，删除/恢复等一次性事件跳过去重保证送达，删除下架不带失效链接）。③ 新增系统公告广播：系统设置 → 系统公告 tab 新增「发送站内公告」入口（标题 + 内容 + 确认弹窗，明示不可撤回），发送后全员通知中心红点提醒，尊重用户个人「系统公告」开关；与首页横幅公告相互独立互补。④ 安全与邮件补齐：换绑邮箱成功后向**旧邮箱**无条件直发预警邮件（防盗号信道，攻击者无法关闭，与验证码类同级）；收藏/下载通知显示操作用户名；新增 3 个邮件模板（账号安全提醒/换绑邮箱旧邮箱预警/收藏模型更新提醒）走双端注册表全链接线，管理后台「邮件服务」tab 新增两枚站点级开关。普通用户的通知设置现在是 5 项：工单、询价、账号安全、系统公告、收藏更新（邮件开关只对有邮件模板的类型显示）。

## 变更清单

### 1. 通知开关角色治理

- 普通用户通知设置隐藏 4 个管理员专属死开关（备份/收藏/下载/转换——收件人只可能是管理员）
- 通知中心「类型筛选」下拉同款治理，非管理员不再出现永远筛出空列表的类型
- 管理员视图无变化（全量 9 项开关）

### 2. 新增通知类型

- **账号安全通知（security）**：改密码/换绑邮箱成功 → 站内通知本人，附操作 IP 与 UTC 时间；「邮件」列走新模板 security_notice
- **收藏更新通知（model_update）**：模型传新版本/回滚/替换文件 → 通知收藏者（fan-out 上限 2000 保护，排除操作者本人，24h 去重）；**删除下架 → 「已删除下架」**（跳过去重、不带失效详情链接）；**恢复上架 → 「已恢复上架」**（跳过去重、带模型链接）
- 通知跳转：security → 个人设置页；model_update → 模型详情页；announcement → 首页

### 3. 系统公告广播

- 管理端：系统设置 → 系统公告 tab → 「发送站内公告」面板（标题 ≤120 字、内容 ≤2000 字、发送前确认弹窗）
- 服务端：POST /api/notifications/announcements（ADMIN only），按用户个人「系统公告」开关过滤（默认开），分块 createMany 写入
- 用户端：新开关「系统公告」，通知中心筛选/图标/路由全接线

### 4. 安全与邮件补齐

- **换绑邮箱旧邮箱预警**：新模板 security_email_changed 直发旧邮箱（新邮箱脱敏 + IP + 时间 + 应急指引），**无条件直发**——不走通知偏好/站点开关（防盗号信道）
- **收藏/下载通知显示操作用户名**：「有用户收藏了模型」→「用户「张三」收藏了模型」；「模型被下载」→「用户「张三」下载了模型」（匿名访客兜底「有用户」）
- 3 个新邮件模板按双端注册表 checklist 全链接线：server/client 注册表同步、编辑器分组（重要事务组 +2 / 通知类发用户组 +1）、emailTplNames/Descs 五语言、站点级开关 notify_email_security / notify_email_model_update
- 邮件偏好默认值：security 邮件默认开（受站点开关二次闸控）、model_update 邮件默认关（opt-in）

### 5. 默认通知偏好（新老用户自动合并生效）

- 站内：工单/询价/安全/公告/收藏更新 默认开；下载默认关（管理员 opt-in）
- 邮件：工单/询价/安全 默认开；收藏/下载/收藏更新/公告 默认关

## 审计确认

- 无数据库 schema 变更、无迁移（61 个迁移状态同步）
- 新增出网请求：仅换绑邮箱时向旧邮箱发一封预警邮件（走既有 SMTP 通道）
- 行为变更：普通用户通知设置项从 2 项变为 5 项；管理员通知设置新增 2 项；模型删除/更新会触发收藏者通知

## 验证

- client / server / 根 verify:deploy 三层全绿
- 公告 fan-out 实测：送达 6 人、关闭开关用户被跳过（sent 5 / skipped 1）
- 删除/恢复通知实测：删除下发「已删除下架」（无链接）、恢复下发「已恢复上架」（带链接），均跳过 24h 去重送达
- 安全通知实测：消息含 IP 与 UTC 时间，跳转个人设置页
- 用户设置面板实测：5 项开关全在、email 开关恰好 4 个（公告无邮件模板不显示死开关）
- 管理端实测：公告 tab 发送面板渲染、邮件服务 tab 两枚新站点开关渲染
- 24h 去重实测：连传两版只收到 1 条更新通知

