# v5.4.3

发布日期：2026-10-08

## 更新标题

3DPartHub v5.4.3 - 首页加载视觉优化五连修（刷新不再闪「未找到模型」/通知铃铛不再弹入/未登录不再闪骨架屏/刷新页头不再闪烁/模型数量不再从「—」跳到几千）

## 更新描述

本次为**纯前端视觉体验修复**版本：集中修复一批页面加载时序导致的视觉跳动与闪烁——空态闪现、元素弹入、骨架屏一闪、FOUC 底色闪白、数字跳变。**无数据库迁移、后端代码零改动**（api 镜像仅版本号随动），更新 web 镜像即生效。

## 背景

v5.4.2 修复登录会话恢复的 TDZ 崩溃后，此前被「乐观保活」掩盖的会话等待窗口真实化，暴露出一批潜伏的加载时序渲染缺陷（等待期被当成空态、元素晚到弹入、锁屏替换骨架等）。本版本逐一根因修复并本地实测验证。

## 修复清单

### 1. 刷新首页不再闪「没有找到匹配的模型」

空态判断此前只看 `products.length === 0`，数据未返回的等待期就被当成「没有结果」渲染了空态，数据到达后又被列表替换——看起来像先报错再有数据。列表骨架判定补上门槛未决/加载中的等待期，空态只在数据真正返回后才出现。

### 2. 右上角通知铃铛不再「弹入」

铃铛按登录态渲染，会话校验（一个网络往返）完成前渲染 null、之后才补位出现——视觉上是页面加载完铃铛突然弹进来。改为会话未决期先渲染同尺寸占位图标（顶栏与通知面板两处），位置从首帧起就固定。

### 3. 未登录不再闪一下首页骨架

开启「需要登录才能浏览模型」后，匿名刷新首页会先渲染模型列表骨架、随后整页被锁屏替换。门槛钩子（useBrowseGate）增加 pendingLock 三态：门槛判定未出结果且本地无已记住的登录身份时，首帧直接渲染锁屏，不再经历骨架→锁屏的整页替换。首页与选型页同步接入。

### 4. 刷新后页头/锁屏不再跳动闪烁

- 移动端：搜索框行在门槛判定期间不渲染、判定完成后才出现导致页头高度跳变；改为判定期间与锁屏态一致地隐藏
- FOUC：CSS 加载前空的 #root 无底色，深色模式下闪白再变暗。index.html 启动脚本在 CSS 加载前先给 `<html>` 设置主题底色与 colorScheme；主题初始同步与切换同一逻辑收口到 browserThemeColor（读 `--color-surface`，与页面首屏底色同源）

### 5. 模型数量不再从「—」跳到几千

- 数量未知时不再显示 0（0 → 几千像数据跳变），改显示「—」占位，`number | null` 类型贯穿两个主题桌面端、移动端与筛选抽屉的渲染层
- 新增分类树 localStorage 快缓存（stale-while-revalidate）：刷新首帧直接用上次数据渲染真实数量与完整分类列表，后台请求回来后原地更新——「—」→「xxxx 个模型」的跳变整体消失（首次访问仍显示「—」一次，随即建立缓存）。缓存按访客身份分桶（用户 id / 匿名），受限分类树不会跨身份闪现；7 天过期自动作废
- 所有数量角标启用等宽数字（tabular-nums），数量更新时逐位不挪动

## 验证

- client `npm run verify` 全绿（主题合同/加载合同/UX 合同/typecheck/lint/format/build/33 单测）；server 无代码改动，verify 维持全绿
- 生产构建产物复查：JS/CSS/HTML 源码注释全部剥离、sourcemap 显式关闭（0 个 .map 文件），部署后浏览器端不含任何注释文字
- 本地实测：登录/匿名/开启登录门槛三种形态下反复刷新首页与选型页，逐项确认无闪动；数量第二次刷新起首帧直接显示真实值
