# v5.3.6

发布日期：2026-10-07

## 更新标题

3DPartHub v5.3.6 - 下载统计新增设备维度（PC 端/移动端下载占比分布 + 下载记录行内设备图标）+ 续传预警提示延长至 8 秒 + 修复设备图标不渲染问题（lucide 映射缺失）

## 更新描述

本次为**下载统计增强**版本，含一次安全加列迁移（`download_events` 新增 `device` 列，纯增量、老数据自动记为 unknown，无数据风险）。更新前后端镜像即可；服务端容器启动时会自动应用迁移。

## 改动一：下载设备维度（PC 端 / 移动端）

- **背景**：站点移动端访问占比高，但下载统计看不出「手机下载多还是电脑下载多」，无法支撑「移动端下大文件体验差，要不要提示走电脑端」这类决策
- **统计页新增「设备分布」条**：概览卡片下方，移动端 / PC 端 / 未知三段占比条 + 次数与百分比，跟随搜索过滤（与格式分布同口径）
- **下载记录行内设备图标**：每条记录显示手机/电脑小图标（中性灰纯图标，无文字无底色）；上线前的历史下载无图标（记为 unknown）

| 层     | 改动                                                                                                                                                                     |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 数据库 | `download_events` 加 `device` 列（`mobile` / `desktop` / `unknown`，默认 unknown），迁移 `20261007032947_add_download_event_device`                                      |
| 服务端 | 新增 `server/src/lib/downloadDevice.ts`：UA 一行正则粗分类，**只存三值枚举不落完整 UA**（避免浏览器指纹隐私问题；iPadOS 13+ 桌面版 UA 伪装会计入 desktop，属可接受误差） |
| 记录点 | 6 处全部接线：模型下载（同步落库 + Redis 队列异步落库两条路）、后台批量打包、用户收藏打包、历史批量下载、**分享链接下载**                                                |
| 接口   | `GET /api/admin/downloads/stats` 新增 `deviceStats` 分组；stats 的 recentDownloads 与 `GET /api/admin/downloads/records` 每条返回 `device`                               |
| 前端   | `DownloadAdminPage` 设备分布条 + 行内图标徽章；`api/downloads.ts` 类型同步                                                                                               |

- 队列兼容：Redis 里的旧载荷无 `device` 字段自动落 unknown，无需清队列

## 改动二：设备图标渲染修复

- 项目 Icon 组件为 lucide-react 显式映射表，`smartphone` / `computer` / `devices` / `help` 四个名字原本不在映射里会渲染成**空 span**（同组件注释记载的历史坑）
- 已补映射：`smartphone→Smartphone`、`computer→Monitor`、`devices→MonitorSmartphone`、`help→HelpCircle`

## 改动三：续传预警提示时长

- v5.3.5 新增的「当前网络链路不支持断点续传」提示原为 3 秒，稍移开视线就错过；Toast 组件支持自定义时长参数，该预警延长至 **8 秒**

## 分享下载归因说明（无代码改动，排查澄清）

- 分享链接下载在统计中的归因链路（分享图标 + 分享创建者用户名）经库内真实事件核验一直正常，显示「未登录用户」的仅为匿名模型库下载
