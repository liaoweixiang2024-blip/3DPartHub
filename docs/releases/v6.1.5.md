# v6.1.5

发布日期：2026-11-09

## 更新标题

3DPartHub v6.1.5 - 选型分享页内容完整版（补画册资料/清单交互/复制型号/咨询客服，与向导结果卡片对齐）；卡片缩略图缺失时自动回落模型缩略图；搜索结果卡片新增单产品分享按钮（不用进向导结果页整体分享）；修复已登录打开分享页仍显示「登录」入口

## 更新描述

两部分改动：

1. **选型分享页内容补齐**：此前分享页卡片是精简版，比向导结果页少了一块内容。本次全面对齐：
   - **画册资料**：分享接口补画册解析（选项级目录 → 分类自带 → 按接头形态共享兜底，与向导接口同规则），分享卡片补「查看画册 / 放大查看」区块与放大弹窗（图片缩放平移 / PDF 内嵌同款）
   - **清单交互**：子零件清单此前一直展开撑长页面，现与向导一致默认收起、点「查看清单」展开
   - **复制型号**：型号旁补复制按钮，复制后图标变 ✓
   - **咨询客服**：卡片底部补「技术支持」按钮——已登录带型号与参数直达工单页；匿名访客（微信打开场景）弹登录确认框，登录后回到分享页再点即直达
   - **缩略图兜底**：产品没配图但匹配到 3D 模型时，卡片图自动用模型缩略图（分享页/向导结果/搜索列表三处统一，与全局搜索下拉同规则）
   - **登录入口修复**：顶栏「登录」链接此前写死不判断状态，登录后仍显示；现在已登录即隐藏

2. **搜索结果单产品分享**：向导内搜索结果与全站搜索「查看全部」列表的产品卡片，分类标签按钮旁新增分享图标按钮——点击直接创建该产品的分享链接（以产品所属分类建空参数快照），不用进向导结果页走整体分享；桌面复制到剪贴板、移动端先弹链接弹窗（可调系统分享）；未登录弹登录确认；站点关闭分享功能开关时按钮不渲染。分享出去的链接打开即是完整卡片（参数 + 清单 + 画册 + 模型入口）。
