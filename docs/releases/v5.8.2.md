# v5.8.2

发布日期：2026-10-15

## 更新标题

3DPartHub v5.8.2 - 移动端选型底部操作条不再随软键盘跳动（搜索底栏 + 询价/清单条钉死布局视口底部）

## 更新描述

v5.8.1 上线后发现移动端选型页两处底部操作条会随软键盘"飞到屏幕中间"大跳动：点击搜索按钮进入全页搜索（面板自动聚焦弹键盘）时「共 N 结果 / 查看全部 / 关闭搜索」整条被顶到屏幕中间；清单有货时在向导结果页/搜索列表点搜索框弹键盘，「已选 N 项」询价条同样跳动。根因是两条底栏的 bottom 计算引用了全局键盘联动变量 `--visual-viewport-bottom`（iOS 软键盘弹出时被写成键盘高度约 320~350px）。本版将两条底栏钉死在布局视口底部，键盘弹出/收起全程 0 像素跳动。

## 修复清单

- **全页搜索底部操作条键盘跳动**：bottom 去掉 `--visual-viewport-bottom`——面板进入即自动聚焦弹键盘，追键盘必然每次大跳动；钉死后键盘盖住它即可（与底部导航键盘弹出时滑出屏幕的行为一致，iOS 惯例），收起键盘自然复见，「关闭搜索」不受影响
- **询价/清单操作条同款跳动**（Playwright 实测复现：键盘变量 320px 时从 top 743 跳到 423 正好屏幕中间）：同修去掉键盘追跳变量
- 触发场景说明：清单有货时在向导结果页 / 搜索列表页点搜索框弹键盘，此前询价条会跳到屏幕中间挡内容

## 不变的部分（有意保留）

- 工单详情回复坞、询价提交弹窗仍随键盘抬升——它们是**输入区本体**（textarea/表单就在里面），跟随键盘才能看见正在输入的内容，属于聊天页标准交互，不是乱跳
- 底部导航键盘弹出滑出屏幕的行为不变

## 全站审计结论

- `--visual-viewport-bottom` 消费者修复后全站清零（grep 验证）
- 同时含输入框 + 固定底部条的页面全站仅 2 个：选型页（本轮已修）+ 工单详情页（正确模式）
- viewport meta 无 `interactive-widget` 覆盖，iOS / 现代 Android 键盘均不压缩布局视口，`#root` 与各弹窗的 `100dvh` 高度稳定，无塌缩跳动
