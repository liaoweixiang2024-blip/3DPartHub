# v5.2.5

发布日期：2026-09-29

## 更新标题

3DPartHub v5.2.5 - 移动端选型页禁用橡皮筋回弹（冻结头彻底钉死，到顶/到底拉拽纹丝不动）

## 标签描述

v5.2.5 removes the iOS rubber-band overscroll from the mobile selection page. On iOS, dragging past the top of a scroll container elastically drags the entire content — including the frozen header (title + search toolbar) — downward before it springs back, making the pinned header look loose and unstable. The root cause: the shared `.scrollbar-hidden` class only sets `overscroll-behavior-y: contain`, which blocks scroll chaining but does not disable the element's own bounce. The selection page's mobile scroll container now forces `overscroll-behavior: none` (matching the existing desktop home-scroller precedent), applied via an important-prefixed utility because unlayered global CSS otherwise outranks Tailwind utilities. Result: pulling down at the top (or up at the bottom) moves nothing at all — the header stays dead still and no accidental pull-to-refresh can trigger on Android. Works in both mobile browsers and the standalone PWA, on iOS 16+ and Android; systems older than iOS 16 (which lack overscroll-behavior support) keep the platform bounce. No database migrations.

## 禁用橡皮筋回弹

### 问题

移动端选型页滚动到顶后继续往下拉，滚动容器发生 iOS 橡皮筋回弹：整段内容（含冻结的标题卡与搜索工具栏）被弹性拖下再弹回——v5.2.4 刚把冻结头修到零位移，但回弹手势仍能把整块拖走，观感松垮不稳定。

### 根因

移动端主滚动器 `.scrollbar-hidden` 全局类只设置了 `overscroll-behavior-y: contain`——它仅阻断滚动链传播（防止拖动传导到外层），不消除容器自身的橡皮筋回弹；桌面端首页滚动器早有 `overscroll-behavior-y: none` 的消回弹先例，移动端选型页此前未覆盖。

### 修复

- 选型页移动端主滚动器强制 `overscroll-behavior: none`（经 `!` important 前缀覆盖全局 contain：无 layer 全局 CSS 级联优先级高于 Tailwind 工具类，普通工具类压不住）
- 到顶/到底继续拉拽纹丝不动，冻结头彻底钉死
- 附带阻断滚动链传播：Android Chrome 在列表顶部下拉不会误触发下拉刷新
- 浏览器与主屏 PWA 两种形态同时生效；iOS 16+ / Android 生效，更老系统（<iOS 16，不支持该属性）保留系统级回弹
