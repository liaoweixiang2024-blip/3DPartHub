## 更新标题

3DPartHub v5.2.0 - 选型数据包按分类导出/一键导入（含图片画册）+ 全站管理页性能优化 + 询价关闭批量导出 + 画册粘贴上传 + 选项值反查 + 产品批量管理

## 标签描述

v5.2.0 brings a full selection transfer workflow: admins can now export any subset of selection categories as a self-contained zip package (column settings, option images/catalogs config, all products incl. kit components, and the actual image/PDF asset files) and import it on another deployment with one click — existing same-slug categories are updated in place (products merged by model number, nothing deleted), missing ones are recreated, and assets are restored to disk with strict zip-slip protection. The inquiry-disabled selection flow gains a persistent cart with batch Excel export. The option-settings wizard gains paste/drag upload with hover-zone targeting (image vs PDF catalog), per-value product lookup ("N 型" dialog), and product batch operations (select-all / batch delete / batch hide). Result cards get a zoomable catalog viewer (images zoom, PDFs render inline) with a zero-shift add button. Model matching now indexes the model-number tail segment of "中文名\_型号" names, fixing PU8-style short part numbers never matching long-named models. Major performance work across admin pages (memoized rows + stable references on model/category/product-wall/selection pages: search typing drops from 240 to 0 re-renders per keystroke). Misc: unified result-card button sizing, 4-column export (型号/名称/数量/单位), archive icon mapping, and the transfer dialogs ignore overlay clicks (only close via button/Esc). No database migrations.

## 更新描述

本次为 **选型数据搬运 + 性能 + 批量能力** 多主题大版本，无数据库迁移，需同时更新两端镜像。

**① 选型分类数据包（本地站 ↔ 服务器站搬运）**

- 导出：选型管理 → 更多设置 → 导出数据包，勾选任意分类（可全选）打包 zip —— 含参数列设置、选项图片/画册配置、全部产品（含子零件清单）与图片/PDF 文件本体
- 导入：上传 zip → 预览清单（每分类标注「新建」或「覆盖更新（已有 N 型号）」+ 资产缺失提示）→ 确认导入；同名（slug）分类覆盖更新，产品按型号合并不删除服务器多出的型号；图片/PDF 落盘带 zip-slip 路径白名单防护
- 数据包上限 200MB（系统设置可调），暂存 1 小时自动清理，落盘文件走云备份钩子

**② 询价关闭时的批量导出**

- 询价功能关闭后选型结果可勾选多个型号加入清单（localStorage 持久，跨选型累计），一键导出 Excel（型号/名称/数量/单位四列）
- 「添加到清单 ↔ 已添加」按钮零位移（叠格文案 + 透明边框占位），不再挤动旁边按钮

**③ 选项设置增强**

- 画册资料修复 PDF 上传（原走图片端点一直是坏的），图片/PDF 支持点击/拖拽/剪贴板粘贴；鼠标停在哪个上传区 Cmd+V 就传哪个区（悬停高亮分流）
- 选项值卡片「N 型」角标一键反查对应产品与全部参数（弹窗表格随视口自适应加宽）
- 产品管理批量操作：全选 / 批量删除（二次确认）/ 批量隐藏 / 批量显示

**④ 选型结果卡**

- 画册资料改版：标题行与子零件清单同构（查看/收起 + 放大查看），图片点击放大、PDF 直接渲染内容，弹窗内可新窗口打开
- 底栏按钮字重/尺寸统一（主按钮与规格书/模型/技术支持一致）

**⑤ 模型匹配修复（PU8 类）**

- 模型库「中文名\_型号」命名（如 白色联管直通\_PU8）现在会为型号尾段单独立索引键，短型号不再被 60% 覆盖率门槛挡掉；选型结果的「模型」直达链接恢复命中

**⑥ 管理页性能（搜索卡顿清零）**

- 模型管理/分类管理/产品墙/选型管理四页：行组件 memo 化 + 列表 flatMap memo 链 + 稳定 handler 引用，搜索连续输入不再整表重渲染（240 次/键 → 0）
