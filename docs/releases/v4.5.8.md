## 更新标题

3DPartHub v4.5.8 - 模型查看器新增 SW 自由看图模式

## 标签描述

v4.5.8 adds an "SW view mode" toggle to the 3D viewer toolbar on the model detail and temp preview pages. When enabled, the viewer swaps the default orbit controls for a trackball controller (SolidWorks-like): rotate freely in any direction with no pole limitation (you can spin past top/bottom views endlessly), the mouse wheel zooms toward the cursor position, left-drag pans the model directly, and right-drag rotates. Rotation sensitivity is calibrated to match the default mode across window sizes. Toggling the mode hands over the current view anchor seamlessly (target + distance limits survive switches, presets and fit-to-view keep working, reset display turns it off). Also fixes two interaction bugs found during testing: a disposed trackball instance could re-register its keyboard listener and interfere with the default controls after closing SW mode, and React StrictMode double-mounting left the controls disabled so SW mode appeared frozen in local dev. Toolbar labels are translated in all six languages. Front-end only, no DB migration.

## 更新描述

本次为 **3D 查看器 SW 自由看图模式** 版本，无数据库迁移。

**① 新增：SW 看图模式（工具栏旋转箭头图标）**

- 模型详情页 / 临时预览页工具栏新增 SW 模式开关（桌面端），点击开启后进入类 SolidWorks 的自由看图：
  - **任意方向无限旋转**——换装轨迹球控制器，绕屏幕空间任意轴旋转，无「正上/正下极点卡住」限制（默认轨道控制器的固有约束），翻顶、翻底、斜滚都行
  - **滚轮朝鼠标位置缩放**——光标放在哪个尖角上放大，哪个尖角就钉在光标下，缩到哪、转到哪
  - **左键直接拖动模型**（平移）、**右键旋转**，中键缩放不变
- **旋转灵敏度与默认模式精确对齐**：按两种控制器的角度公式换算，并随窗口尺寸/全屏切换自动重算，任何窗口比例下手感一致
- **模式切换无缝衔接**：开启时继承当前观察中心与距离限制，视角不跳变；相机预设（正/背/等角）与贴合视图在 SW 模式下照常工作（会把视角拉回模型中心并重置向上轴）；「重置显示」会一并关闭 SW 模式
- 移动端不加此按钮（触屏双指捏合本就朝手势中心缩放）
- 工具栏文案六语言对齐（简中「SW 看图模式」/ 繁中自动转换 / English / 日本語 / 한국어 / Deutsch）

**② 修复测试中发现的两个交互问题**

- **关闭 SW 后默认模式失灵**：轨迹球的键盘监听有「按下自移除、松键挂回」机制，废弃实例可能在卸载后把自己重新挂回 window，与新控制器叠加打架——现在卸载时先停用实例再销毁，监听死循环断根
- **开发环境（React StrictMode）下开启 SW 完全不能操作**：StrictMode 的模拟卸载/重挂载会把控制器留在停用态——现在每次挂载显式恢复启用状态
