## 更新标题

3DPartHub v4.9.5 - 个人设置弹窗居中修复（动画填充根因）+ 用户菜单直达改密 + 移动端设置补全 + 螺纹工具页冻结菜单

## 标签描述

v4.9.5 fixes a long-standing dialog positioning bug and polishes mobile profile settings plus the thread-size tool. The change-password / change-email dialogs in profile settings were offset instead of fullscreen-centered: the page-enter animation used `fill-mode: both`, which leaves the final transform matrix on the element forever — and any non-none transform on an ancestor becomes the containing block for `position: fixed` children. The animation now fills `backwards` only, so the transform truly resolves to none after playback and dialogs center on the whole viewport again (verified on mobile 390×844 and desktop 1440×900). The top-bar user menu's 修改密码 entry now actually opens the dialog (`/profile?tab=security` was never wired up), and the touch-screen menu no longer opens-then-instantly-closes (hover intent is now gated to devices that can hover). Mobile profile settings gain the missing change-email entry (same two-step verification flow as desktop), a read-only email field in edit mode (email can't be edited inline), and the address field is now a province/city/district cascading picker. The thread-size tool page gets the product-wall-style frozen menu: table rows now flow with the page (swiping anywhere scrolls the page — previously the table swallowed all gestures with its own internal scroll), the title card scrolls away and the search + category bar pins to the top; horizontal scrolling and the frozen first column are preserved. Frontend-only release, no database migration.

## 更新描述

本次为 **个人设置修复 + 移动端补全 + 螺纹工具页交互改造** 补丁，纯前端改动，无数据库迁移，前后端镜像均需更新。

**① 修复：修改密码 / 换绑邮箱弹窗不居中（整体偏移）**

- 根因：页面进场动画 `animation-fill-mode: both` 把终态 transform 永久留在元素上（即使 to 帧写 `transform: none`，补间引擎也会以单位矩阵填充），非 none transform 的祖先会取代视口成为 `position: fixed` 弹窗的包含块
- 修复：动画填充改为 `backwards`（结束后真正回退到基础样式），弹窗恢复全屏居中；移动端 390×844 与桌面 1440×900 均验证居中

**② 顶栏用户菜单「修改密码」直达弹窗**

- `/profile?tab=security` 参数从 v1.0.0 起就从未接线，点击后只是跳到设置页；现在会直接弹出修改密码弹窗（支持二次点击重新触发）

**③ 触屏下拉菜单修复**

- 触屏点击顶栏用户菜单会「打开又瞬间关闭」：触屏点击先派发合成 mouseenter（开）再触发 click 切换（关）；hover 意图现在仅对支持 hover 的设备（鼠标）生效，触屏点击开合正常

**④ 移动端个人设置：补换绑邮箱入口**

- 移动端原来没有换绑邮箱的设置项；现与桌面端同款入口 + 两步验证流程（验证旧邮箱 → 绑定新邮箱）
- 附带修复：编辑模式下邮箱框看似可编辑实际保存无效，现改为只读样式并提示需走换绑流程

**⑤ 移动端个人设置：地址改为省市区三级联动**

- 地址原来是纯文本输入框，现换成与桌面端相同的 RegionSelect 省/市/区县级联选择器，保存验证正确

**⑥ 螺纹工具页：菜单吸顶冻结（与产品图库同款）**

- 滚动时标题卡自然滑出，搜索框 + 分类菜单吸附在顶部冻结（移动端 y=49 / 桌面 y=64，与产品图库逐像素一致）

**⑦ 螺纹工具页：表格改为页面流**

- 根治「在表格上滑动页面不动」：原表格有内部纵向滚动吞掉全部手势，页面永远不滚、冻结无从触发；现在 92 行随页面自然流动，任意位置（含表格上）滑动都滚页面
- 横向滚动 + 冻结首列保留；触摸轴锁定重写（纵向交还页面原生滚动，横向仍由表格接管）
- 取舍说明：表头不再纵向冻结（CSS 限制：sticky 无法穿透横向滚动容器），滚动时常驻上下文由吸附的搜索+分类菜单提供
