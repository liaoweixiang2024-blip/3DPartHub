## 更新标题

3DPartHub v4.5.9 - 系统选型导航页（SMC 拓扑图）+ 手机端全面适配

## 标签描述

v4.5.9 introduces a "System Selector Map" page (/category-nav) that reproduces the SMC catalog topology: 23 category slots arranged across four system groups (air preparation / cooling water / hydraulic lubrication / general parts) connected by a cyan pipeline diagram. Clicking a slot opens a borderless floating modal with a large hero image and its category chips — each chip opens the model library filtered by that category in a new tab. Categories without an uploaded image fall back to the category's Material icon. Fully responsive: desktop keeps the fixed topology canvas with horizontal scroll, mobile (<768px) switches to stacked group cards with a 3-column grid, and the modal scales its hero image and grid for small screens. Entry points: an icon beside the "Category Filter" sidebar title on desktop (both workbench and classic themes) and beside the "Product Catalog" title on the mobile home page. Admins get a dedicated management page (/admin/category-nav) with drag-sort ordering, per-slot image upload, and multi-category binding, stored as a JSON setting (zero DB migration) behind a feature toggle (feature_category_nav_enabled). Also fixes model preview thumbnails being cropped on foldable/tablet-width phones: the mobile card media slot now scales by aspect ratio with object-contain instead of a fixed 140px height with object-cover.

## 更新描述

本次为 **系统选型导航页（SMC 拓扑图）** 版本，无数据库迁移。

**① 新增：系统选型导航页 `/category-nav`**

- 复刻 SMC 选型程序「按系统选择」拓扑图：四大分区（气源处理 / 冷却水路 / 液压润滑 / 通用件与资料）共 23 个卡位，天蓝色管线贯穿全图
- 点击卡位弹出**无边框悬浮弹窗**：背景微模糊压暗，中央大图（节点图 / 分类图 / 默认 SMC 插画回退链）+ 分类网格，整卡可点新窗口打开模型库分类过滤
- 分类未配图时用分类目录的 Material 图标兜底（浅色圆片，排版小一档）；单分类为紧凑横排行
- **手机端完整适配**（<768px）：分区卡片纵向堆叠 + 3 列网格（管线画布仅桌面显示），弹窗大图/网格缩档、底部避开刘海屏、末分区不被底部导航遮挡
- **入口**：PC 端在「分类筛选」侧边栏标题旁（workbench / classic 双主题）、手机端在首页「产品目录」标题旁，均跟随功能开关
- **后台管理页** `/admin/category-nav`：拖拽排序、逐节点换图（文件覆盖 + 版本参数破缓存）、多分类绑定，配置存 Setting JSON（零迁移）
- 功能开关三层接线：`feature_category_nav_enabled`（默认开启），关闭后路由 FeatureGate 拦截、入口隐藏

**② 修复：折叠屏 / 平板宽度下模型预览图被裁切**

- 手机端卡片图片槽由固定 `140px` 高 + `object-cover`（裁切填满）改为 **4:3 比例高度 + `object-contain`**——折叠屏展开（700px+ 宽）每列变宽时，预览图等比缩放完整显示，不再只剩中间一条
- 实测 375 / 540 / 717 / 767px 四档视口均完整显示、无横向溢出

**③ 其他**

- 手机端页面底部内容不再被固定底部导航栏遮挡（移动端堆叠容器加让位 padding）
- 选型导航页手机端副标题放开单行截断（允许换行至 2 行）
- SelectionPage 支持 `?c=<slug>` 深链直达选型分类
