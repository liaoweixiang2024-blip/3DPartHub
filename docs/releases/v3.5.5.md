## 更新标题

3DPartHub v3.5.5 - 移动端模型首页分类筛选体验优化（分类高亮 / 滚动跟随 / 浮动筛选按钮）

## 标签描述

3DPartHub v3.5.5 focuses on the **mobile home category bar UX**. Four front-end-only fixes, no back-end change, no DB migration, no breaking change.

1. **Parent category now highlights when a child is selected in the filter drawer**: the horizontal category row only shows top-level categories. Previously, when a user picked a sub-category from the filter drawer, no chip in the horizontal row highlighted — so the user couldn't see what was selected. The parent of the active sub-category now highlights, matching the drawer's behavior.
2. **Active chip auto-scrolls into view**: when the selected category changes (e.g. choosing an off-screen sub-category in the drawer), the highlighted chip is now scrolled into the visible area, with right-side space reserved for the floating filter button so it never hides the active chip.
3. **App-Store-style chips fill the full row**: the category bar now spans the whole row, and the filter button floats over the top-right corner instead of sitting inline. This fixes the filter button squeezing / overlapping categories when scrolling down.
4. **Floating filter button restyled**: the floating button now matches the header filter button (`rounded-sm`, `bg-surface-container-high`) instead of the over-rounded pill — consistent visual language, no longer too round.

Back-end unchanged. v3.5.3/v3.5.4 security hardening is fully retained.

## 更新描述

本次是**移动端模型首页分类筛选体验优化**，纯前端修复，无后端变更、无数据库迁移、无破坏性变更。

- **分类高亮修复**：横向分类条只显示顶级分类。之前在筛选抽屉里选了某个子分类后，横向这一行没有任何项被高亮，用户看不到自己选了什么。现在选中的子分类的**父分类会高亮**，和抽屉里的表现一致。
- **选中项自动滚到可视区**：选中的分类变化时（比如在抽屉里选了一个屏幕外的子分类），高亮的分类会自动滚动到可见区域，并为右侧浮动筛选按钮预留空间，避免高亮项被按钮挡住。
- **分类条占满整行（App Store 风格）**：分类条现在铺满整行，筛选按钮改为悬浮在右上角，解决了下拉滚动时筛选按钮挤压、遮挡分类的问题。
- **浮动筛选按钮样式统一**：浮动按钮改回与顶部筛选按钮一致的样式（小圆角、统一背景色），不再过圆，视觉更协调。

后端无任何改动，v3.5.3 / v3.5.4 的全部安全加固均完整保留。

前端「检查更新」会读取本更新描述（GitHub Release 内容），展示最新版本号与更新内容。
