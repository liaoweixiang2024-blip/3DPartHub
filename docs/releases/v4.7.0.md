## 更新标题

3DPartHub v4.7.0 - 模型库导出/导入 + 离线转换导入 + 转换失败治理 + 系统选型导航全面打磨

## 标签描述

v4.7.0 adds site-to-site model library transfer tools and a major polish pass on the system selector map. New admin capabilities: export selected models as a zip package (preview + drawings + original files + manifest), import that package on another deployment with per-model category mapping and automatic same-name category matching; an offline conversion path for oversized parts that exhaust server memory (run `npm run convert:offline` locally, upload the .offline.zip and the model is restored without touching the conversion queue); a "conversion failed" view in model admin with failure reasons and one-click cleanup of failed leftovers; and failed/processing models now render a clear status page (with delete entry) instead of a ghost detail page. The /category-nav selector map got a full visual overhaul: colors now follow the color scheme engine, pipelines are measured from real DOM geometry (thin rounded lines that track layout changes), the desktop layout fits one screen with viewport-scaled sizing and fills 4K displays, and only configured slots render (no more unnamed placeholder cards). The admin nav manager was restructured: four fixed groups with per-group slot caps, node reorder now carries the default illustration with the node (iconKey stored in config), WYSIWYG thumbnails, compact collapsible group rows with expand/collapse-all, editable page title/description, plus fixes for invisible delete/drag buttons and clipped thumbnails. Saves now refresh the same browser's config cache so the public page follows within ~1 second. No database migration.

## 更新描述

本次为 **模型治理工具 + 选型导航打磨** 功能版本，无数据库迁移。

**① 模型库导出 / 导入（站点间搬运）**

- 后台「模型管理 → 全部模型」勾选模型 →「导出选中」得到 zip 包（含预览、图纸、原始文件与清单）
- 目标站点后台「导入模型」：上传 zip → 解析清单 → 自动匹配同名分类 → 可逐个改分类或一键统一 → 导入结果汇总
- 适合本地站整理好内容后整体搬到生产站

**② 离线转换产物导入（大模型救星）**

- 服务器内存不足转不动的大文件：在本地仓库 server 目录执行 `npm run convert:offline -- /path/模型.STEP`
- 模型详情页「导入离线转换产物」上传产出的 .offline.zip，模型直接恢复为可用，不经过服务器转换队列
- 含原始文件时下载原件同步可用

**③ 转换失败治理**

- 模型管理新增「转换失败」筛选与列表，展示每条失败原因（内存不足 / 引擎崩溃等）
- 一键清理失败残留：软删（自动转移分组主版本）→ 清理残留文件 → 硬删记录，支持勾选部分或全部
- 转换中 / 失败模型详情页不再渲染半空的「幽灵页」，改为明确的状态页并带删除入口

**④ 系统选型导航（/category-nav）视觉打磨**

- 配色全面接入「配色方案」引擎：管线、围合框、弹窗均随主色联动，明暗主题正确
- 管线重画：按四个分区真实包围盒实测几何绘制细线 + 圆角肘，缩放 / 字体加载自动重算跟随，不再粗细不均、错位、分叉悬空
- PC 一屏化：卡位插画与间距随视口高度伸缩，常规屏一屏放下不出滚动条；2K/4K 放开上限、内容垂直居中撑满
- 卡位按后台配置数量渲染——有多少显示多少，未配置不再出现「未命名」占位卡

**⑤ 导航管理页（/admin/category-nav）重构**

- 固定 4 个大类（气源 / 冷却 / 液压 / 通用），不可增删；各组卡位上限（6/7/5/5），满员后「添加节点」置灰
- **默认插画写进节点配置**：后台打开时自动回填，之后调换顺序插画跟着节点走；后台缩略图直接预览默认插画 / 分类目录图标，删除自定义图立即恢复默认
- 大类折叠改为紧凑摘要行，新增「全部展开 / 全部收缩」；大类名点击编辑按钮修改（回车提交、Esc 取消）；移除组颜色设置
- 节点与分类项缩略图统一尺寸并放大，修复 grid 内百分比约束失效导致的图片显示不全
- 修复分类项删除按钮、拖拽把手因图标映射缺失「隐形不可点」的问题
- 页面标题 / 描述可后台自定义（留空使用默认文案）
- 保存后主动刷新本浏览器配置缓存，已打开的前台页面约 1 秒内跟随更新
