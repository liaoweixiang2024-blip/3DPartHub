## 更新标题

3DPartHub v3.4.8 - 功能开关真正关闭 / 新增临时看图开关 / 管理员同样受开关约束

## 标签描述

3DPartHub v3.4.8 patch release. (1) Feature toggles now "truly close": added a route-level `<FeatureGate>` guard so disabled features (/selection, /downloads, /product-wall, /favorites, /my-shares, /my-inquiries, /support, /my-tickets) show a "feature disabled" placeholder on direct URL access instead of loading then failing on the first API call; `/register` redirects to `/login` when registration is off. Residual hardcoded ticket entries (search no-result "request model", floating menu, model-detail "custom support") are also hidden when tickets are disabled. (2) New "temporary viewer" toggle (`feature_temp_viewer_enabled`) in Settings → Access & Security → Feature toggles — disables the STEP/STP temp preview tool site-wide (top nav, user dropdown, /temp-viewer route, upload API). Default enabled. (3) Feature toggles now bind admins too — admins no longer bypass disabled features in the UI; backend featureGuard keeps admin bypass only so admins can still manage existing data in a disabled area (e.g. resolve old tickets). (4) Engineering: frontend test scaffolding (node:test + tsx) with first pure-function cases; server unit-test hang fix (--test-force-exit) and CI glob fix so all nested test files run; behavior-preserving extraction of backup archive-safety and backup-status display logic into pure modules. No DB migration (feature toggles are settings key-value entries; new keys default enabled).

## 更新描述

- **功能开关「真正关闭」**：此前后台关闭某功能后，导航菜单虽已隐藏，但直接在地址栏输入 URL（如 /downloads、/selection、/product-wall、/support、/my-tickets 等）仍能进入页面，直到执行操作时才被后端拒绝，体验割裂且容易误以为功能还开着。本次新增路由级守卫：关闭的功能直达 URL 会显示「功能已关闭」占位页并提供返回首页入口；注册功能关闭时 /register 自动跳转登录页。同时补齐了组件内的硬编码残留入口——搜索无结果时的「请求模型」、浮动菜单、模型详情页「定制支持」等在工单功能关闭后一并隐藏；选型页在「选型开 + 询价关」时也会隐藏「加入询价」按钮与询价车。
- **新增「临时看图」开关**：后台「设置 → 访问与安全 → 功能开关」新增「临时看图」一项。关闭后用户无法使用临时看图上传 STEP/STP 模型进行预览，顶部导航、右上角用户下拉、直接访问 /temp-viewer 与上传接口全部关闭。默认开启，不影响现有站点。
- **管理员同样受功能开关约束**：此前管理员账号会自动绕过所有功能开关（关闭后仍能看到并进入各功能），容易让人误以为开关没生效。本次调整后，功能开关对所有人生效，包括管理员——关闭某功能后管理员也看不到入口、直达路由同样显示「功能已关闭」。管理员后台管理页（模型 / 工单 / 询价管理等）仍由角色权限控制，不受影响；后端仍保留管理员对已关闭功能存量数据的管理能力（如继续处理历史工单），因此不会影响日常运维。
- **工程改进（不影响功能）**：建立前端测试脚手架（node:test + tsx，首批覆盖公安备案号链接构造等纯逻辑），为后续开发提供回归保护；修复后端单测在本地跑完后挂起不退出、以及 CI 漏跑嵌套测试文件的问题；将备份归档路径安全校验、备份保护状态展示逻辑抽取为独立纯函数模块（行为完全不变，更易维护与测试）。
- 前端「检查更新」会读取本更新描述（GitHub Release 内容），展示最新版本号与更新内容。

## 部署备注

本次改动**不涉及 docker-compose / 数据库迁移**，纯镜像内的代码与前端资源变更。默认跟随 latest 的部署由 Watchtower 自动更新；需要立即更新时执行：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v3.4.8 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

# 快速健康检查
curl http://localhost:3780/api/health
curl -s http://localhost:3780/api/settings/version   # 应显示 v3.4.8
```

升级后如需关闭「临时看图」或验证某功能开关，进入后台「设置 → 访问与安全 → 功能开关」切换，并用普通账号（非管理员）强制刷新验证入口与直达路由是否已关闭。
