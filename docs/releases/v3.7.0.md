## 更新标题

3DPartHub v3.7.0 - 后台模型管理：多选模型批量修改分类

## 标签描述

3DPartHub v3.7.0 adds **batch category change** to the admin Model Management page. Admins can now multi-select models (or use 选择全部 / select-all-matching with the current search + category filter) and move them all to a different category in one action — previously each model had to be edited one by one. A new endpoint `POST /api/models/batch-update-category` (admin-only, rate-limited) mirrors the existing batch-delete contract: explicit `modelIds` list (cap 500) or `allMatching + filters` (cap 5000, recursive child-category expansion). Execution is a single atomic `updateMany`; models already in the target category are skipped automatically (including uncategorized ones, which are matched explicitly since Prisma's `not` ignores NULL), and the response reports `{ requested, updated }` so the UI can show the skipped count. Model/category caches are invalidated the same way as the single-model edit. On the frontend, a new 批量改分类 button appears next to 批量删除 in the selection toolbar on both desktop and mobile, opening a shared dialog that reuses the same CategorySelect dropdown as the single-model editor; the confirm button stays disabled until a category is picked, and a success toast reports how many were moved and how many skipped. No DB migration, no breaking change.

## 更新描述

本次为后台「模型管理」新增**批量修改分类**能力，无数据库迁移、无破坏性变更。

- **[功能] 多选模型一键改分类（桌面端 + 移动端）**
  - 之前想给一批模型换分类只能逐个点「编辑」改，现在勾选多个模型（或筛选后点「选择全部」）→ 工具栏点「批量改分类」→ 弹窗选择目标分类 → 确认，一次完成。
  - 弹窗与单个编辑用**同一个分类选择组件**，显示本次将修改的模型数量；未选分类时确认按钮置灰。
  - **已在目标分类下的模型自动跳过**，完成后 toast 明确提示「已修改 X 个，Y 个已在目标分类自动跳过」。
  - 支持「选择全部」语义：按当前搜索词 + 分类筛选匹配的全部模型一起改（含子分类递归展开，与批量删除口径一致）。
- **[后端] 新增 `POST /api/models/batch-update-category`**
  - 管理员权限 + 限流，与批量删除同一套校验风格：显式勾选上限 500 个 / 按筛选全量上限 5000 个（超出提示缩小范围）。
  - 单条原子 SQL 更新（`updateMany`），无逐条循环；未分类（无分类）的模型也会被正确匹配并归入目标分类。
  - 模型列表 / 分类树缓存失效逻辑与单个编辑完全一致，改完前台分类立即生效。

前端「检查更新」会读取本更新描述展示最新版本号与更新内容。

## 部署备注

本次**无数据库迁移、无破坏性变更**。直接升级即可：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v3.7.0 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

curl -s http://localhost:3780/api/settings/version   # 应显示 v3.7.0
```

默认跟随 latest 的部署由 Watchtower 自动更新。
