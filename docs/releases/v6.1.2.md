# v6.1.2

发布日期：2026-11-06

## 更新标题

3DPartHub v6.1.2 - 选型清单导出支持自定义文件名（弹窗预填默认名可直接下载也可改名），修复安卓/鸿蒙等国产手机默认浏览器打开网站「字体和布局整体变大」的显示问题

## 更新描述

两处改动：

1. **导出文件名确认弹窗**：选型页「导出选中」不再点击后直接下载，而是先弹出文件名确认框——预填默认名（`选型清单_年月日-时分`，打开时刻生成）并自动全选，不改名直接点「下载」即按默认名导出，也可改名后下载。输入框右侧常显 `.xlsx` 扩展名缀饰；文件名自动剔除 Windows/macOS 非法字符（`/ \ : * ? " < > |` 及控制字符），清空后回退默认名；支持 Enter 提交、Esc / 取消按钮 / 点遮罩关闭；下载中按钮转圈防重复触发。弹窗样式与分享链接弹窗同款（移动端底部弹起 / 桌面居中），移动端桌面端均已接线。

2. **国产浏览器整页放大修复**：安卓/鸿蒙等系统默认浏览器（华为/小米/OPPO/vivo 等）会把系统「字体大小」设置（fontScale）注入网页根字号——全站 Tailwind 工具类以 rem 为单位，根字号被乘系数后整站等比放大，表现为「字体和布局整体很大」（iOS/桌面/Chrome 不受影响）。本次在全局样式显式钉死根字号 16px（与设计基准完全等价，Chrome/Safari 零变化），并补齐无前缀版 `text-size-adjust: 100%`（此前构建产物只有 Tailwind preflight 的 `-webkit-` 版，部分国产内核只认标准写法）。说明：系统「显示大小」（DPI）调大导致的整页放大（连图片都大）不在拦截范围内；依赖系统字体缩放的老花用户仍可用双指捏合缩放（未禁 user-scalable）。
