## 更新标题

3DPartHub v3.6.0 - 后台模型管理：空分类筛选条不再消失 + 列表列宽统一

## 标签描述

3DPartHub v3.6.0 ships two frontend-only fixes to the admin **Model Management** page (后台模型管理). (1) **The category filter no longer vanishes when the selected category has 0 models.** Previously the whole toolbar (category filter + count + select-all + batch-delete) was wrapped in a single `models.length > 0` guard, so picking an empty category made the filter disappear along with the list — leaving the user stuck on that category, unable to switch back to "全部分类" or any other category. The category filter is now treated as a navigation control and always renders on the models tab; only the count / select-all / batch-delete action controls hide when the list is empty. (2) **Table column widths are now consistent across categories / pages.** The model table previously used `table-auto`, so column widths were driven by content (model-name length, format string, category-path length) and visibly shifted when switching categories or paginating. The table is now `table-fixed` with each non-model column pinned to a fixed width and the model column taking the remaining space (long names / category paths truncate cleanly); additionally the scroll container uses `scrollbar-gutter: stable` so the table width no longer jumps by the scrollbar width (~15px) between "has models / shows scrollbar" and "empty / no scrollbar" states. Frontend-only, no DB migration, no breaking change.

## 更新描述

本次**纯前端**两项修复，针对后台「模型管理」页面，无数据库迁移、无破坏性变更。

- **[修复] 选中空分类时分类筛选条消失（无法切回）**
  - 之前整个工具栏（分类筛选 + 已加载计数 + 选择全部 + 批量删除）统一挂了 `模型数 > 0` 的守卫，导致选中一个**没有模型**的分类后，列表为空、筛选条也跟着没了——**卡死在那个空分类里，切不回「全部分类」或别的分类**。
  - 现在分类筛选作为**导航控件常驻显示**（只要在「模型」tab）；只有「已加载 X / Y 计数」「选择全部」「批量删除」这些**操作控件**在列表为空时隐藏（本来就该藏）。
  - 移动端无此问题（分类下拉本就常驻），本次仅修桌面端。
- **[体验] 各分类的列表列宽统一，不再抖动**
  - 之前表格用 `table-auto`（列宽由内容决定），不同分类、不同页的模型名长短 / 格式（STEP、SLDPRT）/ 分类名长度都不一样，列宽就跟着抖动，看着不整齐。
  - 改为 `table-fixed` + 各列定宽（复选框 / 分类 / 格式 / 大小 / 图纸 / 操作都固定，模型列吃剩余空间），长模型名、长分类路径用 `truncate` 干净裁剪、悬停看全名；操作列给足宽度，保证「查看 / 编辑 / 删除」三个按钮永不换行。
  - 额外修掉**有模型 vs 无模型列宽还差一点点**：滚动面板加 `scrollbar-gutter: stable`，始终预留滚动条槽位，模型多出滚动条时表格不再被吃掉 ~15px 宽度，四种状态下列宽完全一致。此改动同时作用于「建议 / 分组 / 已删除」三个 tab 的面板。

前端「检查更新」会读取本更新描述展示最新版本号与更新内容。

## 部署备注

本次**纯前端、无数据库迁移、无破坏性变更**。直接升级即可：

```bash
cd /opt/3dparthub
docker-compose pull               # 拉取 v3.6.0 api / web 镜像
docker-compose up -d              # 重建 api / web 容器（保留数据卷，绝不用 down -v）
# 更新后强制刷新浏览器：Cmd+Shift+R（Mac）或 Ctrl+Shift+R（Windows）

curl -s http://localhost:3780/api/settings/version   # 应显示 v3.6.0
```

默认跟随 latest 的部署由 Watchtower 自动更新。
