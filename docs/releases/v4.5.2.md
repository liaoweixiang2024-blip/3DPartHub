## 更新标题

3DPartHub v4.5.2 - 多文件夹拖入标题修复 + 待传列表可继续添加 + 上传结果跨组汇总 + 内容指纹防重传

## 标签描述

3DPartHub v4.5.2 fixes multi-folder batch upload titles and adds content-fingerprint duplicate protection. When several folders are dropped at once, the client now splits them by root folder and packs each into an independent ZIP — the server's single-part-folder detection requires exactly one root folder per archive, so the previous single combined ZIP made folder names parse as categories and model titles degrade to file names. The pending list gains a compact "继续拖入或点击添加" drop zone so more folders/archives/files can be appended after the list is shown, and the upload button count shows both ("4 个文件夹 + 2 个文件"). Multi-folder results are now aggregated across groups (previously only the last folder's stats were shown — uploading 2 folders displayed "1 成功"). Duplicate protection: uploading a file that already exists in the same category with identical content (same original filename AND size) is skipped with a clear message; same name but modified content (re-upload after a part revision) is inserted as a new record, keeping the old model and its files intact — matching the existing manual version-merge workflow. Different categories allow same names as before. No DB migration.

## 更新描述

本次为**批量上传修复 + 防重传**版本，无数据库迁移。

**① 多文件夹拖入：标题恢复为文件夹名**

一次拖入 4 个文件夹时，此前前端把它们合成 1 个 ZIP——服务端「单零件文件夹」识别要求包内只有一个根文件夹，合包后文件夹名被当成分类名，模型标题退化成文件名（去掉扩展名）。现在拖入后按**根文件夹拆组**，每个文件夹独立打 ZIP 依次上传，标题=文件夹名、变体子夹跳过、PDF 配对全部按组正确解析。

**② 待传列表可继续添加**

列表显示后，下方新增紧凑拖拽区「＋ 继续拖入或点击添加（文件夹 / 压缩包 / 文件）」——可继续追加任意批次；开始上传按钮计数同时显示两类（如「4 个文件夹 + 2 个文件」）。

**③ 上传结果跨组汇总**

多文件夹依次上传时，结果面板此前只显示最后一组的统计（传 2 个文件夹显示「1 成功」）。现在成功/失败/跳过/PDF 绑定数跨组累加，完成后显示总数。

**④ 内容指纹防重传**

- 同分类 + 同名 + **文件完全一致**（原始文件名+大小相同）→ 跳过：「该分类下已存在同名且内容相同的模型」，不重复入库
- 同分类 + 同名 + **文件改过**（零件改版后重传）→ 正常入库为**新的一条**，旧模型及其文件**原样保留**（确认新版无误后手动删旧的；正式版本合并走模型详情页的上传新版本）
- 不同分类同名照常允许；回收站（已删除）的模型不挡重传
