# v5.4.5

发布日期：2026-10-08

## 更新标题

3DPartHub v5.4.5 - 系统选型导航移动端体验两连修（滑动不再显示滚动条 + 滚到底分区卡紧贴底部菜单栏，消除底部空带）

## 更新描述

本次为**系统选型导航页（/category-nav）移动端专项修复**：隐藏滑动时右缘浮出的系统滚动条；消除滚到底后最后一张分区卡与底部菜单栏之间的空带。纯前端改动，无数据库迁移、后端代码零改动（api 镜像仅版本号随动），更新 web 镜像即生效。

## 修复清单

### 1. 移动端滑动不再显示滚动条

本页移动端的滚动器是画布层（`overflow-x-auto` 使两轴都为 auto），iOS/Android 触摸滑动时系统会在屏幕右缘短暂浮出覆盖式滚动条。触摸滚动本身已有直接反馈，滚动条纯视觉噪音——移动端三引擎全隐藏（iOS Safari / Android Chrome·Edge / Firefox），桌面端横向滚动条**保留**（拓扑画布 1100px+ 宽，横滚位置是有效定位线索）。

### 2. 滚到底分区卡紧贴底部菜单栏（消除底部空带）

- **之前**：滚动器底部本就结束在底部菜单栏上方（外层包装层 `pb-safe-nav` = 5rem + 安全区，已让过位），但内容块内还叠加着 `pb-24`（96px）让位内边距——**双重让位**，滚到底后最后一张分区卡与菜单栏之间永远隔着 ~120px 空带，看着像多出一个分割区块
- **现在**：本页移动端不再使用公共包装层间距，自己精确接管——底部让位只留菜单栏实际高度（3.5rem + 安全区），容器内不再叠加任何 padding；顶部与两侧维持原 16px 间距不变。实测滚到底时最后一张卡与菜单栏上缘 0px 贴合
- 桌面端（≥768px）零改动（`max-md:` 前缀全部不生效）
