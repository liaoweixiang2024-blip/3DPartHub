# v6.1.6

发布日期：2026-11-24

## 更新标题

3DPartHub v6.1.6 - 模型编辑弹窗支持拖拽上传：图纸 PDF 与替换模型文件可直接拖入弹窗（模型详情页 + 管理后台两处入口一致），拖入整块高亮提示，松手即走与点按钮完全相同的校验和上传流程

## 更新描述

管理员在模型编辑弹窗里上传图纸 PDF、替换模型源文件（STEP/IGES）此前只能点按钮打开文件选择框。本次两个入口都支持**直接拖拽文件进弹窗**：

- **覆盖位置**：模型详情页「编辑」弹窗、管理后台模型管理页「编辑」弹窗，两处行为一致
- **交互**：拖文件悬停时按钮区域整块高亮（主色描边），松手即上传；按钮下方新增「也可将文件直接拖到此处」提示
- **校验一致**：拖拽与点按钮走同一条校验+上传链路（PDF 类型/大小、STEP/IGES 扩展名、上限 MB 全部照旧），错误照常弹 toast
- **细节**：上传进行中拖入无反应（防重复提交）；拖拽经过区域内子元素高亮不闪烁；多文件拖入取第一个（与单选行为一致）；预览图上传维持原方式不变

## 变更清单

- `client/src/components/shared/FileDropArea.tsx`（新增）：通用拖拽落区组件——块级包裹不改变布局，dragover 高亮 / relatedTarget 防子元素边界闪烁 / drop 回调首个文件
- `client/src/components/model-detail/DetailEditDialog.tsx`：图纸与替换模型文件上传逻辑提取为共用 handler（`handleDrawingFile` / `handleReplaceFile`），按钮区包 `FileDropArea`；顺带修复替换文件选错格式后 input 未清空的小瑕疵
- `client/src/components/model-admin/EditDialog.tsx`：同构改造（图纸 / 替换模型文件两处）
- `client/src/i18n/locales/`（zh-CN / en-US / de-DE / ja-JP / ko-KR）：新增 `common.dropFileHint` 一个 key（zh-TW 薄覆盖回退 zh-CN）
