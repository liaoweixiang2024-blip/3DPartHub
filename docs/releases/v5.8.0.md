# v5.8.0

发布日期：2026-10-15

## 更新标题

3DPartHub v5.8.0 - 选型搜索直达结果页 + 移动端整页搜索模式（搜索/结果/操作条一张卡）+ 全部搜索列表自动加载

## 更新描述

选型全局搜索三连升级：① 全站搜索列表卡片上的来源标签按钮现在**按产品自身参数把该分类选项一次选满、直接落在「选型结果」页**——型号已经搜到了就不必再一步步选选项，产品没有值的参数项自动跳过（跳过项不参与筛选，结果仍含该产品）；参数与分类列完全对不上的产品退化为从第一步开始。② 移动端点搜索图标进入**整页搜索模式**：统计条与分类内容让位，搜索框、结果、底部操作条（共 N 个结果 / 查看全部 / 关闭搜索）合并为与标题卡同款的一张卡片，整卡钉满标题下方到屏幕底之间，结果区内部滚动、滚到底自动翻页；关闭搜索即完全恢复进入前的分类页面。③ 搜索滚动体验：桌面下拉计数条移出滚动区（触摸回弹不再拽动底栏）、移动端结果行去掉按压缩放（滑动不再「跳动」）、滚动条隐藏、「查看全部」列表去掉手动"继续加载"按钮改为滚到底自动加载（翻页小转圈回到计数右侧）。

## 新增功能

### 1. 全站搜索列表 → 标签按钮直达选型结果页

- 列表卡操作行的来源标签按钮：按该产品 specs 把分类全部选项一次选满 → 直接落在「选型结果」页（含产品卡、重新选择、分享等全部结果页能力）
- 产品无值的参数项自动「跳过」——跳过项不参与筛选，结果仍包含该产品；点已完成步骤 chip 仍可回改单项
- 产品参数与分类向导列完全无交集时（画册型数据）退化为进入该分类从第一步开始
- 浏览器返回仍恢复搜索列表（词与结果不丢）

### 2. 移动端整页搜索模式

- 点标题行搜索图标进入：产品大类/分类/型号统计条与分类网格整体让位，搜索区铺满内容区
- 搜索框 + 结果/空态 + 底部操作条（共 N 个结果 · 查看全部 · 关闭搜索）为**同一张卡片**——与标题卡同款圆角/描边/底色，间距与标题卡到统计条一致（12px）
- 未输入词或无匹配时整卡空态居中（「未找到匹配的产品」）；底栏右侧「关闭搜索」完全恢复进入前页面
- 点结果行直达该分类向导（型号预填）；向导 ✗ 清空回搜索回路照常回到本面板接续搜索
- 「查看全部」进入全站结果列表（与桌面同入口）

### 3. 搜索列表自动加载

- 「查看全部」全站列表：移除手动「继续加载」按钮，滚动到列表尾部（480px 提前量）自动加载下一页（IntersectionObserver 哨兵，桌面内滚动/移动端页面滚动均支持）
- 翻页中小转圈显示在「共 N 个结果」右侧（桌面下拉与移动端面板同款位置）
- 桌面下拉与移动端面板滚动容器隐藏右侧滚动条（scrollbar-hidden）

## 修复清单

- 桌面下拉计数/「查看全部」底栏移出滚动容器：iOS 触摸回弹不再把底栏往上拽、sticky 逐帧抖动消失、结果行不可能从底栏下方漏出
- 移动端搜索结果行去掉 `:active` 缩放反馈：手指滑动起手压在行上不再让行「跳动」（iOS :active 粘滞）
- 移动端整页搜索面板高度链修复（app-page flex-shrink/min-height 强制 + 内容 max-h 封顶）：结果超一屏时页面不再整体滚动，搜索框常驻可见
- 标题描述在全页搜索期间保留（标题+描述两行原样）
